# 保留的反面教材

`gate.py.CONTAMINATED-DO-NOT-REUSE` 是 v3 实验的「确定性结构化效用闸」。

**它不可复用。** 它的实体表硬编码了当时四道测试题的标准答案元素：

```python
ENT = re.compile(r'(湖北|武大|华科|一本|特控|位次|专业组|转专业|保研|分数线|'
                 r'床头|前15位|第\d+圈|退赛|补交|认错|'
                 r'多血质|胆汁质|粘液质|抑郁质|单型|混合型|课堂|作业|清单)')
```

模型看不见这段代码，但它在**选择侧**起作用：8–16 个候选里谁提到这些实体谁就过闸。
于是 v3 中 A3 / C1 / C2 报出的「闸门通过 8/8 全过」**不可信**——很可能是闸门在认答案，而不是机制在起作用。

保留在此是为了让这次失败可追溯，而不是为了复用。
