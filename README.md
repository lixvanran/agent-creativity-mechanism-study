# 为什么 LLM Agent 探索不动：不是搜索空间太小，是前提共享

> 一项关于「ADHD 认知机制能否增强 Agent 创造力」的对抗性迁移研究。
> 2026-10 · 全部代码、提示词、原始答复可复现。

---

## 这个仓库要回答的问题

大语言模型 Agent 在开放任务上表现平庸。流行的解释是**搜索空间太小 / 多样性不足**。这个假设催生了一批「加分支、加采样、加 persona」的方法，包括我自己搭的。

**本研究把这个假设当作待验证命题，而不是前提。**

核心追问不是「怎样让 Agent 更多样」，而是：

> **当多样性机制一个都没能救回某些质量指标时，失败到底出在哪一层？**

---

## 三个结论

### 一、失败模式不是搜索空间小，是**前提共享**

四个实际任务（报志愿 / 自行车赛战术 / 赶作业 / 解读量表），四路架构共 48 份答复：

| 臂 | 出现的院校/地区词 |
|---|---|
| 臂1 直接 | 中南、北邮、华中科技、哈尔滨、武汉、深圳、湖南、电子科技、西安电子 |
| 臂2 ADHD 项目 | 中南、北邮、华中科技、武大、武汉、湖南、电子科技、西安电子 |
| 臂3 双轴 | 中南、华中科技、武大、武汉、深圳、湖南、电子科技 |
| 臂4 双轴 | 中南、华中科技、武大、武汉 |

**四路分支、五个不同规模的模型，全部落在同一个「省内梯队」前提里。**
换了五次视角，没有一个换掉前提。

**决定性证据**：把同一道题接一句中性追问（「除湖北省内的高校外，还有哪些升学通道？」），**单模型单次调用**就给出了港澳高校及其实质门槛。答案是 reachable 的，只是不在 argmax 上。

> **换认知视角 ≠ 换注意对象。**
> 我那六个框架（长时段尺度 / 系统承载力 / 反面案例 / 无利害观察者 / 硬约束 / 二阶效应）改变的是**怎么想**，不是**想什么**。

### 二、**逃逸度是重加权指标，不是扩张指标**

我用来判断成败的指标（离基线质心的语义距离）**永远测不出分布变大**——一个被压窄后整体偏移的分布，逃逸度可能很高。

用一把测不出「变大」的尺子，去验证「有没有变大」。**方法论错误比架构错误更根本。**

能测扩张的量应该是：选项**类别**覆盖率、前提违背率、外部可验证性。

### 三、题目类型决定机制有效与否

| 题型 | 表现 | 原因 |
|---|---|---|
| 开放作文（AI 时代的未来） | 架构间有可测差异 | 无正确答案，「偏离主流」无代价 |
| 实际问题（选校 / 战术 / 赶作业） | 全部停滞 | **有正确答案，偏离即错，多样性是负资产** |

同一套架构在两类题上表现相反，不是 bug，是机制本身是个**多样性机器**——而它在第二类题上不该被使用。

## 六个我自己犯的错

全部写进 [POSTMORTEM.md](POSTMORTEM.md)，因为它们比结论更可复用：

1. **架构幻觉** — 让 Agent「按方法说明写答案」，机制只存在于叙述里，从未被执行
2. **判定函数泄题** — `gate.py` 里硬编码了四道题的标准答案实体；闸门认识答案
3. **检查器失效** — 泄题扫描的禁词表没覆盖代码里实际使用的口语化措辞，检查器通过了但本身是坏的
4. **措辞污染** — 把自己的评分口径（新颖 / 可检验 / 承重假设）写进选择判据，换来了虚假的领先
5. **二手转述未核** — 某论文称 ToT「生成与评估交织在同一次调用里」，**但 ToT 源码里它们是三个独立函数**
6. **关键词扫描漏判** — 模型写「早突围」「兔子小集团」（即套圈/透支），语义命中但正则判 0 分

**第 1、2、5 条的共同点：都是"看起来完成了"而没有独立验证。**

---

## 一个必须说的反证

已发表研究（Yagil 等，*No Evidence for LLMs Being Useful in Problem Reframing*，arXiv 2503.01631）用 280 名设计专业人员发现：**LLM 辅助问题重构没有提升框架质量，反而放大了专家-新人的能力差距。**

本研究不与它冲突——它测的是「人 + LLM」的人类侧产出，本研究观察的是纯系统侧的探索行为。但它的结论构成一道**必须跨过的门槛**，而不是可以绕开的背景。

## 复现

```bash
export OPENROUTER_BASE_URL="https://api.minimaxi.com/v1"
export MINIMAX_SUBSCRIPTION_KEY=...

cd code
python3 leakcheck3.py            # 先验提示词没泄漏，再跑
python3 run_q.py                 # 4 题 × 4 臂 × 3 重复
python3 analyze3.py              # 判据扫描 / 逃逸度 / 离散度 / 臂间距离
```

**沙箱约束**（已实测，写下来省你时间）：
- `git clone` GitHub 会因沙箱 TLS 代理失败；`curl` + GitHub REST API / codeload 可用
- 修正：`git config --global http.sslCAInfo $SSL_CERT_FILE`
- pip 全部索引不通；npm 与 hf-mirror.com 可用
- MiniMax embedding 端点参数是 `texts`（不是 `input`）且必须带 `type: "db"`
- `<think>` 块会吃光 `max_tokens`，需 8000 以上并检查 `finish_reason`
