# 沙箱约束与踩坑记录（已实测）

## 网络

| 事项 | 结论 |
|---|---|
| `gh` CLI | **不存在** |
| `git clone` GitHub | **必失败**：`server certificate verification failed. CAfile: none` |
| 原因 | 沙箱有 TLS 拦截代理 `ack-agent-identity-proxy`（Alibaba Cloud），git 不读 `SSL_CERT_FILE` |
| **修正** | `git config --global http.sslCAInfo $SSL_CERT_FILE`（= `/etc/ssl/certs/agent-identity/sandbox-gateway-ca.crt`） |
| GitHub REST API | ✅ 可用 |
| `codeload.github.com` tarball | ✅ 可用（`/tar.gz/refs/heads/{main\|master}`） |
| `registry.npmjs.org` | ✅ 通（pip 不通，Python 包只能走 npm 侧的 JS 实现） |
| `hf-mirror.com` | ✅ 通（huggingface.co 官方站不通） |
| `arxiv.org` | PDF 直连超时；**API 可用**（`export.arxiv.org/api/query`） |
| `aclanthology.org` | 页面可 curl；`web_fetch` 失败 |
| `doi.org` | 页面 `web_fetch` 失败；**Crossref API 可用** |
| `pubmed.ncbi.nlm.nih.gov` | `web_fetch` 失败；**NCBI E-utilities 可用** |

## 模型接口

| 事项 | 结论 |
|---|---|
| MiniMax chat | `https://api.minimaxi.com/v1/chat/completions`，同 key 共 9 个档位（M3 / M3.1-Flash-Preview / M2.7 / M2.5 / M2.1 / M2 …） |
| MiniMax embedding | `https://api.minimaxi.com/v1/embeddings`，1536 维，语义验证通过（同域 0.66 / 跨域 0.08） |
| embedding 参数 | **是 `texts` 不是 `input`**，且**必须带 `type: "db"`**（`query` 亦可，`document` 报错） |
| `<think>` 块 | 会吃光 `max_tokens`。**默认 8000 起，并检查 `finish_reason == "length"` 后重试** |
| 退化返回 | 弱档位（M2.5 / M2.1）会把预算花在 meta 分析 persona 指令上，返回 25–32 字符且 `<think>` 未闭合。**判据：`<think>` 未闭合即视为无正文，重试** |
| `content` 字段缺失 | M3.1-Flash-Preview 把思考放进 `reasoning_content`（实测 17081 字符），`content` 可能整个不存在 → 需先判 `finish_reason` |
| Claude SDK 兼容端点 | `https://api.minimaxi.com/anthropic` 可用，**`@anthropic-ai/claude-agent-sdk` 能直接指过去**（`ANTHROPIC_BASE_URL` + `ANTHROPIC_API_KEY`） |
| 并发退化 | 3 路并发以上会出现分支静默退化，**题内串行、题级并行**是本次验证过的稳定配置 |

## 统计

`analyze.py` 里手写了 t 分布 p 值（不完全 beta + 连分数），与查表值误差 <1e-4；符号翻转置换检验作为稳健性对照。

## 环境清理

`/tmp` 会被周期性清空。**下载的第三方仓库要放在 `/workspace` 下**，否则下一轮就找不到了。
