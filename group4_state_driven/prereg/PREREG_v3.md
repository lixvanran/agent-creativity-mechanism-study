## 0. 为什么做 v3（两条前置诊断的结论）

### 诊断 ①：v1 的"驱动内容有效"是过度解读

`probe_arch.py` 的 swap 变体用**同一个 `state0`**（`keeps` 不变），只换第③步看到的初稿
⇒ 它测的是「**观测 → 状态 → 产出**」（反馈通路），**不是**「驱动内容 → 产出」（驱动力通路）。
⇒ v1 报告与 `DRIVER_AUDIT.md` §0 把它写成"驱动内容确实在驱动产出" ⇒ **过度解读，需更正**。
（顺带发现：v1 缺**纯重跑地板 D0**，用"格式扰动"当地板 ⇒ 结论偏保守；
补算 D0 = 0.1606 后，D2/D0 = **9.13×**，反馈通路是**强分离**。）

### 诊断 ②：真正该测的那条通路，两批都没测出来

| 通路 | 测法 | 结果 |
|---|---|---|
| 反馈（观测→状态→产出） | v1 D2 换初稿 | **9.13× 分离** ✅ |
| **驱动力（取舍→产出）** | v2 D2 换立场 | **不可分辨** ❌ |
| 候选集执行 | 必含/禁含命中 | 100% / 0% ✅（代码约束，**非驱动力**） |

⇒ **第四组的核心命题是"驱动力"通路，而它恰恰是唯一没测出来的那条。**
⇒ v3 的目标不是"让取舍更干净"，而是**回答"取舍为什么驱动不了产出"**。

## 2. v3 的状态设计（改数据结构，不是加提示词）

```
State3:
  stance / keeps / slip / first      # 认知产物（模型）
  branches: List[str]                # ★ 岔路候选（**代码从观测的实体集里给**）
  decisions: List[dict]              # ★ {branch, choice: 走|不走, priority: 1..3}
  must_include / forbidden            # ★ 由 decisions **代码推导**
  entities / gaps / lang / excluded  # v2 已有（封闭）
```

- **岔路候选从哪来**：观测步给出的实体（已逐字校验 ⊆ 初稿）⇒ **封闭**
- **表态**：封闭枚举 `走 | 不走` + `priority ∈ {1,2,3}` ⇒ **封闭**
- **代码推导**：
  - `choice=走` 的分支 ⇒ 该分支对应实体进入 **must_include**
  - `choice=不走` 的分支 ⇒ 该分支对应实体进入 **forbidden**
- ⇒ **取舍的载体 = "在给定岔路上表态"**：既封闭（决策空间有限），**又保留取舍的实质**（模型仍然做判断）

⚠️ **不循环论证的自检**：
- "必含命中 100%" 只是**代码约束被执行**（v2 已证）⇒ **不作为 v3 的证据**
- v3 的证据只能是 **D2'**（换候选集 ⇒ 产出换向）与 **D0**（地板）

## 3. 读数与判决规则（**先定死，事后不改**）

### 3.1 D0 纯重跑地板（**每个批次必跑**）

同输入、同驱动、同代码，再跑一次整条链。
⇒ 读数：产出 vs 基线的**实词 Jaccard**（越低 = 差异越大）
⇒ **判决**：任何"变体 vs 基线"的差异，若不显著低于 D0 ⇒ 写"不可分辨"。

### 3.2 D2' 换候选集（**单变量**）

把 `branches` 换成一组**不同的岔路候选**（其余一切不变：观测、实体、代码、模板全同）。
⇒ 读数：
- `R_tradeoff` = (换后"被选为走"的实体出现率) − (换前同一实体的出现率) ⇒ **期望 > 0**
- 产出 vs 基线的实词 Jaccard ⇒ **期望显著低于 D0**

### 3.3 D3 无关候选集（**盲从地板**）

`branches` 换成一组**结构相似、领域无关**的候选。
⇒ 读数：产出 vs 基线的实词 Jaccard
⇒ **判决**：若 D2' 与 D3 不可区分 ⇒ **不可分辨**（模型只是对"候选集变了"有反应）。

### 3.4 S-self 对照臂（**等预算 + 取舍意识 + 无状态**）

4 步管线：① 自我说明（说清要牺牲什么）② 写作 ③ 中性修订意见 ④ 定稿。
⇒ 读数：产出 vs WF-a3 的实词 Jaccard
⇒ **判决**：若 WF-a3 ≈ S-self ⇒ **状态机相对"一次性自我说明"没有增量**。

### 3.5 判决表（**先定死**）

| 情形 | 判决 |
|---|---|
| D2' 显著低于 D0 **且** 显著低于 D3 | 驱动力通路**成立** |
| D2' 显著低于 D0 但**不**显著低于 D3 | 只证明"候选集变了会改变产出" ⇒ **不可分辨**（盲从） |
| D2' ≈ D0 | 驱动力通路**不成立** |
| WF-a3 ≈ S-self | 状态机**无增量**（相对一次性自我说明） |

## 3.6 ★ 补充：分离的量化规则（**补充于探针结果产生之前**，2026-10-21 22:52）

⚠️ §3 漏了"显著低于"的量化定义。补上（**此补充在任何 v3 探针结果出现之前写入**）：

> **分离** = 满足**两条**：
> 1. 逐例比较中，变体 J **低于** D0 的比例 **≥ 2/3**（n=3 ⇒ 至少 2 例）
> 2. 均值比 `J_variant / J_D0` **≤ 0.70**（即至少低 30%）
>
> **不可分辨** = 不满足上述两条中的任意一条。
>
> ⚠️ n=3 无统计效力 ⇒ 本规则**不是**显著性检验，只是**判决门槛**。
> ⚠️ 报告里必须同时给出 D0、D2'、D3 的**逐例值**与**均值**，不得只给均值。
