## 1. ★★ 什么叫"分化"（★ 操作化定义）

★ **★ 候选池的"分化" = ★ 三个候选的【自主声明】在【编号集合】上不完全相同。**

★ **★ 为什么用"编号集合"而不是别的**：★
★ ① 候选的声明本来就���**编号化**的（`decl_write` / `decl_drop` ⇒ 编号集合）⇒ ⇒ **可机械比较**
★ ② 状态决策也是编号集合（`deep_set` / `drop_set`）⇒ ⇒ **两者同口径**
★ ③ ★ **★ 与层 2 的"两轴"可对齐**（★ 见 §4）

★ **★ 三个层次的分化（★ 由弱到强）**：

| ★ 层次 | ★ 定义 | ★ 机械判据 | ★ 强度 |
|:-:|---|---|---|
| ★ **D0** | ★ **候选之间有任何可区分的声明** | ★ 三个候选的 `(decl_write, decl_drop)` **不全相同** | ★ 最低门槛 |
| ★ **D1** | ★ **候选之间的【放弃项】不同** | ★ 三个候选的 `decl_drop` **两两不同**（★ 至少两个候选放弃的东西不一样） | ★ ★ **★ 主判据** |
| ★ **D2** | ★ **候选之间的【放弃项】覆盖了状态的不同决策** | ★ **候选集合的 `decl_drop` 并集** 覆盖了状态 `drop_set` 的**多个不同编号** | ★ 最强 |

★ **★ 为什么主判据选 D1（放弃项不同）而不是 D0（任何不同）**：
★ ⇒ ★ **「愿意放弃什么」正是我们要测的那个维度** ⇒ ⇒ ★ **D0 太弱**（★ 只要措辞或写透编号不同就算，★ 而那与"取舍"无关）
★ ⇒ ⇒ ★ **D2 最强但可能过严**（★ 要求候选主动分散覆盖状态的多个放弃项 ⇒ ★ 可能只有特定题型能达到）
★ ⇒ ⇒ ★ ⇒ **★ 三档都要报，★ 但主判据是 D1**。

## 2. ★★ 分化率怎么算（★ 事前定死）

```
★ **分化率 D1 = ★ (满足 D1 的单元数) / (分母)**
★ **分母 = ★ 该单元【三个候选全部有效】的单元数**
★   （★ 候选解析失败 ⇒ 该单元【不计入分母】⇒ ★ **不许按 0 计入** ⇒ ★ 同「三种 0 要分开」）
```

★ **★ 三个必须同时报的口径**：

| ★ 口径 | ★ 定义 | ★ 作用 |
|---|---|---|
| ★ **D1 严格** | ★ 三个候选的 `decl_drop` **两两不同**（★ 三个全不同） | ★ 最严 |
| ★ **D1 宽松** | ★ **至少两个**候选的 `decl_drop` 不同 | ★ ★ **主判据** |
| ★ **D1 有效声明** | ★ 分母只算【三个候选都有可解析声明】的单元 | ★ **分母口径**（★ 防止把解析失败算成分化失败） |

★ **★ 判读规则（★ 事前的，★ 不许事后改）**：

| ★ 实测 | ★ 判读 |
|---|---|
| ★ D1 宽松 ≥ **0.5** | ★ ★ **候选端达标** ⇒ ⇒ **可以开 Stage-2 的能力实验** |
| ★ 0.2 ≤ D1 宽松 < 0.5 | ★ **候选端【未达标但接近】** ⇒ ⇒ **先查提示设计（★ 是否把状态内容泄漏给了候选）**，★ 不进能力实验 |
| ★ D1 宽松 < **0.2** | ★ **候选端未达标** ⇒ ⇒ **Stage-2 不启动**（★ 按预注册门②③ 的同一逻辑） |

★ **★ 为什么阈值取 0.5 / 0.2（★ 事前说明，★ 防止事后调）**：
★ ⇒ ★ **0.5 = 多数单元达标**（★ 粗略的中位数分界，★ 不依赖本批数据）
★ ⇒ ★ **0.2 = 明显未达标**（★ 与「随机水平」拉开距离）
★ ⇒ ★ ★ **★ 这两个数是【设计时的直觉门槛】，★ 不是从数据里反推的** ⇒ ⇒ ★ **★ 所以它们不是「事后调判据」**（★ 但**必须在下一批之前**改一次，★ 因为下一批的数据会告诉我们它准不准 ⇒ ⇒ ★ **改的话要留痕**）。

## 3. ★★ 必须同时报的【区分力读数】（★ 防止"分化了但依然没区分力"）

★ **★ 分化率【不等于】区分力。** ★ 候选的声明不同，★ 但**打分器仍可能读不出差别**（★ 这就是 Stage-1 的 `spread` Gate）。

| ★ 读数 | ★ 定义 | ★ 门槛（★ 事前） |
|---|---|---|
| ★ **批内区分力** | ★ 每个单元里，三个候选在**主判据打分器**上的 `spread = max−min` | ★ **至少 1/3 的单元 spread > 0**（★ 事前定，★ 防止"分化了但仍全是平手"） |
| ★ **题内 σ** | ★ 该单元三个候选主判据分的样本内标准差（★ n−1 分母） | ★ ★ **★ 报告【可算单元数 / 总单元数】**（★ Stage-1 是 1/9）⇒ ⇒ ★ **★ 可算比例 ≥ 1/3 ⇒ 才能算标准化效应量** |
| ★ **Gate 区分力** | ★ 各 Gate 的批内 `var` 与 `len_corr` | ★ ★ **`len_corr` 的绝对值 > 0.9 的 Gate ⇒ 判为【退化】（★ 不进"最优家族"）** |

★ **★ 与 Stage-1 的对照（★ 说明这套判据会抓到哪些问题）**：

| ★ 读数 | ★ Stage-1 实测 | ★ 按本判据 |
|---|---|---|
| ★ 对照端有区分力的单元 | 1/9 = 0.11 | ★ ★ **< 1/3 ⇒ 不达标** ✔（★ 与"候选无区分可排"的诊断一致） |
| ★ 题内 σ 可算比例 | 1/9 = 0.11 | ★ ★ **< 1/3 ⇒ 标准化效应量算不了** ✔ |
| ★ `length` 的 `len_corr` | +1.000 | ★ ★ **|r| > 0.9 ⇒ 判为退化 Gate** ✔ |
| ★ `spread` 的 `var` | 0.0（9/9 恒定） | ★ ★ **恒常量 ⇒ 不进"最优家族"** ✔ |
