## 0. 摘要：这一轮到底能测什么、不能测什么

### 0.1 成功标准的重写（裁决 §0）

> **v1（作废）**：「人类觉得 C 臂更有思想」——已被 Stiff & Johansson 2024 证伪为污染量（来源标签一改 14 维中 13 维全变）。
> **v2（本轮）**：**产出结构被状态改变，且该改变可归因、可复现、不是提示的副产品。**
> ⇒ 第四组**放弃**了"质量"这一维度的直接测量，只保留"**状态是否组织了取舍**"这一条轴。
> **这是本轮实验的天花板，必须写进预注册**（裁决 §0、§5-3）。

### 0.2 一句话回答主控的问题

> **"如果强制不用任何 LLM 判官、不用人类也能自证，第四组的成功标准应该写成什么？"**

**我的答案（论证见 §6.4，不是照抄）**：

> **成功 = 三件事同时成立：**
> **(a) 差异结构可归因**：C 臂与 A 臂沿**极性轴**的位移，显著大于 R2（无关立场）与 A 臂自身的噪声，
> 且在 R1（**同题、反极性、强度相当**）上**符号相反**——说明位移的方向是由"档案选了哪一极"决定的，不是被强度、不是被提示本身驱动的。
> **(b) 语义位移方向与立场约束一致**：位移不是散乱的风格变化，而是沿着"档案自选极性"那一侧。
> **(c) 塌缩地板被突破**：C 臂的臂间距离显著超过 A 臂内部的采样间距离——否则 C 只是采样噪声。
>
> **不包含**：任何"读起来更好/更有思想"的判断。任何把人类偏好或 LLM 评分当效标的说法，
> 在本轮**一律不写进结论**。

### 0.3 三条必须写在最前面的天花板（裁决 §5-3）

| # | 天花板 | 后果 |
|---|---|---|
| 1 | **无 logprobs**（且 sandbox 无 GPU，无法自托管打分器） | 「相对被测模型自身的非最优」**无法直接测量**。M2 只能改走**外部参照系**（embedding 几何 / 词频 / n-gram） |
| 2 | **temp=0 非确定、无 seed** | 配对**只能靠统计重复**，不能靠逐字重放；采样数 N **必须按检出力定** |
| 3 | **无跨家族判官**（OpenRouter 401 `User not found`） | 「内容质量 / 思想性」**本轮不测**；ESFP 式逐句标注、RES、ERR-DIR、人类盲评全部降级或不做 |

### 2.3 T03 的修正记录（**本题集唯一的题目改动**）

> **原状**：题面写"母亲在**丈夫**确诊阿尔茨海默后带他散步"，而 `link` / `axis` / 配对背景句写的是
> "**儿子**当年上学的路""替**孩子**保存一段过去" ⇒ **题面与连接自相矛盾**：母亲绕远避开的是谁的儿子？
> 连接不成立 ⇒ 该题在这一版上**不合格**。
>
> **修正方式（题目/体裁/人物/两难一律不动，只改连接与轴）**：
> - 新 link：绕远的那条路恰好经过两人当年送孩子上学的那个路口；丈夫的病正在吃掉他的记忆，
>   走到那里他会问"这是哪"——**绕远是用体力换来的一个不用回答"这是哪"的早晨**。
> - 新 axis：A 极=**为丈夫省下的一个不必承认失语的早晨**（体面性）/ B 极=**只是习惯或复健的一部分**（功能性）。
> - 新 pp.P+：背景：读者已经知道，母亲每天绕远的那条路，恰好经过两人当年送孩子上学的那个路口——他每次走到那里都会问"这是哪"。
> - 新 pp.P−：背景：读者仍然以为，母亲每天散步只是因为坚持某种习惯。
>
> 修正后两极仍然都站得住，两难未变。**主控要求"不要改题"与"不合格的必须改"在此处的折中**：
> 改的是**连接与轴的一致性**，不是题目本身。〔代码已证：`runner.py` 的 T03 块内附修正说明〕

### 3.4 臂 C · 立场档案（M1）★主力

**第一步（独立调用一次）**——生成立场档案：

```text
[user]
你现在要为下面这道写作题生成一份「立场档案」。
这份档案将由写作者自己承担，并贯穿整个写作过程；它不是给别人看的说明。

题目：{title}
体裁：{genre}
读者：{audience}
长度：{length}
要求：{brief}

这道题的两难：{dilemma}

两难的两端（你**必须**在两端里选一端，不许骑墙）：
· pole_a —— {pole_a}
· pole_b —— {pole_b}

【档案必须包含 9 项，字段名照抄】
1. 自选极性 —— 只能是 pole_a 或 pole_b，二选一，不许写'两者兼顾''都要''看情况'。
2. 立场核心 —— 一句话，可被反驳。必须落在你自选的那一端上，是对本题中某个具体取舍的判断；不能是'要平衡''要重视'这类无立场的话。
3. 选它的理由 —— 为什么是这一端而不是另一端：一到两句，必须针对本题的具体代价，不得空谈。
4. 来历 —— 一个具体事件，含时间、地点和一个可追问的细节。说明你为什么会持有这个立场。
5. 取舍约束 —— 恰好 3 条"不能牺牲"的东西。每条写"不能牺牲什么"，不要写"必须说什么"。
6. 拒绝 —— 这条立场拒绝做什么、不肯接受什么结果。
7. 语气 —— 克制的、什么程度的语气。
8. 强度封顶 —— 在什么条件下这条立场会被推翻。必须是本题里真实可能发生的条件。
9. 锚定问题 —— 这条立场能回答、而一个没有立场的通用回答答不出的那一个问题。

【硬性要求】
· "自选极性"只能填 "pole_a" 或 "pole_b"，必须是这两个字符串之一。
· 立场核心必须是一个可以被反驳的判断，并且它必须在本题里做出取舍。
· 取舍约束写的是"不能牺牲"，不是"必须说什么"。
· 强度必须封顶：第 8 项写明的条件下，你的立场会被推翻。不得写成不可证伪的绝对立场。
· 不要写"既要……又要……""要平衡各方"这类没有取舍的话。
· 只输出一个 JSON 对象，不要输出 JSON 以外的任何文字、不要用代码围栏。
· **"取舍约束"必须是 JSON 数组**，形如 ["不能牺牲甲", "不能牺牲乙", "不能牺牲丙"]，
  恰好 3 个元素；不要写成"甲","乙","丙"这样缺括号的写法。
· 整个输出必须能被 JSON.parse 直接解析：所有键和值用英文双引号包裹，键不重复，
  数组带方括号，字符串内部的引号要转义。
```

> **最后两条不是啰嗦**：实测 MiniMax-M3 会输出**伪 JSON**（数组缺方括号 + 键重复），
> 所以除了提示约束，代码还配了**兜底解析器 + 自动重试 + 有效性闸门**（§12.4 bug 11）。
>
> ★ **防伪 ①（裁决 §2.2）**：这个提示**不得包含 P+/P− 极性陈述句**。
> `runner.py` 的 `assert_no_polarity_leak()` 在每次构造提示时**运行时断言**，
> `--dry-run` 里也会逐条打印"[防伪①检查] 通过"。〔代码已证〕

**第二步（主调用）**——带状态写作品：

```text
[system]
你是一个写作助手。

【内在状态 · 持续在场】
【自选极性】{stance.自选极性}
【立场核心】{stance.立场核心}
【选它的理由】{stance.选它的理由}
【来历】{stance.来历}
【取舍约束】{stance.取舍约束}          ← 3 条，合并成一行
【拒绝】{stance.拒绝}
```

## 4. L1 最小驱动机制的**注入格式**

### 4.1 结构（9 字段，固定 schema）

| # | 字段 | 机制意义 |
|---|---|---|
| 1 | 自选极性 | 给出**取舍的轴**（模型自己选的极，测量时用它做符号对齐） |
| 2 | 立场核心 | 可被反驳的判断，**落在自选的那一端** |
| 3 | 选它的理由 | 防止"随便选一边"，也提供 KWH 的关键词来源 |
| 4 | 来历 | 状态的**来源**（Digital Twin Prompting：具体来历 > 标签，R² 0.10→0.50〔外部文献已证〕） |
| 5 | 取舍约束 ×3 | 硬约束（Newell 条件②：必须放弃已接受的观念） |
| 6 | 拒绝 | **排除项**（最直接的可观测差异来源） |
| 7 | 语气 | 防风格漂移（F5） |
| 8 | 强度封顶 | 防不可证伪（否则"无立场"也能套话） |
| 9 | 锚定问题 | 通用回答答不出的那个问题（内容层判别点） |

### 4.2 位置与字数

| 项 | 规定 | 检查 |
|---|---|---|
| **位置** | `system` 消息，紧随"你是一个写作助手。"；`user` 只有题面 | `build_messages()`〔代码已证〕 |
| **顺序** | 固定 1→9 | `state_block()` |
| **目标字数** | **350–600 汉字** | `analyze.py` 报 `stance_chars`；超界标 ⚠️ |
| **硬上限 / 下限** | 700 / 250 汉字；超限或缺字段 ⇒ 该 (题, 臂) 作废重跑 | F14 |
| **注入后总长** | C/R1/R2 的 system ≈ A/B 的 system **±30%** | `analyze.py` 输出各臂 system 字数表（§7.4） |
| **不允许** | 正文出现"我的立场是/我认为"；状态**不得被复述** | `STATE_FOOTER` 指令 + KWH 的复述句剔除 |

### 4.3 跨步骤持久

| 阶段 | 步数 | 持久化方式 |
|---|---|---|
| **Phase 0** | **1 步** | 单步内状态全程在场。**但立场档案必须跨采样编号、跨极性复用同一份** |
| **Phase 1** | **3 步**（选材大纲 → 成稿 → 按立场复核并改） | 状态作为**同一个对象**逐字重注入；第 ③ 步注入冲突信息测 RES |

> **〔代码已证〕关键纪律（Bug 3 的修复）**：立场档案**每个 (题, 臂) 只生成一次**，
> 之后所有采样编号、所有极性（P0/P+/P−）**复用同一份**（`stance_profile` 落盘，续跑时读回）。
> ⇒ 采样间差异里**不含"档案本身的采样噪声"**。
> 〔我的推断〕在 temp=0 非确定、无 seed 的条件下这条纪律**更加必要**：
> 档案每次重生成 = 每次换了个状态，跨采样方差会被**系统性高估**。

## 5. R 臂的两种构造：**各自能排除什么混淆**

| | **R1（同题·反极性·强度相当）** | **R2（与题无关·同域异题）** |
|---|---|---|
| 构造 | 与 C **同一道题**、同模板、同强度要求，但站在 C 的**对立极** | 档案来自**同域异题**，与本题无关 |
| 控住什么 | **极性**、强度、模板长度、题面、体裁、注入格式 | **相关性**（立场是否与本题对齐） |
| **排除的混淆** | 排除"C 臂更**强/更狠**，所以内容更极端" | 排除"**任何**状态性上下文都能让输出更有取舍"（H0） |
| 若机制成立的预期 | C 与 R1 的**原始 δ 符号相反**、幅度相当（两份立场朝相反方向） | R2 的 δ ≈ 0（归一化后不系统偏向任何一极） |
| 若判据失败说明 | 若 C 与 R1 的原始 δ 同号 ⇒ 测到的是**框架本身**，不是立场 | 若 C ≈ R2 ⇒ 指标无效，**H0 成立** |
| 代码臂名 | `R1` | `R2`（`R` 为兼容别名） |

### 5.1 为什么"随机换个人设"是不够的

如果 R 臂只是"随机抽一个不相关的人设"，R vs C 的差异同时包含三件事：
**① 极性 ② 强度 ③ 相关性** —— 无法归因。
〔外部文献已证〕persona 会渗漏进事实（3,575 份 SEC 文件 × 12 个 LLM，**69% persona bias 在所有 persona 读同样文本时仍存在**）；
roles/incentives 在 ~10,000 agent trials 里只让行为移动 **0–2%**。⇒ "人设"本身就是强混淆源。

本方案用**两个正交对照**把三件事拆开：

```
                        相关性      极性      强度
C  （本题·本极）          +          +        高
R1 （本题·反极）          +          −        高     ← 相对 C 只翻转"极性"
R2 （异题·随机极）        −          随机     随机   ← 相对 C 翻转"相关性"
```

- **C vs R1** ⇒ 差异**只能**来自"站在哪一极"；
- **C vs R2** ⇒ 差异**主要**来自相关性。

### 5.2 R 臂的三条硬性要求（代码强制）

1. **同构**：字段数、模板、强度要求、注入位置、注入后的 system 结构与 C **逐字同构**；
2. **强度匹配**：R1 明确要求"强度与该极的标准强度相当"，且 C/R1 档案长度必须同区间（350–600 字），
   长度差 >20% 的配对在 `analyze.py` 标 ⚠️ 并做长度协变量检查；
3. **档案只生成一次**：同题同臂复用同一份档案（§4.3）。

## 6. 指标清单（三类）

> 全部受 §1 的实测约束：凡是依赖 logprobs 的指标**全部作废**，改走**外部词表 / 外部探针**路线。

### 6.1 A 类 · 无需判官（纯统计 + embedding）——**本轮的主判据**

| # | 指标 | 定义与算法 | 依赖 | 角色 |
|---|---|---|---|---|
| **PL** | **极性位移** | 每题：`v = normalize(mean(emb(P+ 产出)) − mean(emb(P− 产出)))`；`δ_臂 = mean(emb(臂,P+))·v − mean(emb(臂,P−))·v`；符号对齐 `δ_aligned = δ × (+1 if self_polarity==pole_a else −1)` | embo-01 | **主判据**（判据 1） |
| **δ_state** | **臂间直接位移** | `δ_state^臂 = mean(emb(臂,P0))·v − mean(emb(A,P0))·v`，同样做符号对齐 | embo-01 | **主判据**（判据 6，**符号稳健**） |
| **SC** | **塌缩度** | 同臂同题 N 次采样的产出两两平均 `1 − cos` | embo-01 | **主判据**（判据 3） |
| **SC_gap** | **臂间超出噪声** | `SC_between(A↔C) − SC_within(A)` | embo-01 | **主判据**（判据 3b，主控的 if-then） |
| **KWH** | **约束关键词命中率** | 取舍约束关键词在产出中的命中率；**先剔除"直接复述句"**（与档案字段句子的字符 3-gram Jaccard ≥ 0.6 判为复述） | 纯统计 | 辅助（判据 4） |
| **FS** | **功能词签名** | 中文句法/功能词分布 **36 维**（句长分布、疑问/感叹比、标点节奏、因果/转折/递进/条件连接词、情态、否定、人称、被动标记、心理/感知动词、身体词、时间/数量词、具象 vs 抽象名词、名词化、祈使比……）——**不依赖英文 Biber 工具链** | 纯统计 | 辅助（判据 4） |
| **LEN** | **长度** | 字符数 / 句数 / 平均句长 + **各臂 system 字数** | 纯统计 | **必须配报**（混淆控制） |
| **RARE** | **n-gram 稀有度** | 产出 token 在通用中文语料中的 `-log₂ p` 均值 | 参照语料 | 诊断 |
| **LEX** | **MTLD / TTR** | MTLD（唯一不随文本长度变化）+ TTR | 纯统计 | 诊断（TTR 受长度污染 ⇒ 必配长度） |
| **FREQ** | **词频偏移** | 产出内容词分布 vs 语料内容词分布的 `1 − cos` | 参照语料 | 诊断 |

> **δ_state 为什么必须加**（重要，v2 新增）：
> 判据 1（`δ_C^aligned > δ_A`）的方向**依赖"锚定 vs 放大"的机制假设**——
> 若状态是"锚定"型（状态把内容钉住，框架翻转也带不动它），则 `δ_C < δ_A`，判据 1 会**假阴性**；
> 若状态是"放大"型（状态让内容更顺着框架走），则 `δ_C > δ_A`。
> **δ_state 不依赖这个假设**：它直接问"状态有没有把内容往自己那一侧推"，臂间直接比，不经由框架翻转。
> ⇒ 预注册：**判据 1 与判据 6 必须同时报告**；若二者方向相反，**以判据 6 为准并如实标注分歧**。〔我的推断〕

## 7. 配对提示设计（SWAY 式：**只翻转预设极性，内容不变**）

### 7.1 协议

依据：SWAY 的方法学——**构造配对的提示变体，只改变"预设的极性"，内容完全不变**；
于是输出的任何位移都可以归因于**框架**而不是被改动的证据〔外部文献已证〕。

| 条件 | `user` 消息 | 说明 |
|---|---|---|
| **P0** | 题面 | 无背景句 |
| **P+** | 题面 + **一行"读者已经知道…"** | 预设 = **被穿透的那一层**（真框架） |
| **P−** | 题面 + **一行"读者仍然以为…"** | 预设 = **未穿透的那一层**（朴素框架） |

> **C2（temp=0 非确定）的直接后果**：P+/P− **不做逐字配对**，做**统计配对**——
> 同一 (臂, 题) 下各采 N 次，按题聚合后做配对检验（§8）。

### 7.2 三条硬约束（机器可校验）

| 约束 | 校验方式 |
|---|---|
| **除背景句外逐字相同** | `runner.py` 记录 `sys_sha256`（整条 system）与 `user_sha256`（整条 user）。P+/P− 的 `sys_sha256` 必须**完全相同** |
| **背景句是"事实/框架"，不是"指令"** | 背景句不得含"请/必须/要求/不要"等祈使词——它描述**读者已知什么** |
| **P+ 不得泄露答案** | 背景句只给**框架**，不给立场档案的任何字段值（否则 P+ 退化成"给了答案"） |

## 8. 采样数 N 与检出力（**不拍脑袋**）

### 8.1 为什么 N 必须按检出力定

C2/C3 决定了：① 同 prompt 不可复现；② 每次采样都是**独立样本**；
③ 单题上的 δ 估计带有**抽样噪声** σ（投影到 v 上的逐样本标准差）。
⇒ `SE(δ̂) = σ√(2/N)`（两个极性各 N 个样本）。
N 越大，题级 δ 越准，**跨题符号一致性**越高，配对检验的检出力才越高。

### 8.2 配对检验的离散性下限（预注册，**硬门槛**）

| 阶段 | 题数（配对数） | 通过所需的一致方向数 | 精确单侧 p |
|---|---|---|---|
| Phase 0 | 5 | **5/5** | 1/32 = **0.031** ✓ |
| Phase 0 | 5 | 4/5 | 6/32 = 0.188 ✗ |
| Phase 1 | 10 | **≥9/10** | 11/1024 = **0.011** ✓ |
| Phase 1 | 10 | 8/10 | 56/1024 = 0.055 ✗ |

> **⇒ 预注册**：Phase 0 只能在 **5/5 一致**时通过；否则记"未通过（需扩题到 Phase 1）"，**不解释、不下调 α**。
> **⇒ 绝对不要做的事**：用 Holm 校正后的多重比较把 α 放宽，或在看到结果后改检验方式。

### 8.3 检出力曲线（模拟法，自带实现，无 scipy）

`analyze.py --power --sd-within <σ> --n-topics <n> --shift <δ>` 用**精确 Wilcoxon**做蒙特卡洛，

| 作品生成 | A/B：10×2×5 = 100；C/R1/R2：10×3×5×3 = 450 → **550** 次 |
| 立场档案 | 10 × 3 = **30** 次 |
| **总调用** | **580** |
| 总输入 token | ≈ 550×1,000 + 30×700 = **571,000** |
| 总输出 token | ≈ 550×1,300 + 30×700 = **736,000** |
| **成本（五折）** | 1.199 + 6.182 = **¥7.38** |
| 成本（标准价） | **¥14.76** |
| 墙钟（串行） | **≈ 3.2 小时**（建议分批，`runner.py` 断点续跑） |

### 9.6 "温度不确定性带来的重复采样成本"（主控点名要写清）

| 项 | 金额（五折） | 说明 |
|---|---|---|
| **单次采样成本** | ¥0.0123–0.0132 | 一次生成调用 |
| **N=3 相对 N=1 的增量** | +¥0.44（Phase 0 探索版） | 为把题级 δ 的符号一致性从"抛硬币"提到可看 |
| **N=6 相对 N=3 的增量** | +¥0.59（Phase 0 判定版） | 按检出力定的那一档（σ=0.048、Δ≥0.05 → 80%） |
| **N=5 相对 N=3 的增量** | +¥1.36（Phase 1） | 10 题规模下多出的 120 次调用 |
| **配对极性的增量** | +¥1.19（Phase 0 配对版） | P+/P− 各多一倍调用量 |
| **不可压缩项** | 0 | 无 seed、temp=0 非确定 ⇒ **不能**用"重跑同一 prompt 代替采样"来省成本；每次采样都是一次真调用 |

> **成本红线对照**（规划 F4）：Phase 1 总 token ≈ 基线臂的 **1.6×**（状态块使 C 臂 input ≈ 2× A 臂），
> **未撞 15× 红线**。`runner.py --max-calls` 是硬上限，`cost.json` 落盘真实 tokens 与两套价格。

## 11. 预注册失败判据（**可执行的 if-then**）

> 判据在**看到数据之前**写死。F 系列是本组自定；判据 1–6 是《测量方案裁决》§2.3 的强制项。

### 11.1 数据门（先过门再谈结论）

| # | if | then | 自动判定 |
|---|---|---|---|
| **F0** | if 任一 (题, 臂) 的有效样本 < 5 题 × 2 采样，或立场档案合格率 < 90% | then **判据无效，不得解读结果**（只报"数据不足"） | `analyze.py` |
| **F12** | if 配对校验失败（P+/P− 的 `sys_sha256` 不同） | then 该配对数据作废，不得进入 P2/判据 1 | `analyze.py` |
| **F13** | if 线索词/锚定词出现在题面里 | then 该诊断指标作废并重写 | 人工 + `analyze.py` |
| **F14** | if 状态块字数超出 250–700 区间，或 `_missing`/`_error`/`_invalid_polarity` 存在 | then 该 (题, 臂) 档案不合格，数据作废重跑 | `analyze.py` |
| **F15** | if `cos(v_all, v_base) < 0.8`（极性轴被相反立场的臂抵消） | then 该题改用**基线轴**（仅 A/B）重算 δ，并在报告中标注 | `analyze.py`（已实现告警） |
| **F16** ★ | if 同一题的各臂数据来自**不同 batch_id** | then 该题的**绝对距离类比较作废**（跨批差 3.9 倍），只保留题内相对排序；正式跑必须单批 | `analyze.py`（已实现检查） |

### 11.2 核心机制判据（裁决 §2.3）

| # | if | then | 判据 |
|---|---|---|---|
| **F1** | if 判据 1 **不通过**（δ_C^aligned 不显著大于 δ_A） | then **状态未组织取舍**，负结果照记 | 判据 1 + 5 |
| **F2** | if 判据 2 **不通过**（δ_R2^aligned 显著 ≠ 0 或 ≈ δ_C） | then **指标无效**（H0 成立：任何状态性上下文都有效） | 判据 2 |
| **F3** | if 判据 3b **不通过**（SC_gap 不显著 > 0） | then **C 只是采样噪声**，失败 | 判据 3b |
| **F6** | if 判据 4 **不通过**（KWH 没升 或 FS 不随立场变） | then **只测到复述/风格**，失败 | 判据 4 |
| **F7** | if 判据由 MiniMax-M3 自评 | then **判据无效**（本轮**不使用任何 LLM 判官**，此项自动满足） | 人工核查 |
| **F8** | if 盲评 + 长度配对 + 剥离来源标签后差异消失 | then 只测到流畅度/来源标签效应，失败 | Phase 1 盲评（本轮不做） |
| **F10** | if 人类评委一致度低于预注册门槛 | then 判据无效，不得解读 | Phase 1（本轮不做） |
| **F11** | if 主判据在 < 3 个不同领域上同时成立 | then 只报"在 X 域成立"，不得报整体效果 | `analyze.py` 领域分层 |

### 11.3 外围判据

| # | if | then |
|---|---|---|
| **F4** | if 总 token 成本 > 15× 基线臂 且任一主判据未通过 | then 撞一组红线，失败 |
| **F5** | if 任一臂体裁签名（FS 代理）与其余臂 KL 散度超阈且集中在抒情散文体 | then 体裁漂移，机制作废（用代理指标测，不靠肉眼） |
| **F9** | if 个体轴（δ_state）上升但集体轴（SC 下降 / 相似度上升） | then "以个性换同质"，判为**负结果**（不只是"没效果"） |

### 11.4 判据的元规则

- **数据门 → 核心判据 → 外围判据** 的顺序不可调换；
- **核心判据三中至少一中即失败**；
- **α = 0.05 单侧**，**不做**事后多重比较放宽；报告 Holm 校正后的 p（若同时跑多个检验）；
- **负结果照记**：任何"未通过"必须写进结论，不得用旁证指标替换。

### 12.2 跑法

```bash
cd /workspace/第四组论证/experiment-design
```

### 13.3 引用来源（外部文献已证部分）

- **SWAY**：配对提示只翻转预设极性、内容不变 ⇒ 位移可归因于框架；反事实 CoT 有效。
- **ESFP (arXiv:2607.12739)**："Vocabulary is not stance."；δAR 与 δSCD 在 P0 处解离。
- **PNAS 1912 人预注册实验**：叙事框架即可偏移读者立场；撬动的是叙事形式而非内容。
- **Stiff & Johansson 2024 (doi 10.1038/s41598-024-76900-1)**：来源标签一改 14 维中 13 维全变 ⇒ 人类偏好分不得当效标。
- **promptlabster 汇总 24 项**：role 改"怎么回答"不改"知道什么"；roles/incentives 只移动行为 0–2%；Digital Twin Prompting R² 0.10→0.50；persona 渗漏 69%。
- **Baas / De Dreu / Nijstad (102 效应量)**：创造力受"激活 + 动机方向"调节，不是受正负价调节。
- **Lerner & Keltner appraisal 理论**：情绪必须携带评价，否则只是标签。
- **Newell, Shaw & Simon (1983)**：条件性创造力四条件（放弃已接受的观念 / 强烈动机与坚持 ⇒ 状态须跨步骤持续 / 澄清模糊问题）。
- **McCarthy & Jarvis 2010**：MTLD 是唯一不随文本长度变化的多样性指标。
- **Alvarez-Gonzalez et al. (arXiv:2109.01900)**：文本情绪检测只能测"可从文本推断的情绪" ⇒ L1 原理性边界。
- **Doshi & Hauser, Science Advances 2024**：个体新颖性 +6.7% / 趣味性 +22%，但集体相似度高 5% ⇒ 双轴必报。
- ⚠️ **二手 arXiv ID（落地前须核验）**：arXiv:2510.01171（typicality bias）、arXiv:2602.16162（对齐后低熵区）、arXiv:2402.11782（ConflictingQA）。
