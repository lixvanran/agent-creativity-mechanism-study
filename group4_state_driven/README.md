# 第四组 · Agent 状态驱动（思想/情感驱动的产出）

> 本目录是 **Agent 创造力大项目 · 第四组** 的实验与论证。
> 第三组的实验台在仓库根目录 `creativity_lab/`；本目录是**独立的第四组链路**，
> 不改动第三组任何文件（借用即复制，见 `reports/`）。

## 这个组在回答什么

**让 Agent 的输出过程像人一样由思想/情感推动，而不是仅靠 LLM 基于概率检索。**

在四层研究结构中，本组对应**第 4 层：Agent 的状态驱动**——
由 Agent 的**内部状态**决定下一步行为（区别于层 3 的"跨轮自迭代"）。

| 层 | 状态怎么起作用 | 本组进展 |
|---|---|---|
| 层 1 | 搜索空间塌缩/过早闭合的**机制性解释**（transformer 注意力） | ⬜ 未碰（v4 的失败把问题推回这里） |
| 层 2 | **设计**手段（架构/提示/拓扑，运行时不自修改） | v3 已做：**状态→prompt 文本** ⇒ 失败（与层 2 同构） |
| 层 3 | **训练/自迭代**（系统根据经验修改自己） | ⬜ 未做 |
| **层 4** | **内部状态决定当下动作** | ★ **v4 已做：状态→候选集合→选择** ⇒ 失败，但失败位置精确 |

## 三条核心结论（v3 + v4）

1. **v3（状态进 prompt）**：状态机臂与档案全文注入臂的差异**未达显著**（McNemar p=0.0923）
   ⇒ 状态通过提示词传递 ⇒ **与层 2 机制同构**，不能作为"状态驱动"的证据。
2. **v4（状态进选择层）**：预注册判决臂（`WF-v4-blind`）里
   **状态化打分 vs 通用打分 9/9 完全打平**（gap 0.0）⇒ **H3 不成立**（n=9≥6，可判定地不成立）。
3. ★ **但失败位置很精确**：
   - **状态塑造候选有效**：候选符合状态率 0.0741（盲态）→ 0.6667（给缺口），**9 倍**；
   - **失效的是选择器读不出状态**。
   ⇒ ★★ **结构性两难**：状态**不进**候选 ⇒ 产出无状态指纹 ⇒ 打分无处发力；
   状态**进**候选 ⇒ 打分**接近恒真** ⇒ **"状态化选择"要么无效、要么恒真。**
   ⇒ 问题被**收敛到"状态必须在生成过程内部起作用"** ⇒ 指回**层 1**。

## 判据纪律（别绕过）

1. **检查器先证明自己能抓到东西**（自检 + 变异注入）；
2. **判据外置**，与被测模型同源时只能作交叉验证的一端；
3. **解析失败必须显式标记**，不得静默回退；
4. **分析单元 = 题**，不报显著性（题数太少）；
5. **预注册先于结果**；补充必须留痕并注明写入时点在结果前还是后；
6. ★ **任何读数先问：这个数能不能是恒真的？**
   （v4 第一版实验因此被**主动终止**：候选提示告知了打分依据 ⇒ 打分接近恒真）
7. ★ **按臂分组读数时先打 `n` 验范围**
   （v4 分析脚本曾把一个臂整个漏掉，差一步判决落在错的臂上）。
