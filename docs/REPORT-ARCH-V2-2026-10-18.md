## 2. 但测量告诉了我这个架构该长什么样

三条实测结论直接推出架构：

| 实测 | 推出的设计要求 |
|---|:-:|
| 矛盾率是唯一有方差的量（法律域 0.4% vs 政策域 33–71%） | **用矛盾率当仲裁器**，而不是别的 |
| 「选赢家」信号量≈0（Spearman +0.166，训练第1名→留出第15名） | **不能靠挑最好的那个** → 要靠「收集」 |
| 覆盖单调不减，argmax 无自由参数 | **不生成，只筛选** —— argmax 不过拟合，且候选越多越好 |

## 3. 架构 V2「核验在环」

```
① 生成 N 份候选（不同切入角度）           ← 思维面变宽
② 抽取全部断言，去重
③ 逐条对照依据核验 → 支持 / 矛盾 / 未提及   ← 唯一的外部锚
④ 组装最终答案：
     主体  = 只用被依据支持的断言
     未提及的 → 明确标注「依据未覆盖，仅供参考」
     矛盾的   → 剔除
⑤ 重新核验最终答案（闭环）
```

**关键性质**：
- 宽度 = 多个候选触及的**不同考虑**（含未核实的，作为「已探索但未证」清单）
- 错误 = 构造上被压到 0（最终答案只由被支持的断言组成）
- 单调：**候选越多 → 宽度越大，且不引入新错误**

## 5. 诚实的保留

1. **分母很小**（已核验 8–21 条）。留出的 100%/0% 建立在 8 条断言上。
2. **搜索题上 V2 没赢**（交付宽 2.60 < 2.80）。
3. **V2 的探索池宽反而低于 direct**（5.80 vs 9.60）——
   3 份候选的不同考虑比 1 份直调还少，说明我的「切入角度」提示让候选**收敛**了。
   这是个明确待修的设计缺陷：**角度设计不足以制造多样性。**
4. V2 **不是自主探索的产物**。它是我用测量结果反推的架构。
   自主探索的价值在于**证伪**（5 份提案全否，证明了提示词层的上限），不在于找到赢家。

## 6. 一句话

> **「拓展思维面」在提示词层买不到；在「生成后按证据筛选」这一层，买得到且不增错。**
>
> 自主探索的产出不是更好的架构，是**更好的架构该满足什么的规格**——
> 以及一条硬证据：**任何靠改提示词来扩宽思维面的方案，都必然同时扩大错误面。**

## 7. 下一步

1. **修 V2 的角度设计**（候选收敛 → 探索池宽低于单份直调）
2. **加第 4 个轴：机械组装**——最终答案**不由模型重写**，
   而是把「被支持的断言」直接拼装，「未提及的断言」另列一节标注。
   这样矛盾率**构造上为 0**，且交付宽 = |支持| + |未提及|（真正的并集）。
3. **扩题到 20+、重复到 5**，把分母从 8–21 提到 100+
4. **用户的四道题作为最终外部测试**（模型不饱和类型，正好是 V2 该发挥的地方）
