### 0.2 清单里需要更正的三处

**错误 1（最严重）：MACE 的标题和结论被写反了。**

清单写「MACE: Multi-Agent **Collaborative** Exploration / Agent 如何避免 groupthink、premature agreement」。

论文实际是 **《Multi-Agent LLMs *Fail* to Explore Each Other》**（arXiv 2607.11250, 2026-07-13, Choi / Li / Li / Wang / Li, UW-Madison）。它的**标题结论是否定式的**：现代 LLM agent 彼此**探索失败**，表现出「myopic and polarized interaction patterns」。MACE 的全称是 **Multi-Agent Contextual Exploration**，机制是**结构化的同伴选择（structured peer selection）**，不是提示词层面的多样性。

⚠️ 这条对你有利：它是**证明「多 agent ≠ 多样性」的正面证据**，而不是要你去解决的同类方法。

## 第 1 部分 · 这 13 份资料合起来其实在说同一件事

我把它们按「机制」而不是按「你列的类别」重排，**它们拼出的是一个完整的两因素理论**：

### 1.1 核心论文：A5（arXiv 2602.20408, Deng / Brucks / Toubia, 2026-02）

这是整批资料里**唯一给出理论框架**的一篇，也是你应该站在上面的那块地基。

它指出 LLM 想法多样性崩塌有**两个独立机制**：

```
机制一（个体层）：fixation 固着
  人类和 LLM 都会「前面说了什么，后面就被它锚住」
  → 解药：CoT 提示能减少 fixation（注意：只对 LLM 有效，对人类无效）

机制二（群体层）：缺乏知识分区 knowledge partitioning
  人类群体天然「各占一块知识区域」
  LLM 把所有知识聚合成一个统一分布 → 没有分区
  → 解药：普通 persona（如「一个从俄亥俄来的 34 岁 John」）
          比精心设计的专家 persona（如「乔布斯」）
          更能改善分区
```

**关键发现**：两种干预**各自独立**作用于不同机制，**合起来产生最高的想法多样性，超过了人类。**

> 论文原句：*"ordinary personas (versus "creative entrepreneurs" such as Steve Jobs) improve knowledge partitioning by serving as diverse sampling cues, anchoring generation in distinct regions of the semantic space."*

### 1.2 这解释了我实测到的所有现象

| 我实测到的 | A5 的解释 |
|---|---|
| 32 次采样的两两相似度中位 0.722，扩不出真正的多样性 | 机制二：同模型多次采样**只是从同一分布再抽一次**，没有知识分区 |
| 单链里"列出 5 个备选"会互相靠拢 | 机制一：fixation |
| 认知框架（vantage）比普通 persona 效果不确定 | A5 说 persona 改善分区是因为**"采样线索"**作用；vantage prompt 未必产生同等强度的语义锚点 |

### 1.3 其余 12 份各自填一块

| 资料 | 填的那块 | 关键内容（已核原文） |
|---|---|---|
| **ACL Diversity Collapse** | 为什么多 agent 没用 | 三层实证：**模型层**——更强更对齐的模型边际多样性递减（compute efficiency paradox）；**认知层**——权威主导的群体比新人主导的语义多样性更低；**系统层**——群体规模边际收益递减，**密集通信拓扑加速过早收敛**。结论：坍塌源于**交互结构**，不是模型能力不足 |

| **POET** | 问题与解**同时**生成 | 成对生成环境挑战与解，早期解成为晚期更难挑战的垫脚石 |
| **ToT** | 树搜索 | 局限：分支**共享一个上下文**；分支驱动是**下一步变化**（试数字 2/3）→ 产生**邻近想法而非结构不同的想法**；生成器与评估器交织在同一次调用里 |
| **GoT** | 图而非树 | 任意图结构，thought 可**组合、聚合、反馈增强** |
| **Self-Discover** | LLM 自选推理结构 | 从原子推理模块（批判性思维、逐步思考等）自组成显式推理结构 |
| **Voyager** | 开放式 agent | 三件套：自动课程（最大化探索）、**不断增长的可执行代码技能库**、带环境反馈/执行错误/自我验证的迭代提示 |
| **Generative Agents** | 记忆与行为涌现 | 完整记录流 + 反思 + 计划 |

## 第 2 部分 · 由此推出的架构

### 2.1 核心改造：从「一维发散」到「二维发散」

现有方案（包括 ADHD 项目）**只处理机制一**：

```
问题 ──▶ N 个隔离分支（不同认知框架）──▶ critic 收敛
         ↑ 处理 fixation
         ✗ 完全没处理知识分区
```

**改造后的架构**：

```
                    ┌───────────── 双轴发散 ─────────────┐
                    │                                   │
              轴 A：VARIANCE（变体）              轴 B：PARTITION（分区）
              治 fixation                          治 knowledge partitioning
                    │                                   │
        N 个隔离上下文 × 同一模型              M 个**不同知识源**的采样
        （不同认知框架/vantage）                （不同模型 / 不同 persona / 不同检索源）
                    │                                   │
                    └────────────┬──────────────────────┘
                                 ↓
                    【归档层 Archive】← 借 MAP-Elites
              维护一个「问题框架 × 解法」的精英档案，不是只留最优
                                 ↓
                    【收敛层】← 必须**后置**
              先做深度验证（问"它最不寻常处 + 什么条件下成立"），
              而不是先问"它合不合常识"
                                 ↓
                    【反证检查】← 借 Novelty Search 的 deception 意识
              目标函数本身会把搜索误导到死胡同 → 显式问
              "我的目标函数是什么？它会把我引到哪里去？"
```

### 2.2 三个具体设计决定

**决定 1：Vantage prompt 换成/补充 ordinary persona**

依据 A5：persona 改善分区靠的是**作为「多样采样线索」把生成锚定在语义空间的不同区域**，而**普通 persona 优于精心设计的专家 persona**。

ADHD 项目把 frame 定义为「vantage operator 而非 credential」并明确说「frames 不是 personas」（issue #17 已承认两者被混为一谈）。但 A5 的实证指向相反：普通属性 persona 效果更好。

**做法**：每个分支同时给 (a) 一个普通属性 persona（年龄/地域/职业具体化）+ (b) 一个认知框架。**这正好也是我上一轮实测里 A5 缺的那块。**

**决定 2：分区轴必须用真异质源，不能用同模型多次采样**

三重独立证据：
- A5：LLM 把知识聚合成统一分布，**没有知识分区**
- ACL 2026：密集通信拓扑加速过早收敛
- Science Advances「Wisdom of the Silicon Crowd」：**模型多样性 > 随机多样性**（不同架构优于同模型多次采样）

**做法**：分区轴的 M 个采样点来自**不同厂商的模型**（本项目已具备 MiniMax，可再接 1–2 家），或至少是**结构上真正不同的解码配置**（不同 system prompt 家族 + 不同温度区间 + 不同检索源）。

**决定 3：收敛层必须后置，且问「差异+成立条件」而不是「合不合理」**

ADHD 项目 6 道工程题里输掉的那一道，judge 的原话是：

> *"B [ADHD] explores vastly more creative territory and expertly identifies traps, but A [baseline] delivers a pragmatic, immediately implementable solution that an engineer can ship today."*
> —— 输在 `builder_usefulness`，因为「丰富的堆比磨光的单答案更好」只在**单答案本身是错的**时成立。

**做法**：收敛层的判据换成三问：
1. 它与常规做法最不同的地方是什么？
2. 它在什么条件下成立？（不是「合不合理」）
3. 它的**承重风险**是什么？

这三问正是 ADHD 项目的 deepen 提示词里已有的，可以直接复用——但**要把顺序从「评分→聚类→深化」改成「存疑标注→深度验证→评分→聚类→深化」**。

### 2.3 明确不做的两件事

**不做 1：不做「模拟 ADHD 症状」。** A5 和 Hoogman 2020 都不支持「ADHD 人更有创造力」这个前提；Hoogman 的结论更精确——发散升高**只在亚临床组**，临床组没有。ADHD 在这里只能作为**认知机制的存在性证明**（异常显著性、远联想、探索偏置这些现象真实存在），不能作为能力来源。

**不做 2：不做无人类基线的评测。** 下一节说明为什么这条是生死线。

## 第 3 部分 · 反证：必须正面处理的死结

### 3.1 已有实验直接否定了「LLM 帮人类重构问题」

**Shin, Polyanskaya, Lucero, Oulasvirta (2025)，arXiv 2503.01631，《No Evidence for LLMs Being Useful in Problem Reframing》**（ADHD 项目 issue #16 称之为 CHI 2025 反证）：

- N = 280 名设计专业人员，三种用法对照：free-form / 直接生成 / 有理论支撑的结构化方法
- **使用 LLM 没有提升问题框架的质量**
- **反而扩大了专家与新手的能力差距**
- 新手在使用 LLM 时**感知到更低的能动性（agency）**

**这条对你的项目是致命的，如果你的评估仍以「人类用 LLM 重构问题后变好」为终点。**

### 3.2 你手上的实验恰好是它没做的

那条研究测的是「人 + LLM」这条链路的**人类侧产出**。它**没有**测：

- 纯 Agent 系统内部的问题空间是否真的被扩张了
- 扩张后的空间里是否真出现了基线分布外的解
- 这些解在**没有人类筛选**时是否可用

**这正好是你的位置。** 你的评估终点不应该是「人类满意度」，而应该是**可测的分布指标**。

### 3.3 你已经跑出来的数据为什么重要

我实测的 3×2×2 网格（n=72 配对单元）恰好构成一个可发表的证据链，而且结论是**否定的**：

- 11 个机制/架构组合，**没有一个**在四个预设条件上达标
- 最强组合是 **A0（零机制基线）** 和 **N1（负对照）**，各满足 1 条
- 32 次采样两两相似度中位 **0.722** —— 直接实证 A5 的「无知识分区」
- 更高的 `temperature` 在分布已坍塌时**毫无作用**（DIVERGE 论文的结论）
- 我犯的 τ 阈值标定错误（0.90 永不触发 / 0.72 砍到只剩 2 个候选）本身也是一个可发表的负面发现：**多样性参数没有稳健的甜点**

**这组数据不是失败，是护城河的前半段。** 负面结果 + 可复现代码，比一个跑不通的「能用了」有价值得多。

## 第 4 部分 · 你的差异化位置

### 4.1 已被占据的地盘

| 地盘 | 占领者 | 你的进入成本 |
|---|---|---|
| 「多分支发散 + critic」 | ADHD 项目（★4412, MIT, preprint, npm 包） | 极高，别碰 |

| 「人类在环用 LLM 重构问题」 | Yagil/Shin et al. 给出否定证据 | 别正面顶，见 4.3 |

### 4.2 没人占的三块

**A. 双轴架构（fixation × knowledge partitioning 的联合干预）**

A5 说两种机制**各自独立**、**合起来最好**。目前**没有人把这两条合成一个架构**。ADHD 只做了左边半边，Multi-agent 辩论只做了右半半边（而且做坏了）。

**B. MAP-Elites 式的「问题空间档案」**

全部 13 份资料里，**只有 MAP-Elites 一篇谈「不要返回单点、返回地图」**。但它从没被用到 LLM 的**问题空间**上——它管理的是**解空间**。而你需要的正是：

```
Elites 档案的键：从「解的行为特征」
              改成「问题框架 × 解法」的二维格子
```
这是一个干净的、可形式化的、目前没人做的迁移。

**C. K 的量级缺口**

ADHD issue #18 自己承认：CreativeDC 报告的新颖性提升是 **K=100 平行采样**量级下测的，而它的评测是 **K=5**。K=5 与 K=100 之间隔着一整个数量级，**没有任何人补上**。

（我实测的 16–32 次采样两两相似度中位 0.722，就是这个 K 缺口的直接后果：样本数上去了，分区度没上去。）

### 4.3 论文该怎么定位（诚实版）

不要写「ADHD-inspired 提升 Agent 创造力」。写：

> **「两种坍缩机制，两种解药，一次联合干预」**
>
> 已有工作把 Agent 的发散不足归因于**单条链上的固着**（fixation），并用隔离分支解决它。
> 但 LLM 想法多样性的崩塌还有**第二个独立机制**：LLM 把知识聚合成统一分布，**不具备人类的知识分区**。
> 隔离分支**治不了**这个——N 个隔离的同模型采样仍然来自同一个统一分布。
> 我们提出双轴发散架构，并给出可测的证据：在 K=5–100 的整个量级上，
> **同模型多次采样的边际多样性趋近于零，而跨知识源采样才产生真实分区。**

这个定位的好处：
- **不与任何人正面冲突**（ADHD 项目占的是单轴，你占双轴）
- **直接接在 A5 的理论上**（A5 说了两机制独立且联合最好，但没做）
- **我的实测数据就是它的第一篇证据**（0.722 相似度 + 11 组合全灭）
- **反证不再是威胁而是弹药**（Shin et al. 否定的是人类侧，你测的是系统侧，且你能解释为什么两者会不同）

### 阶段 0（0.5 天）：把地基补齐

### 阶段 1（2 天）：把已有数据变成证据
我已跑完的 n=72 网格直接复用，补三件事：
1. **测量 K 曲线**：K ∈ {1, 5, 8, 16, 32, 64} × {同模型 / 同模型+异 persona / 跨模型}，指标 = 批内两两相似度中位数与分位数。**这条直接回答 K 缺口**
2. **测分区度**：定义「知识分区」的可测代理——各候选在高维语义空间的**占据体积**（而非仅两两距离），区分「一个中心附近的小云团」与「真的分成了几块」
3. **修正 τ 标定**：把我犯的阈值错误变成正式的**敏感性分析**（负面结果也要发表）

### 阶段 2（3 天）：建双轴原型
- 轴 A：复用 ADHD 的隔离分支，但**换成 ordinary persona**（依据 A5）
- 轴 B：跨知识源采样（MiniMax + 至少 1 家其他）
- 归档层：先做二维格子（问题框架 × 解法）的朴素版本，不上 MAP-Elites 全套
- 收敛层：后置 + 三问判据

### 阶段 3（待定）：评估设计
**这是最关键的一步，也是最容易做错的一步。** 三条铁律：
1. **不以人类满意度为终点**（Shin et al. 已证伪这条路）
2. **必须有「问题空间是否真的扩张了」的直接度量**，不能只测解的质量
3. **必须有 K 的扫描**，否则跑不过 issue #18
