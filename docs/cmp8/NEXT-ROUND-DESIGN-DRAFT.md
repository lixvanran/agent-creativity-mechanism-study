## 2. 诊断集（GPT6 最有价值的一条，我完全采纳）

**目的**：把「**真的在拓展思维面**」和「**在制造表面新颖性**」分开。

| 类型 | 构造 | 测什么 |
|---|---|---|
| **孪生任务** | 同一题**只改一个条件**（"若 X 条件改变"）⇒ 合理判断**应该变** | 策略能否**察觉条件变化并改变探索方向** |
| **只改措辞的负对照** | 同一结论，**换措辞/换表述**（不换信息）⇒ 合理判断**不该变** | 策略是不是**把表面新颖当发现**（假阳性） |
| **占位对照** | 用无关但**结构相似**的内容替换 | 增益不是靠"看起来不一样"骗来的 |

⇒ **判据**：在孪生对上**维度应变化**，在负对照上**维度应不变**。
⇒ **一个只在负对照上"有增益"的策略 ⇒ 判定为制造表面新颖**。

**⚠️ 本轮的 4 道题完全区分不了这两者**（每题只有一种条件、且依据包与题目同源）⇒ 这是下一轮**必须补**的。

## 3. 维度卡片（中间产物，不再用整篇答案当单位）

每张卡片至少记：

| 字段 | 说明 |
|---|---|
| 维度主张 | 一条可独立判定的陈述 |
| **原题映射** | 它回答的是原题的哪个部分（**必须能映射回去，否则剔除**） |
| **适用条件** | 在什么条件下成立（孪生任务的抓手） |
| **决策含义** | 它会改变哪个判断/行动 |
| 证据类别 | 事实 / 推论 / 价值判断 / 建议（**分层，不压成可检索事实断言**） |
| 核验状态 + 来源 | 依据包哪一条 / 模型 / 操作 / 轮次 / 提示版本 |
| **与已有卡片的关系** | 重复 / 细化 / 矛盾 / **互补** / 条件依赖 |

⇒ **"与已有卡片的关系"这一列就是"互补性"的可审计表示** —— 本项目完全没有这个东西。

## 4. 互补性用交互增益量化（不是单步边际）

```
I(A, B) = D(A ∪ B) − D(A) − D(B) + D(∅)
```

⇒ **判据**：`I > 0` ⇒ 组合有交互；`I ≈ 0` ⇒ 冗余。
⇒ **保留单位 = "依赖组"**（一组互相有交互的卡片），**不是单条卡片**。
⇒ ⚠️ **本项目的直接对应物**：⑤a/⑤c 反复 `GEN_PLAIN` 产出的是**同一段话** ⇒ 它的互补增益 **= 0**；
而 `EXTRACT`/`SPLIT` 路径产出的是**多条不同的断言** ⇒ 互补增益可能 > 0
⇒ **这才是"思维面变广"该测的量**，而 `n_raw` / `width` 都测不到。

## 5. 信息路由（本项目完全没碰的一维）

GPT6 的三分支原型：

| 分支 | 读什么 | 目的 |
|---|---|---|
| **独立发现** | 只读原题 + 共同证据，**不读基线答案或其他分支草稿** | 避免共同锚定 |
| **缺口干预** | 读原题 + 记录的"未覆盖缺口"，**不读整篇已有答案** | 针对一个条件/目标/尺度做干预 |
| **关系重组** | 读**挑出来的维度卡片** | 找交互、冲突、反馈、条件依赖 |

⇒ **信息可见性是设计变量**，三个模式等预算对比：**全共享 / 固定隔离 / 学习调度**。
⇒ ⚠️ **本项目的 A5 是"单一工作流 + 可选 VERIFY"** ⇒ **从来没测过"分支隔离/信息路由"这一维**。
⇒ 而"搜索空间不过早闭合"**一半的机制就在这里**（共享上下文 = 提前闭合）。

## 7. 成本闸门（本轮已验证有效，保留）

- 判官 **temperature = 0** ⇒ 矛盾率是**确定量**（本轮教训：temp=1.0 时自检"一次 4/4、一次 2/5"）
- 判官自检要**可复现**（连跑 2 次一致），**单次通过不算闸门**
- **遍2 复用遍1 的判官结果**（`judge_cache.json`）⇒ 判官只付一遍
- 失败路径**必须能被计数**（`parsefail_rate` / `samples.valid/total`），**不许静默归零**
- 闸门型自检要先在**坏仪器**上验过（变异注入）
