## 1. 负责人的人肉标准（**逐字照抄，不许解释、不许扩展**）

> 「提到港校 +0.5，提到香港城大、香港理工这两所学校的具体名字再 +0.5」

⇒ 打分规则（**事前定死**）：

| 命中 | 加分 |
|---|---|
| 出现「港校」二字 | **+0.5** |
| 出现「香港城大」**或**「城市理工（大学）」（指 CityU） | **+0.5** |
| 出现「香港理工」**或**「香港理工大学」 | **+0.5** |
| **满分** | **1.0** |

⚠️ **跑批前修订（2026-10-21 06:52，第一次调用之前）**：原措辞「港校 +0.5，两个具体校名再 +0.5」
有两种读法。**主口径取「分级」**：泛指「港校」= 0.5；**点名列名（任一或两所都算）= 1.0**。
同时**并算**「每校名各 +0.5」的变体 ⇒ 二者**只在「两个校名都点、但没提港校」这一种情形下不同**，
其余完全一致 ⇒ 两种读法都报，不影响结论稳健性。

- 实现方式：**纯字符串匹配**（无模型、无判断）⇒ 确定性、可复现、零歧义。
- 匹配范围：**最终交付答案全文**（机械装配后的答案），**不含**中间过程/日志/元数据。
- 大小写与全半角：**不做归一化**（中文语境无此需要）；「港校」按**子串**匹配。

## 4. ★ 事前预测（**跑之前写死，看结果后不许改**）

### P-1 ★★ 关键预测：两套测量**测的不是同一个量**，且**方向预期相反**

**依据**：U1 的依据包（16 条原子事实、30 个来源）**全部覆盖湖北本地**（武大/华科/武理工/武科大）
+ 分数/位次/选科/转专业/双学位规则；**整个依据包里没有一个「港」字**。

⇒ **负责人的人肉标准衡量的是「答案有没有提到依据包【不支持】的学校」**；
⇒ **本项目的流水线衡量的是「答案提供了多少条能被依据包核验、且改变决策的承重维度」**。

⇒ **预测**：
- **人肉标准**在**提及港校的臂**上高分、其余臂低分（**离散、区分度极高**）
- **流水线**在**所有臂上给出相近的有效维度数**（因为依据包覆盖的是湖北本地 + 规则类事实，
  各臂只要提到这些就能过承重检验）⇒ **区分度低**
- ⇒ **两套测量的秩相关可能很低甚至为负**

⚠️ **这个"低相关"不是流水线的缺陷，是两把尺子本就不量同一个东西的必然结果。**

### P-2
流水线的**净维度增益**主要来自这些**依据包覆盖**的维度：
分数位次（EV-01/02/03）、选科门槛（EV-04/05/06）、AI 专业格局（EV-07/08）、
三校硬指标与投档线（EV-09…EV-13）、强基/转专业/双学位路径（EV-14/15/16）。

### P-3
**若某臂提到港校/香港城大/香港理工**，那些提及**不可能**通过承重检验
（依据包不支持 ⇒ 无法核验为「支持」）⇒ **它们不会进入「经核验成立」节**
⇒ **流水线的有效维度数不会因为提到港校而增加**（那部分只能进「未经核验」节）。

### P-4
**两套测量的秩相关高** ⇒ 则 P-1 错（说明它们其实在量同一个东西）⇒ **本预测被否证**。
