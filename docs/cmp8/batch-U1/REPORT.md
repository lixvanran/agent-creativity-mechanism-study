## 2. 为什么"差距测不出来" —— 三个原因，逐个查清

### 2.1 人肉标准恒为 0（零方差 ⇒ ρ = n/a）

12 份答案（含所有中间产物）**零命中**「港校 / 香港城大 / 香港理工」。

**我先前的判断要修正**：我原以为"工作流臂受依据包约束 ⇒ 不可能提到港校"。
**不对** —— 直调基线 B0 rep2 产出了 5 所**依据包外**的高校（浙大、上交、北航、哈工大、华科），
它们被装进「**依据未覆盖、仅供参考的事项**」节。⇒ **依据包外的内容在设计上是允许出现的**，
只要模型自己想到了。**港校没出现是 grok-4.3 在这个题上没往那个方向想**，不是设计禁止。

⇒ **结论**：人肉标准在设计上**可以**命中；本批没命中 ⇒ **测不出差距**。

### 2.2 我的流水线的维度数压到地板（0 或 1）

12 份里 **9 份 D=0**。原因：**承重检验很严** ——
"写不出它改变了哪个决策/结论 ⇒ 不算维度"，且必须**指向 `C_t` 里某条具体结论**。
直调基线那些"浙大是 CS/AI 强校"式陈述**确实不改变任何结论**（依据包没有浙大）⇒ 被判不承重 ✔ 合理。

⇒ 代价：**在这个题上，流水线的区分度极低**，净增益基本由个别几份撑着。

### 2.3 ★ 测量**跨版本不稳定**（必须先解决）

同一批 12 份答案，两次测量：

| 测量版本 | 判官提示 | 承重数分布 | parsefail 最高 | A_fixed 净增益 |
|---|---|---|---|---|
| v1 | 依据 + `C_t` **各传一份**（3771 字符） | 0–3 | **1.000（R2 触发）** | 0 / +1 / −1 |
| v2 | 依据与 `C_t` **合并成一份**（同一批事实，编号即结论编号） | 0–3 | **0.000** | +1 / +4 / 0 |

⇒ **同一批答案、同一判官模型，换个提示词版本 ⇒ 承重数分布就变** ⇒ **跨版本读数不可比**。

## 3. ★ 一个闸门按设计抓到了真问题（这本身是正面的证据）

**v1 触发了 R2（parsefail_rate 最高 1.000）** ⇒ 我去查，发现：

```
max_tokens=12000  finish_reason=length  content_len=0
prompt_tokens=2222  completion_tokens=12000
```

⇒ **MiniMax-M3.1-Flash-Preview 把 12000 个 token 全部花在思考块上，正文一个字都没输出。**
⇒ 根因之一：**我把依据包传了两遍**（`C_t` 就是那 16 条事实本身）⇒ 提示词 3771 字符 ⇒ 触发长思考。
⇒ 修法：合并成一份 + 预算阶梯 + 批大小 6→4 ⇒ parsefail 归零。

⇒ ★ **这条是"闸门有效"的直接证据**：如果协议里没有 `parsefail_rate` 这个必报项，
这 2 份答案会**静默地以 D=0 计入**，看起来像"这两臂没有有效维度"，**而真相是判官崩了**。

## 4. 两套测量到底在量什么（这才是"差距"的本质）

| | 人肉标准 | 我的流水线 |
|---|---|---|
| 量什么 | **是否点名了港校**（一个特异内容检查） | 有多少条**能被依据包核验、且改变决策**的承重维度 |
| 粒度 | 0 / 0.5 / 1.0（3 档） | 整数维度数（可到 0–4） |
| 判据来源 | 负责人的先验 | 依据包 + `C_t` + 承重判据 |
| 会不会罚"提了港校" | **会加分** | **不会加分**（依据包不支持 ⇒ 不可能通过承重检验） |

⇒ **即使人肉标准有命中，两者的秩相关也很可能低** ⇒ **低相关不代表流水线错**，
只说明**它们不是同一个量**。

⇒ ★ 而且方向上它们是**可能相反**的：
**人肉标准奖励"提到依据包外的内容"，而流水线的承重检验要求"内容能被依据包支持"。**
⇒ 这是**测量目标本身的张力**，不是实现 bug。

## 7. 本批的三个结论（都可核对）

1. **人肉标准与流水线在本批不可比** —— 不是因为流水线差，是因为**人肉标准没有命中任何一份答案**，
   且它测的是"是否点名港校"这个**特定内容**，而流水线测的是"承重维度数"。
   ⇒ **要比较它们，先得让答案里有港校可提。**
2. **管线的 R2 闸门抓到了一个会让结论失真的真问题**（判官把预算花在思考块上、正文为空）。
   ⇒ **闸门有效。** 这也是本批最值得保留的机制。
3. **测量跨提示词版本不稳定** ⇒ **任何"维度数"读数都必须带测量版本号 + parsefail + 跨版本复现**，
   否则数字不可引用。
