# 五族对比实验 · 设计 v2（EXPERIMENT-v2）

> 实验代号 **cmp8**。被测模型走 MiniMax 订阅，判官走 OpenRouter 上的**跨厂商模型**（DeepSeek / Grok / Qwen 等，非 MiniMax）。
> 本文档是**重建版**的设计说明（见 `_CMP8_RECOVERY.md` 与 `README.md` 第 5 条）。

---

## 0. 这套实验在问什么

**问题**：Agent 的"创造力"到底来自哪里？把五种主流做法放进同一批**外部真实题**上，
用**跨厂商判官**统一打分，看哪种机制真的让答案更"多、且不互相打架"。

**为什么要有 7 个臂而不是 3 个**：本项目反复踩过一个坑 ——
**只看主实验臂，无法区分"机制有效"和"多花了调用 / 接触了 oracle"**。
所以 A5a / A5c 是**控制臂**，专门把这两件事拆开。

## 1. 题（外部测试集，4 道）

| id | 题 | 域 |
|---|---|---|
| A1 | 湖北考生，物理类 620 分，想学 AI，应如何选择大学？ | 选校 / 规划（含硬数字、分数线、位次） |
| A2 | 公路自行车个人赛（无车队），单圈 1.6km 共 15 圈，本人大集团中上，如何安排战术？ | 运动战术（含 UCI 规则、器材规定、生理数据） |
| A3 | 五一长假最后一天 18:00，明天要上学，作业一笔没动，怎么办？ | 时间管理 / 记忆 / 睡眠（方法学事实） |
| A4 | 解读一份陈会昌气质量表得分：胆汁质-6，多血质 23，粘液质-4，抑郁质-1 | 量表判读（判定规则与阈值） |

**共同点**：全部是**用户自己的真实问题**，不是学术基准题。
**依据包**（`creativity_lab/data/user4_q{1..4}.json` 的 `evidence` 字段）
是**联网独立构造**的原子事实集 —— 只收可核验事实，**不收建议/结论**，
拿不准的一条都不写（假矛盾会污染矛盾率）。**依据包全程不参与训练**。

**题面的单一真相源**：`armdeps/topics4.py`（`TOPICS4`）。
`run_compare5.py` 优先从它读题；读不到时回退到自己内联的那份副本（两份内容一致）。

## 2. 七个臂

| 臂 | 是什么 | 调用数 | 作用 |
|---|---|:-:|---|
| **A1** | 直调 LLM（单次） | 1 | 基线：没有机制时是什么样 |
| **A2** | 开源 ADHD 项目（**机制复现**） | 11–12 | 外部项目对照 |
| **A3** | 双轴 · **融合门**（5 分支 → 前提审查 → 反诘 → 融合重写） | 8 | 旧架构 |
| **A4** | 双轴 · **去融合门**（5 分分支各写完整答复 → 只选不融） | 6 | 旧架构最强版 |
| **A5a** | 新架构 · **无核验**（只 GEN/EXTRACT/SPLIT，机械装配） | ~12 | **控制**：隔离"有没有 oracle" |
| **A5b** | 新架构 · **学到的策略**（有核验） | ~14 | **主实验** |
| **A5c** | 新架构 · **初始策略 w=0**（有核验） | ~14 | **控制**：学到的权重有没有用 |

### 2.1 两个控制臂为什么必须有

- **A5a 隔离"oracle"**：A5b 唯一接触 oracle 的操作是 VERIFY（拿依据包去核验断言）。
  如果只报 A5b，分不清效果来自"多一步核验"还是来自"可学习的架构"，
  **也可能只是多花了 2 次调用**。A5a 去掉核验、步数对齐 ⇒ 隔离这一项。
- **A5c 隔离"学到的权重"**：A5b 用 `runs/arch_learn/result.json` 里学到的 14 维策略权重选操作；
  A5c 把权重置零 ⇒ 如果 A5b ≈ A5c，说明**权重没学到东西**（或学到的没被用上）。

### 2.2 新旧架构的可比性

新架构的**认知位置**（FRAME / PERSONA / 模型轮换）与 A3/A4 **逐条一致**，
只有"架构部分"不同。**否则测的就不是架构，是别的东西。**

### 2.3 A2 是复刻，不是原版

A2 照搬 `src/engine.ts`（reframe → 5 帧 × 6 想法 → score+cluster → deepen top3 = 11 次调用）、
`src/packs/core.ts` 的 15 个认知帧、`src/render.ts` 的输出形状，**只换传输层**
（原版走 claude-agent-sdk，实验当天**彻底挂死**：`Claude Code process exited with code 1`）。
**已知差异**：原版用 `systemPrompt:{preset:"claude_code"}` 会叠加 Claude Code 自己的系统提示，
复刻版只注入项目自己的 system prompt。
`ADH_MODE=node` 入口保留着，通道恢复后可直接跑原版（需 `ADH_REPO` 指向 node 仓库，默认 `/workspace/adhd-repo`，本包用不到）。

## 3. 判官：跨厂商，且必须先自检

- **被测 = MiniMax，判官 = OpenRouter 上的非 MiniMax 模型**
  （默认 `deepseek/deepseek-chat`；fallback `x-ai/grok-4.3` → `qwen/qwen3.7-plus` →
  `meta-llama/llama-3.3-70b-instruct` → `z-ai/glm-4.5`）。
  理由：**判据与被测同源 ⇒ 判据不可信**（同厂模型容易对同一批错误达成一致）。
- ⚠️ **原设计的 `x-ai/grok-3-mini` 已于实验当天 404 下架**（xAI 建议改用 `grok-4.3`），
  `openai/text-embedding-3-small` 被供应商 ToS 拦（403）⇒ 默认值已换，详见 `README.md` 第 4 条。
- **自检先行**：判官先判一批**已知真断言**（应判"支持"）和**已知假断言**（应判"矛盾"）。
  **假断言召回 < 50% ⇒ 矛盾率不可信 ⇒ 整套拒绝出数**（是"拒绝出数"，不是"出完再解释"）。
- 四分类判定：`支持 / 矛盾 / 未提及 / 非主张`。
- **实测自检结果**：`deepseek/deepseek-chat` 与 `x-ai/grok-4.3` 各 **真断言 4/4 ｜ 假断言 4/4** ⇒ 闸门已过。

## 4. 指标口径

- **宽度（去重）**：单份答案去重后的断言数。
  ⚠️ 模型会在一份答案里把同一事实说 3–4 遍 ⇒ **任何按断言条数算的量都必须先去重**
  （embedding 去重阈值 0.75，**该阈值标定在 MiniMax `embo-01` 上**，
  换 embedding 模型则不可跨模型比较 ⇒ `analysis.json` 会记 `embed` 字段）。
- **并集宽度**：同臂 3 份去重后的并集 = 覆盖广度。
- **矛盾率** = 矛盾 /(支持+矛盾)。**唯一有方差、能当仲裁器的量。**
- **离散度**：3 份之间两两语义距离均值。
- **种子噪声地板**：同臂同题 3 次重复的逐份矛盾率标准差。
  分析器最后会打印它 ——
  **A5b 与 A5c 的差异若小于这个地板，就是噪声，不是效果。**

## 5. 跑法

```bash
export MINIMAX_SUBSCRIPTION_KEY=...
export OPENROUTER_API_KEY=...
export PRIMARY_MODEL=MiniMax-M3.1-Flash-Preview
export OR_PRIMARY=deepseek/deepseek-chat
export OR_EMBED=qwen/qwen3-embedding-8b
export CMP_OUT=runs/cmp8
export ADH_MODE=repro

python3 smoke_or.py          # 冒烟：不过就别往下跑
python3 run_compare5.py --arms A1,A2,A3,A4,A5a,A5b,A5c --reps 3 --workers 4
python3 analyze_cmp6.py
python3 build_compare5_page.py
```

**规模**：7 臂 × 4 题 × 3 重复 ≈ 700 次被测调用 + ~170 次判官调用。
**耗时**：1.5–2 小时。**成本**：被测走 MiniMax 订阅 = $0；判官 ≈ $0.12；embedding ≈ $0.05。**总计 < $1**。

**输出**（在 `$CMP_OUT` 下）：
`analysis.json`（全部指标）、`compare5_report.html`（**判读页**：原始答案 + 指标）、
`judge_selfcheck.json`（判官自检）、`runlog.jsonl`（每次调用的审计日志）。

## 6. 诚实边界

1. **臂 2 是机制复刻，不是原版本体**（见 §2.3）。
2. **模型集被固定为 5 个健康档位**（M3.1-Flash-Preview / M2.7 / M2.5 / M2.1 / M2），
   各臂完全一致 —— 因为 M3 当天整片返回 529 过载。
   ⚠️ 换模型会悄悄改掉"模型构成"这个变量，臂间对比就失效 ⇒ **429 只退避不换模型，529 才降级**。
3. **判官是跨厂商模型**（DeepSeek / Grok / Qwen / Llama / GLM），被测是 MiniMax；
   判官自检不过就拒绝出数；`analysis.json` 里 `judge_same_vendor=true` 就说明判官退到了同源（须在报告里声明）。
4. **用户的四道题是外部测试集**，全程未进训练；依据包由联网独立构造，不读任何已有答案。
5. **最终评分由人做。** 判读页给的是原始答案，指标只是辅助。
6. **本包为重建版**（源文件在 2026-10-20 沙箱重置后丢失），不是逐字节原版 ⇒ 结论用于方向性判断。
