图 1 · 有效信息维度的测量流水线

从答案到净维度增益。承重检验与去冗余检验是两道硬闸门；质量闸门不过就停该臂，不重跑到好看。

图 2 · 维度卡片的准入流水线

一条断言要成为"维度"，必须依次通过：证据类别分层 → 原题映射 → 承重检验 → 去冗余检验。

⚠️ U4 校准点：气质量表那题的有效维度可以很少（一条承重规则就够）， 但必须能推出结论。⇒ 「维度数」绝不能退化成「条数多」。

图 3 · 三条路线泳道对照

差别只在谁决定什么：A 全人定；B 全学；C 人定拓扑、训练调参数。三者共用同一层。

图 4 · 预注册 → 跑批 → 否证判定

指标只提供证据，决策由负责人拍板。"不显著"要记成「不可分辨」，不能记成"失败"，也不能记成"成功"。

三条路线一句话

路线谁决定架构能拿到什么最大风险怎么被否证
A 设计架构人（写死拓扑）稳定、可复现、归因清楚人的偏见无处收敛与等预算多次采样比，净维度增益不显著
B 训练架构训练（策略学出）能适应信息缺口样本少必过拟合；搜索空间可能闭死留出集不优于随机/固定；或只改了行为没改内容
C 先设计再训练人定拓扑 + 训练调参数A 的归因清楚 + B 的自适应性拓扑定错 ⇒ 参数再优也救不回来与 A/B 对比分离不出"拓扑"这一项的贡献
