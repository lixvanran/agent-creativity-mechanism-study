# 跨篇综合 · 这批文献对我们的项目意味着什么
> 2026-10-21 ｜ 配套：`LIT/` 下各篇收获 ｜ 我们的坐标：协议 `PROTOCOL.md`、路线 A/B/C、优化器契约 `OPTIMIZER-CONTRACT.md`

## 0. 一句话

> **这批文献没有给我们一个"更好的优化器"，而是把我们的问题重新定位了三层：**
> ① 我们缺的是**模块化的设计空间**，不是优化器（AgentSquare）；
> ② 就算有优化器，我们的**目标函数当前是欺骗性的**（SAFE 的 objective ≠ objective function），
>    所以**先修目标、再谈搜索**（这是 ADAS 成功的前提，也是它给我们的天花板参照）；
> ③ 而且**这个领域最容易被同一个统计坑吞掉**（best-of-N 单点读数、无重复、无置信区间），
>    **我们的 U1 批次已经实测踩到了它**（组内波动 > 组间差）。

## 一、★ 重新定位：我们缺的是**设计空间**，不是优化器

**AgentSquare（2410.06153）** 把 agent 设计写成**四模块元组** `A=(P,R,T,M)`，统一 IO 接口，
然后在**模块池**上做进化 + 重组 + 代理预测。

**映射到我们**（这是全批最可操作的一条）：

| AgentSquare 模块 | 我们的对应 | 我们现在有吗 |
|---|---|---|
| Planning | 拓扑选择（T0–T5）| ⚠️ 6 个，但**手写枚举，不是模块池** |
| Reasoning | 抽取 / 拆分 / 去冗余 / 条件重采样 | ✅ 路线 A、C 都有 |
| Tool Use | 依据包核验（唯一接触 oracle）| ✅ 都有 |
| Memory | 断言池 / 维度卡片库 / 结论空间 `C_t` | ⚠️ 有断言池，**没有跨臂共享的卡片库** |
| **（缺）** | **★ 承重检验层** | ⚠️ **在四模块框架里无处安放** |

⇒ ★ **两条推论**：
1. **A / B / C 三个手写的点 ≠ 一个可搜索的空间。** 先按统一 IO 接口拆模块，
   再把三条路线变成**模块池里的条目**，优化策略才有对象、消融才有结构保证。
2. **我们的"承重检验"这一层没有槽位。** 而它恰恰是我们的**差异化资产**
   （思维面 = 有效信息维度数 = 承重信息）。
   ⇒ ⇒ **必须显式加第五个模块 `E`（Evidence/承重）**：输入 = 候选断言 + `C_t`；
   输出 = 承重判定 + 支持的结论编号。**接口天然独立。**

⇒ **顺带白送的两条**：
- **统一 IO ⇒ 消融天然成立** ⇒ 我们的 L1（`Δ(component)`）不需要额外工程，**模块级替换就是消融**。
  AgentSquare 的 `w/o module evolution` 消融证明**模块级贡献可分离**是被同行接受的做法。
- **"人设计的 memory + 机器搜出来的 reasoning" 混合优越性** ⇒ **独立支持**我们路线 C 的核心命题。

## 二、★★ 我们问错了问题的一半：缺的不是优化器，是**不欺骗的目标函数**

**SAFE（Sipper et al. 2019, arXiv:2206.12707）** 的框架：
> **"conflating the objective with the objective function"** ——
> 目标可能明确良定义，但**目标函数可能具有欺骗性**。
> 他们的迷宫例子里，"离终点的距离"作为目标函数是欺骗性的：
> 更高的适应度 ≠ "快到了" ⇒ 标准 EA 失败（Figure 2）。

⇒ **我们的处境一字不差**：
- **目标**：思维面变宽（有效信息维度数变多）—— 明确、良定义。
- **目标函数**：净维度增益 = 工作流 − 直调 —— **欺骗性**：
  ① 它是**两个噪声测量之差**（噪声 = 两边之和）
  ② 实测：**跨判官提示词版本 ⇒ 净增益 0/+1/−1 → +1/+4/0**（带宽 > 信号）
  ③ 实测：**12 份里 9 份 `D=0`**（地板效应）

⇒ ⇒ **"补一个优化策略"这个任务本身可能是错的问法。**
按这一族的诊断，正统出路是 **别优化目标**：
**Novelty Search（放弃目标，用档案 + 行为距离）** → **Quality Diversity / MAP-Elites（行为空间格子，每格留最优）**
→ **POET（任务与求解器共演化）**。

⇒ ★ **ADAS（2408.08435）的成功恰恰依赖"目标函数干净"**：
它的目标是 ARC/GPQA/MGSM 的**任务正确率** —— 标量、可自动判定、重复测量几乎无噪声。
⇒ **它没有解决"目标函数不可信"，它假设目标函数可信。**
⇒ ⇒ **这是它对我们的真正价值：它是天花板参照，不是路线图。**
⇒ ★ **顺序由此确定**：**先把目标函数变可靠（契约 L0）→ 才轮到学架构（ADAS 式）**。

## 三、★★★ 最贵的一条横向发现：**这个领域最容易被同一个统计坑吞掉，而我们已经在坑里**

| 出处 | 读数 | 问题 |
|---|---|---|
| **AgentSquare** | 公开代码 `run_benchmark(agent, n=50)`；**未报告 seed 数、未报告重复次数、未报告置信区间** | **报的是 best-of-50 的单点读数** |
| **2608.04341** | 单 agent 提交 60–124 次 / 五 agent 274–550 次；**评审明指 "best-of-n 的最大值随 n 增大而偏高"** | 多跑 = 读数高，**与架构质量混在一起** |
| **我们的 U1 批次** | 同一 `w=0`、同一批题，两遍读数：**矛盾率 37.5% vs 25.0%**、核验 2.33 vs 3.00 次 | **组内波动 > 组间差** |

⇒ ⇒ **我们的实验恰好是这三种最容易被吞掉的**（多路线 × 多次重复 × 取最好）。

⇒ ★ **必须写进协议的四条**：
1. **重复次数 R 事前固定**（不由"跑够为止"决定），**跨臂一致**；
2. **主读数取中位数**；best-of-N 只作**上界参考**并单独标注；
3. **报噪声地板 δ**（同配置不同 seed 的波动），**增益必须 > δ 才算数**；
4. **跨臂对齐 R 与总调用预算** —— ⚠️ **我们协议 F6 目前只覆盖"生成预算"（B0/B1/B2），
   没覆盖"优化预算"（改了拓扑后要重跑参数学习）** ⇒ **这是我协议里的一个真实漏洞**。

⇒ ★ **还要补一条来自 2608.04341 评审的**：
**"no-seed control"是决定性对照** ⇒ 我们的映射是
**「拓扑的选择权归人，还是归搜索」** ⇒
⚠️ 这比我原先写的"与 A/B 对比分离出拓扑贡献"**更干净**，因为它**只变一个自由度**。

## 四、★ 地板效应的正解：**POET 的「最小准则」共演化任务**

我们实测 **9/12 份 `D=0`** ⇒ 现在的 DEV 题"太容易或测不出来"⇒ 没有"变好"的信号。

**POET（1901.01753）**：环境（任务）本身被演化，并按**最小准则**筛选保留 ——
> 保留那些**不太容易**（否则没有学习价值）**也不至于不可能**（否则没有可学信号）的环境。

⇒ ⇒ **映射到我们**：
**DEV 集不该是"随便造的 9 道题"，而该是按实测读数筛出来的题**：
- 一道题若 12 份答案 `D` 全为 0 ⇒ **太容易或测不出来** ⇒ 加难度或换判据；
- 若 `D` 恒定且 = 结论空间大小 ⇒ **饱和、无区分力** ⇒ 淘汰；
- **保留 `D` 分布跨臂有差异、且离 0 有距离的题**。

⇒ ★ ⇒ **这给 DEV-SPEC 加了一条"事后筛选"步骤** —— 我给三名构建者下的任务里**没有这一条**，
⇒ **这是我该补的洞**：DEV 集不是"造完就冻"，而是「**造 → 测 → 按最小准则筛 → 冻**」。
⚠️ 筛选必须用 DEV 自己的答案，**不能用 U1–U4**（TEST 集侧）。

## 五、★★ 新颖性判据要换载体：**用"操作序列"，不用"答案 embedding"**

**Novelty Search（Lehman & Stanley 2011）** 的新颖度不是对答案文本算的，
而是对**行为刻画（behavior characterization, BC）** 算的，且 BC 必须满足
**敏感性**（随行为变化）与**不冗余**（不同行为给不同 BC）。

⇒ ⇒ **我们恰好有现成的行为空间**：**操作序列**（GEN/EXTRACT/VERIFY/SPLIT/MERGE/STOP 序列 + 目标节点）。

⇒ ★★ **这一条顺手绕开我们已知的两个坑**：
- **embo-01 中文句级几何无分辨率**（实测：27 条断言被压成 1 条）⇒ **根本不用 embedding**；
- **措辞级相似度在改写型环节彻底失效**（keep-Jaccard = 0.000）⇒ **行为是结构性的，不是措辞性的**。

⇒ ★ **顺带解决了"三路线是否真的不同"**：
2608.04341 的机制刻意**只共享分数与摘要、不共享代码** ⇒ 我们 A/B/C 若共用同一套抽取器与装配模板，
"三种架构"的差异可能只是提示与参数 ⇒ **行为多样性是假的**。
⇒ ⇒ **用操作序列算三条路线的行为距离**：距离近 ⇒ "三路线"其实是一条。

## 六、★ 格式对称化：一个我们自己还没查到的污染通道

**组4 在源码里挖出**（ADHD 项目，作者自己没承认）：**判官读到的两份文本格式极不对称** ——
ADHD 输出带 `★`/`⚠`/分数 chip `[N8 V6 F7]`/分簇小标题，而 baseline 是一段散文
⇒ **judge 打分里混着"结构化程度"的分，与"思维面宽窄"无关。**

⇒ 加上我们 U1 批次测到的"**答案极短（30–194 字）⇒ 维度数触底**"，
⇒ ★★ **两件事指向同一个下一步**：
**跨路线比较前必须做一次「格式对称化」审计** ——
同一模板、同一字数上限、同一标题结构 ⇒ 否则判官读到的是**格式**不是**内容**。
⇒ 我们协议 §4.5 写了"机械答案 = 唯一评分对象"+"同一模板/同一字数上限"，
⇒ ★ **但路线 C 的装配模板与路线 A 不同** ⇒ **跨路线比较前必须专项审计这一条**。

⇒ ★ 还有一个同源事实（ADHD 源码）：**文档声称"帧选择可按种子复现"，代码用 `Math.random()`，没有 PRNG**
⇒ **不可复现** ⇒ 我们用它当基线时**不能声称可复现**；
⇒ 我们的 Python 复刻（`adhd_repro.py`）也继承了这个 ⇒ **必须如实标注**。

## 七、★ 一个可立刻用的新模块候选：ADHD 的 `trap` 字段

ADHD 的 `SCORE_SYSTEM` 要求 critic 为每个想法输出：
```
"trap": "if the idea looks attractive but has a hidden cost ... name it as a specific,
         actionable heads-up — e.g. 'solid for a prototype, breaks past 10k concurrent users'
         — not a dismissal like 'bad idea.'"
```
⇒ ★ **这是一个"带机制性理由的结构化字段"**：
离散 / 可归因 / 可计数 / **不依赖 embedding** / **不依赖措辞相似度** / **能被依据包核验**。

⇒ ⇒ **它是"第五模块 E（承重）"的一个现成实现候选**：
`trap` = "这个想法看着好，但会在哪崩" ⇒ 与我们的承重检验是**互补**的一对：
- **承重** = "它改变了哪个结论"（正面）
- **trap** = "它在什么条件下不成立"（负面）
⇒ ⇒ 两者合起来 = **一条信息真的被用上了**（既承重、又被限定了边界）。
⇒ ⇒ ★ 值得做成候选操作化指标，与"净维度增益"做**相关分析** ——
**若不相关，那是一次有价值的否证**（trap 数只反映"被否掉的诱惑"，不反映"被采纳的承重信息"）。

## 十、⚠️ 三条不要照抄的

1. **不要照抄"并行 agent 带来多样性"** —— 2608.04341 的评审明说这个核心结论**尚未被确立**
   （agent 数 ↔ 提交数 ↔ 算力 ↔ 共享可见性同时变化；作者自己的 Limitations 与"independent of agent count"自相矛盾）。
   ⇒ 拿它当"我们也要并行化三条路线"的理由**不成立**；拿它当"我们必须补等预算与 no-seed 对照"的理由**才对**。
2. **不要照抄"报 best-of-N 的最高分"** —— 两篇都这么干，而那正是我们 U1 批次踩中的坑。
3. **不要照抄"用 agent 自评当反馈信号"** —— 我们的判官与被测不同厂商已是底线；
   ADHD 自己的 5 个维度里**只有 `trap_detection` 大概率是真的**，其余 4 个
   （+4.17 / +5.17 / +3.00 / +0.83）在**同源判官 + 无重复**条件下**都不可信**（组4 的独立判断）。

## 十一、诚实交代：这批文献**没有**解决我们的哪几个问题

| 我们的难题 | 这批文献给了什么 | 够不够 |
|---|---|---|
| **目标函数带宽 > 信号** | ADAS 的前提是目标干净；没有任何一篇处理"目标函数本身不可信" | ❌ **不够** ⇒ 只能靠我们自己修 L0 |
| **地板效应（9/12 份 D=0）** | POET 的最小准则给了**方向** | ⚠️ **方向够，工具没有** ⇒ 我们要自己实现筛选 |
