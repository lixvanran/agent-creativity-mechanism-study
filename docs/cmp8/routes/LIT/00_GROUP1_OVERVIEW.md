## 一、最值得我们抄的 3 条

### 抄 1（结构）：AgentSquare 的「统一 IO 接口 + 可枚举模块池」
`A = (P, R, T, M)`，四个模块各有一个写死的调用签名，模块池规模 **6×7×5×5 = 1050**（我用官方 `modules/*.py` 的类名逐个核对过 = 论文的 1050 ✓）。
- **为什么值钱**：这是本批里**唯一**把"架构"变成**可枚举离散对象**的做法。我们的"思维面 = 有效信息维度数"如果只在自然语言层做，永远算不出维度；有了统一接口，维度才有结构载体（正对我们的坑 ③）。
- **配套抄这对算子**：`重组`（只允许替换模块、**不许改 IO**）+ `进化`（LLM 写新模块代码并入池）。
- **配套抄这条边界规则**（§3.6 原文）："新模块从未出现在经验池里，所以 evolution 阶段**永远真评**；只有 recombination 才可以用代理评估" ⇒ **"什么时候可以信便宜评估"有了可抄的规则**。
- **⚠️ 必须先修**：官方代码把 `tooluse != 'None'` 的 agent 全过滤掉了，6 个任务里 4 个的最优 agent 根本没装工具模块 ⇒ "4 模块"实为 3 模块。

### 抄 2（判据）：ADAS 的判据格式 + ToT 的两条离散判据
- **ADAS 的格式**（本批唯一判据比我们强的）：**val 搜索 / test 报告分离** + **95% bootstrap CI**（10 万次重采样，`utils.py:bootstrap_confidence_interval`）+ ★ **"CI 重叠的条目一律并列加粗"** —— 论文原话：*"we bold … **all entries whose median falls within the 95% confidence interval of the highest-performing treatment**"*。这等于把"不可分辨"写进排版规则里。
- **ToT 的两条离散判据**（`tasks/game24.py` / `methods/bfs.py`）：
  - `if len(y.split('\n')) == 4 and 'answer' not in y.lower(): return 0` ⇒ **结构不合规就排除**（不是给低分）
  - `if y in local_value_cache: value = 0` ⇒ **离散去重代替几何相似度**
  ⇒ 这两条**完全绕开 embedding**，直接解我们的坑 ②③。
- **配套抄**：ADAS 的**零准确率守卫 + debug 修复回路**（≤3 次）⇒ 把"评估崩溃"和"设计不好"分开计数；`n_repreat` 从 1 提到 ≥5。

### 抄 3（异源判官）：Re3 的训练判别式 reranker + ToT 的生成/评估交叉实验
- **Re3**（本批唯一在"选择/打分"环节做到异源的）：Coherence / Relevance Reranker 都是**微调过的判别式模型**（Longformer-Base + BART-Large-MNLI），**不是 LLM 自评**。⇒ 我们的"依据包核验器"应学它：**训练一个判别器判"这一段是否真的用上了这条依据"**，而不是问 LLM "你觉得用了吗"。
- **ToT 的交叉实验**是**检验方法**不是结果：把生成器和评估器换成不同模型看分数怎么动（64% / 31% / 74%）⇒ **这就是我们坑 ⑥（判官同源）的直接检验法**。
- **配套抄**：Re3 的"**计划 ≠ 兑现**"自曝（*"stories often deviate from parts of our more detailed outline"*）⇒ 我们的维度判定必须区分"**注入了**"和"**改变了决策**"。

## 二、最容易骗我们的 3 条

### 骗 1：★ 把「分支数」当成「维度数」—— ToT 的 b=5
- 广为流传的 "CoT 4% → ToT **74%**"、"b=1 45% → b=5 74%（+29pp）"。
- **真相**：`n_select_sample=b` 是**并行候选分支数**，不是信息维度数；而且论文的 "success rate" = **ANY(5 个候选里任一命中)**（我用官方 `logs/` 验证：CoT best-of-100 的 ANY = **49.0%**，正好对上论文的 49%；而 AVG = 4.0% 正好对上论文的 "CoT 4.0%"）。⇒ **b=5 给了 5 次机会，best-of-100 给了 100 次机会**。
- **同源证据**：Creative Writing 上 **IO+refine 7.67 > ToT 7.56** ⇒ **改写型环节比搜索型环节更有效** —— 这对我们的坑 ③ 是反向警示。
- **结论**：**我们绝不能把"多 4 个维度 = +29pp"写进任何文档。**

### 骗 2：★ 所有 "±" 都小得离谱 —— 它们只覆盖题目抽样，不覆盖生成随机性
- **ADAS 官方 `results/drop_gpt3.5_results.json`**（我自己扒的，论文里没有）：同一段代码（md5 相同）、val fitness 相同，**被评估了两次**：
  - Role-Adaptive Agent：test med **52.8 vs 50.6**（2.2pp），**两次 95% CI 不重叠**
  - Distributed Consensus Agent：test med **75.4 vs 79.4**（4.0pp），**两次 95% CI 不重叠**
  - 而论文 Table 1 报 DROP **79.4 ± 0.8** ⇒ **误差棒小了约 5 倍**，而且**论文选的是较幸运那次**。
  - 根因：`_drop/_mgsm/_mmlu` 的 `n_repreat` 默认 **1**（`_arc`/`_gpqa` 才是 5）⇒ 报告值里**根本没这一项**。
- **ToT 官方 README 自己承认**：headline 复现只有 **69%** 而非 74%（"due to randomness in GPT decoding"）。我算过：n=100 时 69% 的 95% CI = **59.9–78.1** ⇒ **论文的 74% 就在这个区间里**。
- **我重算的 crosswords 官方日志**：prune 版 **69.0 / 44.0**（论文说 78 / 60），no-prune **58.8 / 32.0**（论文 65.4 / 41.5）⇒ **"论文数字 > 可复现数字"在三个任务上系统性成立**。
- **⇒ 效应量/噪声比只有 ~2.5σ。我们在自己测出 δ 之前，不该接受任何 <5pp 的净维度增益。**

### 骗 3：★ "best" 是噪声估计的 max（winner's curse）+ 分母口径不可比
- **ADAS**：在 **20 题** ARC dev 集上搜 25 代再取 max（官方 val 最优 13.0 vs CoT 3.0）⇒ 这个 +10pp 极可能是**纯选择偏差**。（test 上 13.7 vs 6.0 CI 不重叠，那个才是真的。）
- **AgentSquare**：主表**单次读数、零 CI、零 seed、零显著性检验**；"平均 17.2%"是把 **6 个不可比的指标**（success rate / progress rate / micro pass rate / 平均 reward）直接平均；GPT-3.5 版 PDDL 最优只有 **0.219**、M3Tool 0.285 ⇒ **在 0.1~0.4 区间上谈"提升 20%"毫无意义**。
- **Re3**："+14% / +20%" 来自 **n=50 的人工 pairwise**（95% CI 约 ±14pp），且"Interesting"在 ROLLING-FT 那组只差 **1.0pp 且不显著**；**Re3 的"维度"是"塞进 prompt 的上下文层级"，它从没检验过"该信息是否改变了决策"**。
- **⇒ 三条共同形态：把"某个量纲下的最优读数"当成"我们这个构念的收益"。**

## 三、我们要复现的 3 个数字

### 复现 1（最优先）：**噪声地板 δ —— run-to-run 波动 2.2 ~ 5.0pp**
- 来源：ADAS 官方 archive 同一代码两次评估 **75.4 vs 79.4**（CI 不重叠）+ ToT 官方自认 **74% → 69%**。
- **做法**：拿我们自己的一个固定拓扑，在同一 DEV 集上重复评估 k 次（k≥5），报**中位数 + 95% CI + 极差**，不报单点。
- **门槛**：在拿到我们自己的 δ 之前，**任何 <5pp 的净维度增益一律判为"不可分辨"**（不是"无效应"）。
- **为什么第一个做**：我们的坑 ④（测量带宽 > 信号带宽）如果成立，**不先测 δ，后面所有实验都白跑**。

### 复现 2：★ **判官同源污染的量级表**（ToT 附录 B.2）
- 原数：GPT-4 生成 + GPT-3.5 评估 = **64%**；GPT-3.5 生成 + GPT-4 评估 = **31%**；GPT-4+GPT-4 = **74%** ⇒ 换判官模型，**分数差 11 倍**。
- **做法**：把我们的判官从同源模型换成异源（或换成 Re3 式**训练判别式**），**重测净维度增益**。
- **判据**：若净增益塌掉 ⇒ 现有结论全部作废。**这个数不测出来，后面什么都不要做。**
- **附带**：Re3 的 Edit 模块消融（≈0，甚至 −3.0pp）也提示"改写型环节可能根本不承重"。

### 复现 3（实验优先级）：**Re3 Table 3 的三维消融 + ADAS Table 6 的空初始化反常**
- Re3 Table 3：**Plan +16.6pp / Rewrite +13.7pp / Edit ≈ 0（Coherent −3.0pp）** ⇒ 直接给我们的"思维面候选清单"排优先级：**先测"有没有规划层"和"有没有检索/重排层"，暂时不要把"改写/修正"算成一个维度。**
- ADAS Table 6：**Math 域空初始化 67.5 vs 有初始化 53.4（−14.1pp）** ⇒ **路线 C 的存在性威胁**：人把拓扑池塞满强基线，可能像 ADAS 在 Math 域那样**把多样性压死**。⇒ 我们**必须**做一次"空初始化 vs 人工初始化"对照。

> **如果还有余力**：复现 AgentSquare 的 **ALFWorld 一次 CoT 评估 ≈ $60（GPT-4o）** 与 **性能预测器 ≈ 真实评估成本的 0.025%** —— 这两个数直接决定我们能不能用"便宜代理 + 昂贵真评"的分层评估策略。

## 四、贯穿全组的 3 条方法论（与上面分开，因为它们是"怎么做"而不是"抄什么"）

1. **★ 判据排序（按污染风险）**：外部 oracle（ADAS/AgentSquare/ReAct）> 训练判别式（Re3）> 异源 LLM judge > **同源 LLM 自评（ToT 的 value/vote、Creative Writing 的 judge、AgentSquare 的 π_p）**。**我们只能停在第 1 或第 2 级。**
2. **★ 一切"提升"必须做同预算对照**。ToT 的做法可直接抄：把 IO/CoT 的 best-of-k 当作"访问 k 个节点的 bandit"，**换算到同一"访问节点数/成本"轴上**再比。我们目前只有"工作流 − 直调"一个差值，**没有控制"直调多采样几次"这个混淆**。
3. **★ 报告口径纪律（三条硬规定）**：
   - 报**中位数 + CI**，不报单点；CI 重叠的条目**并列**呈现（ADAS 做法）。
   - 分母/量纲写清（ANY vs AVG；n=题数×重复数；指标口径 success rate / F1 / reward）。
   - **"选最好一次"必须同时报"同一配置的重复评估分布"**（ADAS 官方 archive 藏了两次评估，论文只报了幸运的那次）。
