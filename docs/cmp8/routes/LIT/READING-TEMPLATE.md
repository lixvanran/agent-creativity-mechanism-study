# 精读提取模板（每篇论文一份，**逐条填，不许留空**）

> 我要拿这个模板的产出**自己写收获**，所以模板必须给到"能形成判断"的颗粒度。
> **不许**只写"论文讲了 X" ⇒ 那是摘要不是提取。

## 0. 引用
- 标题 / 作者（第一作者 + et al.）/ 年份 / venue / arXiv id 或 DOI
- 一句话：**这篇论文声称自己解决了什么**

## 1. 核心机制（**要具体到能照着实现**）
| 项 | 内容 |
|---|---|
| **输入** | 任务/题面形式；有没有状态 |
| **状态表示** | 是什么（树？图？文本？向量？） |
| **动作/算子** | 枚举全部 |
| **过程/回路** | 怎么迭代；**停止条件是什么** |
| **输出** | 最终交付物形态 |
| **谁来评价** | 自评？外部判官？规则？oracle？**评价信号怎么回传给搜索** |

## 2. 关键数字
- 实验设置（题数/样本数/模型）
- 主指标与读数（**要具体数值，不要"有提升"**）
- 消融（去掉哪个组件掉多少）
- 成本（调用数/token/美元）

## 3. ★ 它的「成功标准」是什么（**对我们最有用**）
- 它**怎么判定自己成功了**？（哪个指标、什么阈值、什么对照）
- 它的**否证/失败条件**有没有写？
- 它**有没有报告"不可分辨"这种结果**？（如果它的指标本身有噪声，它怎么处理的？）

## 4. 自认的局限（**原话优先**）
- 论文自己承认的 3–5 条

## 5. ★ 对我们项目的可迁移点
映射到：**路线 A（固定拓扑）/ 路线 B（训练架构）/ 路线 C（先设计再训练）/ 优化器契约（L0–L4）/ 测量协议 / DEV 集设计**
- 能省我们什么（具体到"省掉哪个实验"）
- 要改什么才能用

## 6. ★ 不可迁移 / 会误导我们的点
- 为什么不能照抄（量纲不同？样本量不同？判据同源？自评污染？）
- **特别检查**：它的"宽度/新颖性"指标是不是**用 embedding 余弦**做的？在我们这儿有已知问题
  （embo-01 句级几何无分辨率 ⇒ 见 U1 批次实测）
- 特别检查：它的成功判据有没有**被同一模型自评**污染？

## 7. 逐字摘录（**2–3 句**，标明在哪一节/哪一段）
- 用来让我能引用原话

## 8. 读完后你**自己**的一句判断（**不许复述摘要**）
- 哪一条最值得我们抄？哪一条最容易骗我们？
