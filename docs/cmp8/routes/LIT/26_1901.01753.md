## 1. 核心机制（要具体到能照着实现）

| 项 | 内容 |
|---|---|
| **输入** | 域 = 改造版 OpenAI Gym **"Bipedal Walker Hardcore"**（2-D 双足行走障碍场）。障碍类型：**stumps（树桩）、gaps（沟）、stairs（台阶）、roughness（粗糙度表面）**。环境由**基因编码向量** e(E) 描述（roughness、gap 宽度上下界、stump 高度上下界），每个值有取值范围。 |
| **状态表示** | ① **活动环境队列** `EA_list`（容量 `capacity`，超了淘汰最旧的）；② **活动智能体参数** θ（每 env 一个）；③ **archive**（所有曾被接纳过的环境的编码）；④ 每个 pair 自己的 **Adam 优化器状态**（每次 transfer 或新建 pair 时重置）。 |
| **动作/算子（主循环三件事，Algorithm 2）** | ① **MUTATE_ENVS**：环境突变产生子环境；② **ES_STEP**：每个 pair 各自被 ES 优化一步（**互不干扰、可完全并行**）；③ **EVALUATE_CANDIDATES / transfer**：在活动环境之间**周期性尝试迁移**（双向，含子→父）。 |
| **过程/回路（Algorithm 2 逐行）** | 初始化 `EA_list = [(E_init, θ_init)]`（E_init = 全平地）→ 主循环 t = 0..T−1：<br>① 若 `t>0 且 t mod N_mutate == 0` → MUTATE_ENVS；<br>② 对每个 m：`θ^{m}_{t+1} = θ^{m}_t + ES_STEP(θ^m_t, E^m, α, σ)`；<br>③ 若 `M>1 且 t mod N_transfer == 0` → 对每个 m 在**其他**活动环境里找最优 θ^{top}，**若 `E^m(θ^top) > E^m(θ^{m}_{t+1})` 则接受迁移**；<br>④ `EA_list[m] = (E^m, θ^{m}_{t+1})`。<br>**MUTATE_ENVS 内部的 6 步（Algorithm 3，Supplemental §6.1）**：(1) 每个环境评估其配对 agent，**满足 `ELIGIBLE_TO_REPRODUCE()` 的环境**才进父代列表；(2) 父代突变产生子环境（子 agent = 父 agent 的克隆）；(3) 子 pair 过**最小准则 `MC_SATISFIED()`**——"**不 trivial 也不太难**"（否则删掉）；(4) 剩余子环境**按 novelty 排序**（相对当前种群 + archive）；(5) 做一次 transfer 尝试；(6) 再过一次最小准则（transfer 后可能变得太容易）；并限制每轮 `max_admitted` / `max_children`。 |
| **停止条件** | **T 次迭代**（实验里 T = 25,200）。另外两处硬上限：活动环境数 `capacity`（超出淘汰最旧）、每轮新生数 `max_admitted`。 |
| **输出** | ★ **不是"一个最好的解"，而是一批"被造出来且被解开的"环境 + 与之配对的智能体**。最终报告的是**环境空间覆盖度**、**解开难度所需迭代数**、**迁移替换的成功率**。 |
| **谁来评价 / 信号怎么回传** | ★ **两套完全分离**：<br>① **内环（每个 pair 内部）**：目标函数 = **环境自带的 reward**（外生、不可被优化器攻击）：`reward = 130·Δx − 5·Δhull_angle − 0.00035·torque`；摔倒 `−100`。<br>② **外环（要不要接纳新环境）**：**最小准则**（可解性/难度区间）+ **novelty 排序**（相对 archive 的编码距离）——**这是一个纯内部信号，没有 oracle**。<br>③ **评估（论文的报告口径）**：**"solved" 的硬定义 = 到达终点 且 score ≥ 230**（人定的阈值）。<br>④ **迁移接受规则**：`E^m(θ^top) > E^m(θ^{m}_{t+1})` ⇒ 接受——**用环境自己的 reward 判，不自评**。 |

**ES 内环的具体参数（可直接复现）**
- 控制器 = 3 层全连接、tanh；**24 输入 / 2×40 隐层 / 4 输出**（动作∈[−1,1]）。
- **ES 种群 = 512**（每步采样 512 个参数做加权平均，rank-normalize + Adam）。
- 学习率 0.01 → 0.001（每步衰减因子 0.9999）；噪声 σ 0.1 → 0.01（衰减因子 0.999）。
- **任何一次 transfer 被接受、或新建 pair 时，Adam 状态重置、lr 与 σ 复位到初始值。**（★ 这是一个容易漏的工程细节，也是我们"改拓扑后要重跑参数学习"的先例，见 §5。）
- episode 上限 2,000 步；摔倒即终止。

**novelty 的定义（★ 本篇对我们最关键的一段）**
- 环境编码 e(E) 是**数值向量**；novelty = **到 archive+种群里 k 近邻的平均 L2 距离**，**k = 5**：
  `N(e(E), L) = (1/|S|)·Σ_{j∈S} ‖e(E) − e(E_j)‖₂`，`S = kNN(e(E), L)`。
- ★★ 论文**自己点明**了这个选择的后果（Supplemental §6.1）：
  > 「the encoding of an environment is in effect a **genetic representation**, which means that in POET in effect **novelty is a genetic diversity measure**. That way, **POET does not in principle require a behavior characterization (BC)** to be devised for environments, though doing so is also not precluded.」

## 2. 关键数字

**实验设置**
- 域：Bipedal Walker Hardcore 改造版；**3 次 POET 运行**；每 run **25,200 次 POET 迭代**；活动环境数 **20**；ES 种群 512。
- **算力：每次运行约 10 天，256 个 CPU 核**（Ipyparallel 调度）。
- 难度分级（Table 2，用三个条件是否满足来定级）：本工作 roughness ≥ 2.4（参考 OpenAI Gym 原版 2.0，**1.2×**）、stump 高度 ≥ 6.0（原版 3.0，**2.0×**）、gap 宽度 ≥ 4.5（原版 1.0，**4.5×**）。满足 1 个 = challenging，2 个 = very challenging，3 个 = extremely challenging。

**主读数 1：解开难度所需迭代数（均值 ± 95% CI）**
| 难度 | POET 迭代数（从该环境被创建起算） |
|---|---|
| challenging | **638 ± 133** |
| very challenging | **1,180 ± 343** |
| extremely challenging | **2,178 ± 368** |

**主读数 2：对照实验（★ 本组对照设计最严的一篇）**

| 对照 | 做法 | 结果 |
|---|---|---|
| **① ES-alone** | 对 POET 造出的 5 个环境直接用 ES 从头优化，**每个跑 5 次不同初始化/种子，最多 16,000 ES 步**（= Ha 给同域 ES 步数的 2 倍） | 5 个环境的**最高分**分别只有 **17.9 / 39.6 / 13.6 / 24.0 / 19.2**，**远低于成功阈值 230**。**单样本 t 检验 p < 0.01**（全部 5 个环境）。ES 的失败模式：学会"不动"以避免 −100 摔倒惩罚（局部最优）。 |
| **② direct-path curriculum control** | **人写课程**（从全平地开始，逐个障碍参数朝目标环境加一步），到达目标或预算耗尽为止。**★ 预算严格对齐**：「each run of the control algorithm is given the same computational budget (measured in **total number of ES steps**) spent by POET to solve the environment」——**包括 POET 在整条祖先链上（含 transfer）花掉的所有 ES 步** | 用**归一化编码距离**衡量"控制算法离目标多远"（`1/β·‖(e(E_A)−e(E_B))/e(E_max)‖₂`，β=√5 归一化）。结果：challenging 档控制算法**常常**（though not always）能追上；very/extremely challenging 档**追不上**。**Mann-Whitney U 检验 p < 0.01**（challenging vs very challenging、very vs extremely 两两）；**单样本 t 检验 p < 0.01**（绝对距离显著非零）。 |
| **③ POET without transfer** | 重跑 3 次 POET，**关掉全部 transfer** | **覆盖度显著更低（Mann-Whitney U，p < 2.2e−16）**；★ **极端困难档一个都没解开**（"no extremely challenging environments are solved at all"）。 |

**主读数 3：迁移的普遍性**
- 三次 run 的 **transfer 替换尝试总数 = 18,894 / 19,014 / 18,798**；其中**成功替换率 = 53.62% / 49.26% / 48.89%**（成功 = 被试 agent 比该 niche 现任冠军更好）。
- 论文自己的保留：「While transfer is **pervasive**, that does not in itself prove it is **essential**.」⇒ 所以才有对照 ③。

**主读数 4：双向迁移的个案（Figure 7）**
- 迭代 400：父环境（全平地）突变出带小树桩的子环境，子 agent 继承蹲姿步态 → 学会"站起来跳过树桩"→ **迭代 1,175 迁移回父环境**，父 agent 首次获得站立步态 ⇒ 3,000 次迭代后**分数 349 vs 原蹲姿 309**。
- 对照：关掉 transfer 单独跑蹲姿 agent 3,000 次迭代，**"did not result in any substantive change"**。

**成本**
- 每 run ≈ **10 天 × 256 CPU 核**（≈ 61,440 核·小时），× 3 runs + 3 次对照 run + 5 个环境的 ES 对照（每个 5 runs × 16,000 ES 步）。这是**全组成本最高的一篇**，也说明它为什么用 ES（无 GPU、无 LLM）。

## 3. ★ 它的「成功标准」是什么

**（a）它怎么判定自己成功了？**
- **"solved" 是双条件硬定义**：「we define an environment as **solved when it both reaches the far end of the environment and obtains a score of 230 or above**.」★ 注意"230"这个阈值是**人定的**，作者给了理由：「Based on our observations, the score of 230 ensures that the walker is **reasonably efficient**.」
- **★ 报告口径不是单一分数，而是三个不同性质的量**：① 解开所需迭代数（随难度分档，各报 95% CI）；② 对照的"离目标距离"分布；③ 环境空间覆盖度。⇒ **它没有用一个总分把一切压平**。
- **★ 对照结构是三档，而且每一档都"等预算"**：
  - ES-alone（等 ES 步数）、direct-path 课程（**严格等总 ES 步预算**）、POET-no-transfer（**同算法同参数，只关一个变量**）。
  - ⇒ 这是本组**唯一一篇把"等预算"写进正文并明确算清预算口径**的论文。
- **统计方法**：单样本 t 检验（POET 分布以单个 POET 分数为中心）、Mann-Whitney U 检验（分布形状/秩）、95% CI。

**（b）否证 / 失败条件有没有写？—— 写了，而且写得很显眼（本组最诚实的一段方法学自白）**
> 「An interesting aspect of open-ended algorithms is that **statistical comparisons can be challenging because such algorithms are not trying to perform well on a specific preconceived target, and thus some amount of post-hoc analysis is often necessary.** That property is what motivates an analysis driven by choosing environments produced and solved by POET, and then checking whether direct optimization can solve these environments.」
> 「However, from a statistical comparison standpoint it raises the challenge that **because each environment created by POET is unique, we only have one score for POET to compare against a set of direct-optimization ES runs.** For that reason, we use a **single-sample t-test that assumes the POET distribution is centered on the single POET score** and measures whether the direct optimization distribution's mean is statistically significantly lower.」
- ⇒ ★★★ **它明确承认：开放型搜索没有"天然的统计对照物"，必须先人为造一个"事后分析"框架。** 这正是我们的问题（"净维度增益"这类开放型指标怎么跟什么比）。
- 另外的否证：直接路径控制"**常常**（though not always）能解 challenging 档"⇒ 它没有夸大。

**（c）有没有报告"不可分辨"？—— ❌ 没有。**
- **n = 3 runs**；没有噪声地板 δ；没有功效分析；没有"这两者差异落在噪声内"的档；单样本 t 检验在 n=5 的 ES 对照上做，假设较强（POET 分布中心 = 单个观测值）。
- ⇒ **我们不能只学它的 p 值用法**；但**它的"开放型搜索统计比较"框架必须学**（见 §5）。

## 4. 自认的局限（原话优先）

1. **§5（问题空间会"顶到天花板"）**：
   > 「The present problem space is a 2-D course of obstacles that can be generated within distributions defined by the genome describing the environment. This space is **limited by the maximal ranges of those distributions**. For example, there is a maximum possible gap width and stump height, which means that the system in effect can eventually **"max out" the difficulty**.」
2. **§5（agent 身体固定）**：
   > 「An additional constraint that exists in this initial work is that **the body of the agent is fixed**, ultimately limiting the sort of obstacles it can overcome (e.g. how big of a gap it can jump over).」
3. **§4.3（迁移普遍 ≠ 迁移必要，所以必须加对照）**：
   > 「While transfer is pervasive, that does not in itself prove it is essential. To demonstrate the value of transfer, a control is needed.」
4. **§4.3（开放型算法统计难比）**：
   > 「…because each environment created by POET is unique, **we only have one score for POET** to compare against a set of direct-optimization ES runs.」
5. **§4.2（阈值是人拍的）**：
   > 「**Based on our observations**, the score of 230 ensures that the walker is **reasonably efficient**.」★ 诚实，但**没有做阈值敏感性分析**。
6. **§2.2（MCC 的问题）**——它对自己前作的批评，也顺带暴露了自己的前提：
   > 「in MCC **problems have to be solvable by the current population**, so complexity can only arise through drift. … In contrast, in POET, we accept problems if (according to some heuristics) they seem likely to be improved upon and/or solved after some amount of dedicated optimization effort.」★ ⇒ **"太难就扔掉"这条准入规则，本身就是"不追求真正困难"的机制** —— 我们的"维度准入"也必然有类似取舍。

## 5. ★ 对我们项目的可迁移点

| 我们的东西 | 它对应什么 | 怎么用 |
|---|---|---|
| **★ 我们的"新维度准入"要不要行为描述符？** | **POET 的 novelty = 基因型编码距离（k=5, L2），且论文明说"不需要 BC"** | ★★★ **本篇对我们最直接的可抄点。** 我们完全可以把"新颖性"定义在**拓扑/op 序列的编码**上（例如 op 类型的 one-hot 序列、或 op 序列的 n-gram 集合），用 k-NN 距离算 —— **这一步彻底绕开 embedding 几何**（坑②：embo-01 句级几何无分辨率）和措辞相似度（坑③）。<br>⇒ 而且它和第 1 篇（Novelty Search，用**行为**距离）形成**正面对照**：**行为描述符是可选的，不是必需的**。我们的"承重信息"要的是**可核验性**（另一个维度），而"新颖性"可以单独用编码距离算。★ **两篇合起来给出一条干净的路：新颖性用结构距离（可抄 POET），承重性用可核验性（我们自己定）。** |
| **★ 我们的三路线对照的预算对齐** | **"等预算"的严格写法** | ★★★ POET 的 direct-path control 明确写：「given the **same computational budget (measured in total number of ES steps)** … which includes all the ES steps taken in the entire sequence of environments along the direct line of ancestors (taking into account transfers)」。⇒ **我们的对照必须把"生成侧预算"和"优化侧预算"都算进去**（这正是第 4 篇 pith 评审指出的我们协议的漏洞，POET 早在 2019 就做对了）。**能省我们**：以后不用再临时争论"预算怎么算"——直接引用它的口径。 |
| **★ 我们的"维度"成功定义** | **双条件硬定义** | ★★ 「solved ⟺ **到达终点** 且 **score ≥ 230**」。⇒ 我们的"承重信息"也应是**双条件**：**依据包可核验**（a）**且** **改变决策**（b）—— 我们已经这么定义了，但**要抄它把条件写成一个可机械判定的合取式**。 |
| **★ 开放型搜索的统计比较** | **"事后分析 + 单样本 t 检验"框架** | ★★★ 本组唯一正面处理这个问题的论文。⇒ 我们的"净维度增益"（差值）**天然可以做配对比较**，但如果我们要报"这条路线产生了多少个**新**承重维度"，就需要 POET 这套"人为造对照物"的办法：**先由被测系统自己产出一批对象，再问对照能不能复现/逼近它们**。⇒ 这可以直接变成我们的一个 DEV 集设计：**让工作流自己产出候选维度清单，然后问"直调臂能不能复现出这些维度"**——如果不能，工作流的价值就被隔离出来了。 |
| **★ 转运（transfer）与"改拓扑要重训参数"** | **transfer 被接受 ⇒ Adam 状态重置、lr/σ 复位** | ★★ 这给了我们一个**可抄的工程规则**：**任何改变拓扑的操作都必须重置优化器状态并从头训参数**。⇒ 我们的协议里"改了拓扑后要重跑参数学习"这条，**不只是为了公平，而是因为优化器状态本身携带了旧拓扑的假设**。★ 抄 POET 的 reset 规则。 |
| **路线 C（人定拓扑 + 训练调参数）** | **POET 内环 = 路线 C** | ★★ POET 的每个 pair 内部就是"**环境固定 + ES 训参数**" ⇒ **路线 C 的现成范例**。⇒ 我们的路线 C 可以直接引用 POET 说明"人定结构 + 学参数"这一格不是空想。 |
| **路线 A（人写死固定拓扑）** | **POET 外环（环境生成 + 迁移编排）** | ★★ POET = **路线 A 的编排 × 路线 C 的内环**。⇒ 我们如果想论证"路线 A 也有价值"，POET 提供了"**人定结构 + 自动编排**"的第三条路，比纯 A/B 二选一更贴我们的真实处境。 |
| **路线 B（训练学出操作序列）** | —— | ★ **POET 完全没碰这一格**：它的新环境来自**突变 + 人工阈值筛选**，不是学出来的。⇒ **"谁来提出新拓扑"这个问题 POET 没解决**（它用环境编码的突变代替了）⇒ 我们路线 B 的核心难题在 POET 里**没有先例可抄**，别指望从它那儿得到答案。 |
| **"多样性 ≠ 思维面宽"（坑⑦）** | POET 的 diversity = **环境编码多样性** | ★★ 它的"多样性"是**环境参数空间的覆盖度**（用编码距离算的），**不是**"有多少个不同的承重信息"。⇒ 又一个"多样性 ≠ 思维面"的实例，支持我们把两者分开报。 |

**能省我们什么（具体）**
- 省掉一轮"我们的新颖性到底该在哪个空间里算"的争论 ⇒ 直接用 POET 的做法：**在编码/结构空间算 k-NN 距离**，并**明确声明"这是遗传/结构多样性度量，不是行为刻画"**（论文原话就是最好的免责句）。
- 省掉"预算怎么对齐"的扯皮 ⇒ 抄 ES 步数口径。
- 白拿一个"开放型指标怎么做统计比较"的现成框架。

**要改什么才能用**
- POET 的编码空间**极其便宜**（5 个数值参数）。**我们的"拓扑空间"必须先有一个可比、可枚举、低维的编码**，否则 k-NN 无从算起。⇒ 这件事本身就是路线 B 要学的产物 ⇒ 我们的"结构距离新颖性"在路线 B 成立之前，只能先用**人定拓扑的编码**做 ⇒ **这恰好可以变成一个干净的"路线 A 有什么独特价值"的实验**。
- 它的最小准则（"不太难不太容易"）需要**一个能测难度的东西**；我们的对应物是"这条维度对决策的影响有多大" ⇒ **我们的准入阈值会比它更可疑**（我们还没有可靠的测量带宽，见坑④）。

## 6. ★ 不可迁移 / 会误导我们的点

- ★★★ **量纲完全不同：它的"目标函数"是外生的、不可被攻击的；我们的不是。** POET 的 reward 来自环境（走得远、别摔），优化器**碰不到** reward 的定义 ⇒ 它的"目标不被骗"是**结构上**保证的。**我们的"净维度增益"是我们自己定义的、判官可被影响的、且我们已测出测量带宽 > 信号带宽（坑④）** ⇒ **我们比它危险得多**，不能拿它的"干净"来安慰自己。
- ★★ **它没有"新颖性被优化器攻击"的防护，因为它不需要**（novelty 只用于**准入/排序**，不用于评价成败）⇒ 抄它的双通道结构（搜索信号 ≠ 评价信号）是对的；★ 但**如果我们也把"新颖度"当评价指标**（我们正是要测它！），就落进了它不需要面对的坑 ⇒ **必须显式分开**。
- ★★ **"solved 的阈值 230 是人拍的，而且没做敏感性分析。** ⇒ 我们的"承重信息"阈值也一定是人拍的（"改变决策"到什么程度算改变？）。**POET 提醒我们的是：要交代这个阈值怎么来的、换它结论会不会变** —— 它自己没做 ⇒ **这是我们的机会点**（做一个阈值敏感性扫描，论文里少见）。
- ★★ **它的"多样性"是环境参数覆盖度，不是"承重维度数"。** 拿 POET 的覆盖度读数支持"我们的思维面更宽"是**偷换构念**（坑⑦）。
- ★ **统计功效弱**：n = 3 runs；ES 对照 n = 5；单样本 t 检验把"POET 分布中心 = 一个观测值"当假设。**没有 δ、没有"不可分辨"档。** ⇒ 我们必须**比它更严**（我们已有 σ_d(k) 与 n≈13.3(σ_d/Δ)² 的采样公式）。
- ⚠️ **不可复现成本**：10 天 × 256 核 × 多次 run。**我们不可能复现 POET 的规模** ⇒ 我们的"要复现的数字"必须选**便宜且有信息量的那一个**（见会话总览）。
- ⚠️ **预印本 vs 正式版**：arXiv 版 28 页、9 图；GECCO'19 正式版 pp.142–151（10 页）——**内容有出入**。引用实验数字时以**预印本**为准并注明版本（本文所有引文与数字均出自 arXiv v1 的 HTML）。
- ⚠️ **它的"新颖性"用在"环境准入"上，不是用在"评价 agent 好不好"上** —— 我们若把 k-NN 新颖性同时用于"生成候选维度"和"给候选维度打分"，会退化成"自己给自己打分"（坑⑥）。

## 7. 逐字摘录

1. **Supplemental §6.1 Producing New Environments（novelty 的定义 + BC 不必要的声明 —— 对我们最有用）**
   > "POET calculates the novelty of the child environments. This novelty calculation is based on the **encoding**. … For readers familiar with the novelty search algorithm, it is important to note here that the encoding of an environment is in effect a **genetic representation**, which means that in POET in effect **novelty is a genetic diversity measure**. That way, **POET does not in principle require a behavior characterization (BC)** to be devised for environments, though doing so is also not precluded."
   > "…each child environment … is checked against a predefined **minimal criterion** … only those satisfying the minimal criterion are kept … **ensuring that potential new environments are not too trivial and not too hard** (which would lead to little progress)."

2. **§4.3 Results（开放型搜索的统计比较 —— 本组唯一的正面处理）**
   > "An interesting aspect of open-ended algorithms is that **statistical comparisons can be challenging because such algorithms are not trying to perform well on a specific preconceived target, and thus some amount of post-hoc analysis is often necessary.** … However, from a statistical comparison standpoint it raises the challenge that because each environment created by POET is unique, **we only have one score for POET to compare against a set of direct-optimization ES runs.** For that reason, we use a **single-sample t-test that assumes the POET distribution is centered on the single POET score** and measures whether the direct optimization distribution's mean is statistically significantly lower."

3. **§4.3 Results（等预算的严格写法）**
   > "To be fair, **each run of the control algorithm is given the same computational budget (measured in total number of ES steps) spent by POET to solve the environment**, which includes all the ES steps taken in the entire sequence of environments along the direct line of ancestors (taking into account transfers) leading to the target."

4. **§4.3 Results（transfer 普遍 ≠ transfer 必要）**
   > "While transfer is pervasive, that does not in itself prove it is essential. To demonstrate the value of transfer, a control is needed."

5. **§4.2（成功阈值是人拍的）**
   > "In this work, we define an environment as **solved when it both reaches the far end of the environment and obtains a score of 230 or above**. Based on our observations, the score of 230 ensures that the walker is **reasonably efficient**."

## 8. 读完后我自己的一句判断

**最值得抄**：★★ **"新颖性用结构/编码距离算，不必用行为刻画、也不必用 embedding"**（POET 明说 BC 不是必需的）+ **"等预算对照按 ES 步数算，含 transfer 开销"** 这两条。前者直接把我们从坑②/坑③里拔出来一半，后者把我们从"预算不对齐"的质疑里拔出来。

**最容易骗我们**：★ **它的"目标函数干净"是外生给的（环境的 reward，优化器碰不到）**，而我们的主判据是自定的、判官可被影响、且我们已测出测量带宽大于信号带宽。⇒ 拿 POET 的"新颖性 vs 目标"框架来讲我们的事，会**掩盖我们真正的风险**：我们的搜索信号和评价信号还没物理隔离（见第 1 篇的双通道原则、见第 4 篇的留出集隔离）。

**额外捡到的**：它那句「**open-ended algorithms … statistical comparisons can be challenging**」是本组唯一一句话点破我们这类研究的方法论死结 —— **开放型指标没有天然对照物，必须自己造**。这可以直接写进我们的协议：**"净维度增益"的对照物不是"直调"，而是"由被测系统自己产出的候选维度集合 + 一个复现实验"**。
