## 1. 核心机制（具体到能照着实现）

| 项 | 内容 |
|---|---|
| **输入** | 一个初始环境 `E^init`（平坦无障碍地面）+ 一个随机初始化的策略参数 `θ^init`。**没有题目、没有标签、没有目标任务的编码。** |
| **状态表示** | **种群**：`EA_list` = 若干 **(环境, 智能体) 对**（environment-agent pair）。<br>• **环境的编码 = 一个 5 维基因向量**（每维是"从哪个区间均匀采样"的 (min,max) 区间 + 一个随机种子）：`stump height` / `gap width` / `step height` / `step number` / `surface roughness`。**实际环境 = 从这些分布采样出的具体地形，种子存在环境里 ⇒ 可精确复现。**<br>• **智能体 = 一个神经网络控制器**（3 层全连接 tanh；24 输入 / 4 输出 / 2 个 40 单元隐层）。<br>★ **注意：环境空间本身是人手写的 5 维编码。** |
| **动作/算子** | 每次主循环做三件事：<br>1. **生成新环境**（每 `N^mutate` 步一次）：`MUTATE_ENVS` —— 采样一个父环境 → 扰动其编码（每个参数 ±1 个 mutation step）→ 换新随机种子。<br>2. **优化配对智能体**：每个 (E, θ) 独立做一次 **ES_STEP**（Salimans et al. 2017 式 ES，rank-normalize）。<br>3. **尝试转移**（每 `N^transfer` 步一次，`M>1` 时）：`EVALUATE_CANDIDATES` —— 让**其他环境的 agent** 尝试在本环境里跑一段，**如果更好就替换掉当前 niche champion**（θ^m ← θ^top）。<br>★ 转移是**双向**的：父→子、**子→父**、以及任意跨 niche。 |
| **过程/回路** | `Algorithm 2 POET Main Loop`：`for t = 0 to T-1`。<br>• 群体上限固定，**满了就淘汰最老的**（FIFO 队列式），保证技能有transfer 的时间窗口。<br>• **两个准入闸门（这是 POET 的核心控制逻辑）**：<br>　– **繁殖资格**：父环境的配对 agent 得分 **≥ 200**；<br>　– **最小准则 MC**：`50 ≤ E^child(θ^child) ≤ 300` —— 不太难也不太易；超出就**丢弃**。<br>　– 若合格子环境超过上限，**优先保留期望得分低的**（更难但可达）。<br>**停止条件 = 迭代数 T 耗尽**（无收敛判据、无早停）。 |
| **输出** | **不是一个最终答案，而是"一整个被创造并解决的环境+智能体集合"**（一串涌现的能力）。评价靠**覆盖率**与**距离**（见下）。 |
| **谁来评价** | **环境自身的奖励函数**（`Reward = 130·Δx − 5·Δhull_angle − 0.00035·torque`，摔倒 −100），**没有任何 LLM、没有判官、没有人工**。✅ 判据 100% 同源无关、100% 可复算。<br>**信号怎么回传**：奖励只用于**ES 的梯度估计**和**准入闸门（MC / 繁殖资格）**；**"哪些挑战值得被造出来"这个决策，由 MC 阈值 + 难度优先级规则给出，不是学出来的。** |

**实验域设置（Bipedal Walker Hardcore 改造版）**
- agent 两条腿 × 每腿 2 个关节 = **4 维动作空间**；10 个 LIDAR + 14 个状态变量。
- episode 上限 **2000 步**；**"解决"= 走到终点 且 得分 ≥ 230**。
- ES：**population 512**（每次梯度步采样 512 个参数），**Adam**；lr 0.01 → 0.001（每步衰减因子 0.9999）；噪声 σ 0.1 → 0.01（每步衰减 0.9999/0.999）；**每次发生 transfer 或新建 pair 时，重置 Adam 状态并重置 lr/σ 到初值**。
- 群体：**20 个活跃环境**；**每次运行最多 25,200 次 POET 迭代**；**3 次运行**；每 run **约 10 天 / 256 CPU 核**。
- `max_children = 512`。

**环境基因表（Table 1，逐字）**
| 障碍类型 | 初始值 | 变异步长 | 最大值 |
|---|---|---|---|
| Stump Height | (0.0, 0.4) | 0.2 | (5.0, 5.0) |
| Gap Width | (0.0, 0.8) | 0.4 | (10.0, 10.0) |
| Step Height | (0.0, 0.4) | 0.2 | (5.0, 5.0) |
| Step Number | 1 | 1 | 9 |
| Roughness | uniform(0, 0.6) | uniform(0, 0.6) | 10.0 |

## 2. 关键数字

**对照 1：ES 单独跑（POET 生成的环境）** —— 每个环境跑 **5 次 ES**（不同初始化/种子），最多 **16,000 ES 步**（是 Ha 2018 同域预算的 2 倍）：
- Figure 2 的三个环境，5 次 ES 的**最高分**分别是 **17.9 / 39.6 / 13.6**（成功阈值 230）。
- Figure 3 的两个环境：**24.0 / 19.2**。
- **单样本 t 检验：p < 0.01**（假设 POET 分布中心在那个单点，比较 ES 分布均值是否显著更低）。
- ES 的失败模式很具体："these agents learn to move forward, but also to **freeze before challenging obstacles**" —— 局部最优（不动就不会摔）。

**对照 2：direct-path curriculum-building（直接路径课程控制）** —— 给它**同样的 ES 步数预算**（含沿祖先直线的全部步数），沿"平坦 → 逐障碍加一档 → 目标环境"直线路径训练：
- 距离度量：`d(E_A,E_B) = (1/β)·‖(e(E_A)−e(E_B))/e(E_max)‖₂`，**β = √5** 归一化（使"最大环境 ↔ 全平环境"的距离 = 1）。归一化用 `E_max`：roughness=8, Gap_lower=upper=8, Stump_lower=upper=3。
- 难度分级（Table 2）：满足 3 条中的 1 条 = challenging；2 条 = very challenging；3 条 = extremely challenging。阈值：**Roughness ≥ 2.4 / Stump Height ≥ 6.0 / Gap Width ≥ 4.5**（原始 Hardcore 参考值 2.0 / 3.0 / 1.0 ⇒ **本工作分别是 1.2× / 2.0× / 4.5×**）。
- **Mann-Whitney U**：challenging vs very challenging 距离差 **p<0.01**；very vs extremely **p<0.01**。
- 结论：**极难 / 极极难环境，控制算法完全够不着**；最低难度（challenging）控制算法**常常（但不总是）能解**。

**POET 求解所需的迭代数（均值 ± 95% CI）**
| 难度 | POET 迭代数 |
|---|---|
| challenging | **638 ± 133** |
| very challenging | **1,180 ± 343** |
| extremely challenging | **2,178 ± 368** |

**转移机制的量化**
- **替换尝试**（一个环境接受来自其他所有活跃环境的转移尝试的次数）：RUN1 **18,894**、RUN2 **19,014**、RUN3 **18,798**；其中**成功替换率**分别 **53.62% / 49.26% / 48.89%**（成功 = 被试 agent 比当前 niche champion 更好）。
- **★ 消融（POET without transfer）**：另跑 3 次 POET，**关掉所有转移**。覆盖率度量 = 均匀采样 1000 challenging + 1000 very challenging + 1000 extremely challenging 环境，对每个样本算到"已创造并解决的环境集合"中**最近者的距离**，求和（覆盖越好，距离和越小）。
  - **POET 显著优于无转移版：Mann-Whitney U，p < 2.2e-16**。
  - **★ 质变：无转移版"一个 extremely challenging 环境都没解出来"**（Figure 8）。
- **双向转移的实例（Figure 7）**：iteration 400 父→子（子环境学出"站起来跳过树桩"）；**iteration 1,175 子→父**（把"站起来"传回全平面的父环境，打破父环境的"蹲着走"局部最优）。同样 3,000 次迭代：**蹲姿 309 分 vs 站姿 349 分**。作者另做了验证：关掉 transfer 后，蹲姿 agent 在原环境跑 3,000 次迭代"**did not result in any substantive change**"。

## 3. ★ 它的「成功标准」是什么

**它怎么判定自己成功了？**
- **★ 主判据是"覆盖"而不是"峰值"**，这是本批 6 篇里最值得我们抄的判据形状：
  1. **绝对判据**：一个环境被"解决" = **走到终点 且 得分 ≥ 230**（硬阈值，可复算，无判官）。
  2. **群体判据**：**覆盖率** = 采样空间中的环境，到"已创造并解决的环境集合"的**最近距离之和**（越小覆盖越好）。
  3. **难度分层**：把环境按"满足几条难度条件"分 3 档，分别报覆盖。
  4. **对照 = 三个反事实**（这是它最强的地方）：
     - **ES 单独**（无课程、无跨环境）；
     - **direct-path curriculum**（**同预算**、一条最短路径的显式课程）；
     - **POET without transfer**（**只拆掉一个机制**）。
- **★ 成功 = 在**同等计算预算**下，覆盖显著大于三个反事实中的每一个；且难度越高，差距越大。**

**它的否证/失败条件有没有写？** —— **★ 写了，而且罕见地显式**：
- 明确承认**统计比较的困难**："because each environment created by POET is unique, we only have one score for POET to compare against a set of direct-optimization ES runs. For that reason, we use a single-sample t-test that assumes the POET distribution is centered on the single POET score…"（⇒ **它知道自己的 n=1 问题，并为此选了对的统计方法。**）
- 明确承认**不能保证到达预设目标**："while POET cannot guarantee reaching a particular preconceived target, these results suggest that in some environment spaces POET's unique ability to generate multiple different challenges and solve them may actually still provide a more promising path…"
- 明确承认**编码有上限**："there is a maximum possible gap width and stump height, which means that the system in effect can eventually '**max out**' the difficulty."

**它有没有报告"不可分辨"这种结果？** —— **★ 接近全套，是本批最好的**：
- ✅ 报了 **95% 置信区间**（638±133 / 1,180±343 / 2,178±368）；
- ✅ 报了**统计检验**（单样本 t 检验 p<0.01；Mann-Whitney U p<0.01 与 **p<2.2e-16**）；
- ✅ **明确拒绝因果外推**（见上）；
- ⚠️ 但**没有**"不可分辨"档位（没有"差异小于 X 视为不可分辨"）——它是靠**大效应 + 显著 p 值 + 定性崩塌**（"无转移时极难环境解出数 = 0"）来避免噪声问题。

## 4. 自认的局限（原话优先）

1. **编码上限**："This space is limited by the maximal ranges of those distributions. For example, there is a maximum possible gap width and stump height, which means that the system in effect can eventually '**max out**' the difficulty."
2. **身体固定**："an additional constraint that exists in this initial work is that **the body of the agent is fixed**, ultimately limiting the sort of obstacles it can overcome (e.g. how big of a gap it can jump over)."
3. **不可保证目标**："while POET **cannot guarantee reaching a particular preconceived target**…"
4. **统计上的先天不对称**："because each environment created by POET is unique, we only have **one score for POET** to compare against a set of direct-optimization ES runs."（并据此选用单样本 t 检验作为补偿。）
5. **内层优化器是"沿用"而非设计的**："While ES is the base optimization algorithm in this paper for training solvers… POET can be instantiated with any RL or optimization algorithm."（⇒ 它的贡献**不依赖**优化器，我们不必照抄 ES。）
6. **尚未做 per-environment 奖励函数**：当前版本"does not also create a unique reward function for each environment, doing so is a natural extension we leave for future work."

## 5. ★ 对我们项目的可迁移点

**映射：路线 C（先设计再训练）/ 路线 B（训练架构）/ 优化器契约 / 测量协议 / DEV 集 —— 本篇是全批最重的可迁移源**

- **★★ 抄 1：把"搜索空间"本身当作被设计/被演化的对象。**
  POET 演化的是**问题**，不只是解；而且**问题和解是一起演化的**（"environment-agent pair"）。
  → 对我们的意义：**我们的"工作流"如果只是在一组固定题上换操作顺序，本质上是在解空间里搜，不是在解空间里开路。** POET 提示我们：真正的"思维面"可能体现在**"我们能造出什么新问题/新情境"**，而不只是"我们能解出几个"。
  → **要改什么**：我们的题集是给定的（这是我们的约束），但**我们可以让"依据包/情境组合"成为可演化的对象**——例如按某条轴（题面长度、约束条数、领域）生成新的"承重信息配置"，并为它配一个 agent。

- **★★ 抄 2：`POET without transfer` 这个消融的形态 —— ★ 这是本批最该照抄的实验形态。**
  **只拆掉一个机制，其余全同，然后看"某一类解的数量是否质变归零"。**
  它的读数不是"平均分降了 5%"，而是 **"no extremely challenging environments are solved at all"**（一个**定性崩塌**）+ **p<2.2e-16**。
  → **能省我们什么**：省掉"消融该做成什么形状"的争论。**我们的消融目标形态应该是"某一类承重信息维度归零/塌缩"，而不是"均值降了点"。** 这也直接对上我们 ④（测量带宽 > 信号带宽）：**离散计数上的质变归零**比连续量上的均值差更抗版本漂移。
  → **具体**：我们的 A/B/C 三条路线天然可以互为消融（去掉 C 的"训练"就是 A；去掉 C 的"人定拓扑"就是 B）——**这不是三条路线，是一次 2×2 消融。** POET 告诉我们**这个消融值得单独成篇**。

- **★★ 抄 3：三个反事实对照，且**同预算**。**
  - **ES 单独** ≈ 我们的"直调"；
  - **direct-path curriculum** ≈ 我们的"人手写一条最直接的路径"；
  - **without transfer** ≈ 我们的"去掉某个信息通路"。
  关键细节：**"To be fair, each run of the control algorithm is given the same computational budget (measured in total number of ES steps) spent by POET…"** ⇒ **同预算**是硬要求。
  → **能省我们什么**：省掉"我们的增益到底是方法带来的还是算力带来的"这个无解的争论——**同预算对照一次解决**。（这正是 07 篇 GoT 没做、08 篇仓库里也没有的东西。）

- **★ 抄 4：覆盖度量的形状 —— "采样空间 → 到已解集合的最近距离之和"。**
  → 对我们的意义：**这可能是"思维面 = 有效信息维度数"的一个更硬的同构物**：不是数"我们解了几题"，而是问"**我们的解覆盖了配置空间的多大比例**"。我们的"承重信息组合空间"就是那个被采样的空间。
  → **要改什么**：POET 的距离是在**人手写的 5 维基因空间**里算的（归一化到全平↔最大环境的 L2 距离 = 1）。⚠️ **我们的"配置空间"也得有一个等价的、可归一化的坐标**——**这个坐标由谁定义？**（见第 6 节第 2 点，这是本篇对我们的**最大陷阱**。）

- **★ 抄 5：难度分层 + 逐层报告。**
  POET 把环境分 3 档难度、**逐档报覆盖与迭代数**（638 / 1,180 / 2,178）。⇒ **我们的 DEV 集应该按"承重信息条数/难度"分层，逐层报净维度增益**，而不是只报一个总平均。**这也和 10 篇的"逐类别资格线"一致。**

- **★ 抄 6：转移是双向的，且"子→父"能打破父的局部最优（309 → 349）。**
  → 对我们：**一条新思维面（子）的信息，回灌到旧路径（父）上能改进旧路径**，这是"跨臂信息共享"的最小证据。⇒ 我们的并行臂之间**允许传什么**，应该抄这条：**传"承重信息"，不传"结论"**。

- **优化器契约 L0–L4**：POET 有 **L2（有反馈的循环：ES 步 + 准入闸门 MC + 转移接受/拒绝）**、有 **L3（跨环境转移 = 跨臂信息共享）**，但**没有 L4（元层学习"什么转移更好"）**。⇒ **它是"有机制、有回路、有对照，但没有元优化"的形态**——对我们补 ⑤（缺优化策略）有参照价值：**至少要有"接受/拒绝"这个二值决策规则**（POET 的规则是"更好就替换"，纯规则，不学）。

## 6. ★ 不可迁移 / 会误导我们的点

1. **★ 领域完全不可比（量纲）。**
   Bipedal Walker 的 reward（`130·Δx − 5·Δhull_angle − 0.00035·torque`）、阈值 230、迭代数 638/1,180/2,178 —— **与"信息维度"没有任何换算关系**。只能抄**实验形态与判据形状**，不能抄数值。

2. **★★ 最大的陷阱：POET 的"开放性"是**在人手编码的空间里**开放**，而"编码"是路线 A。**
   - 环境空间 = **人手设计的 5 维基因**（stump / gap / step height / step number / roughness），**每维的初值、变异步长、上限全是人定的（Table 1）**。
   - "开放"发生在**这 5 维盒子内部**（论文自陈："This space is limited by the maximal ranges of those distributions… can eventually 'max out' the difficulty"）。
   - 覆盖度量也在**同一个 5 维空间**里算。
   → **对我们的直接威胁**：如果我们把"承重信息组合"当成我们"开放"的空间，并且用**我们自己设计的坐标**去测覆盖率，那么**我们的"开放"和我们的"度量"共享同一个循环假设**——测出来的高覆盖可能只是"我们设计的格子被填满了"。
   ⇒ **必须做 10 篇的 no-seed 对照的同构版**：**用一个人不知道的、独立的配置生成器**（或随机配置）来测我们的覆盖率，看结论是否成立。**这是本篇给我们的最重要的一条警告。**

3. **★ "多样性"在这里有**特定的、非通用的**定义。**
   POET 的多样性是 **基因空间里的距离**（`‖Δe‖₂`），**不是行为多样性、不是语义新颖性**。
   → ✅ 好处：**它完全避开了 embedding 相似度**（模板第 6 节专门检查项：POET 全文无 embedding、无语义相似度、无措辞判据）。**这是本批 6 篇里判据载体最干净的一篇。**
   → ⚠️ 代价：**它能用，是因为它的"多样性"恰好有一个可解析的、低维的、人可设计的坐标**。我们的"承重信息"没有这样的坐标。⇒ **我们需要自己发明那个坐标**（这恰恰是我们项目的核心难点，也是 POET 唯一没帮上忙的地方）。

4. **★ 统计上 POET 自己是 n=1（作者自陈）。**
   "we only have one score for POET to compare against a set of direct-optimization ES runs."（用单样本 t 检验补偿，但**假设 POET 分布中心在那个单点上**是强假设。）
   → 对我们：我们的"净维度增益"如果也是**每个拓扑只有一次测量**，就会继承同一个统计缺陷。⇒ **每个拓扑必须多次重复 + 报区间**（这正是 10 篇的做法、也是我们 ④ 的教训）。

5. **★ 算力完全不可比**：3 runs × 25,200 iterations × 10 天 × 256 核。⇒ **POET 的结论不能直接支持"我们的路线 B 值得投算力"**——它证明的是"**在有一个可解析编码空间的领域里，开放式演化能打败直接优化**"，**不证明**"在 LLM agent 架构上也能。

6. **内层是 ES（无梯度 RL），不是 LLM。** POET 的一切"迁移"都是**参数向量的迁移**（一个 4 输出 MLP）。⇒ **它没有回答"LLM 产生的中间状态/依据包能不能迁移"**——而这正是我们的问题（我们的"承重信息"是**文本/结构**，不是参数）。⚠️ **迁移机制在参数空间和文本空间里的行为可能完全不同**（文本无法"部分继承"，只能整段传递）——**这一条没有任何一篇论文回答了**。

## 7. 逐字摘录

> **§3 POET 算法（环境生成的定位）**
> "To generate a new environment, POET simply mutates (i.e. randomly perturbs) the encoding (i.e. the parameter vector) of an active environment. However, while it is easy to generate perturbations of existing environments, the delicate part is to ensure that (1) that the paired agents in the originating (parent) environments have exhibited sufficient progress… and (2) when new environments are generated, they are **not added to the current population of environments unless they are neither too hard nor too easy** for the current population."

> **§4.3 Results（统计的自陈）**
> "An interesting aspect of open-ended algorithms is that **statistical comparisons can be challenging** because such algorithms are not trying to perform well on a specific preconceived target… because each environment created by POET is unique, we only have one score for POET to compare against a set of direct-optimization ES runs."

> **§4.3 Results（转移消融）**
> "In an even more dramatic statistic showing the essential role of transfer in open-ended search, **in POET without transfer, no extremely challenging environments are solved at all**."

> **§5 Discussion（上限自陈）**
> "This space is limited by the maximal ranges of those distributions… which means that the system in effect can eventually '**max out**' the difficulty."

## 8. 读完后我自己的一句判断

**最值得抄**：**`POET without transfer` 那个消融的形状**——"拆掉一个机制 → 某一类解**数量质变归零** + p<2.2e-16"，而不是"均值降了 5%"。我们的 A/B/C 天然是一张 2×2 消融表（去掉 C 的训练 = A；去掉 C 的人定拓扑 = B），**这张表值得单独成篇**；而且"某一类承重维度归零"这种读数，**天生比我们那个 0/+1/−1 的离散净增益抗版本漂移**（治 ④）。

**最容易骗我们**：**它的"开放"是在一个"人手写的 5 维盒子"里开放的，而它的"覆盖"也在同一个盒子里测。** 如果我们把"承重信息组合"当成开放空间、用自己设计的坐标测覆盖率，就会得到一个**自证的**高覆盖——**度量与被测共享同一个循环假设**。⇒ POET 唯一真正没帮到我们的地方就在这：**它没有回答"怎么给'信息维度'找一个可归一化、人可设计的坐标"**，而那恰好是我们的核心难点。
