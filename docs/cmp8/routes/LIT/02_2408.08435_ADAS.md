# 精读 02 · ADAS：Automated Design of Agentic Systems
> arXiv:2408.08435 ｜ Shengran Hu, Cong Lu, Jeff Clune ｜ 2024-08-15 ｜ cs.AI ｜ 官网 shengranhu.com/ADAS

## 我的收获

### 一、这篇是"我们要做的那件事"的**唯一直接先例** —— 但它成立的前提恰恰是我们还没有的那一样

我们整个项目的原始命题是「**Agent 能否自主探索出一套扩展思维面、且搜索空间不过早闭合的架构**」。
ADAS 把这句话变成了一个可执行的算法：**Meta Agent Search** —— 一个 meta agent 反复**用代码编程出新的 agent**，
依据是**一个不断增长的档案（archive）里的历史发现**。

关键在于它的搜索空间是**代码**。论文的论证链条是：编程语言是图灵完备的 ⇒ 原则上**任何** agentic system
（提示词、工具使用、工作流、它们的组合）都能被写出来 ⇒ 学习空间原则上无界。

⇒ **这直接命中我们的"搜索空间过早闭合"问题**：我们的路线 C 只有一个 **6 模板的固定菜单**，
**在结构上不可能发现菜单之外的架构** —— 这就是 Lehman/Stanley 说的"域受限"，
也正是 OMNI-EPIC 用来批评 OMNI 的那句"受限于环境生成器的预设分布"。
⇒ ★ **对我们的直接后果**：C 的拓扑枚举**不是 Darwin 完备的**，而 ADAS 之所以能出"跨域可迁移的新颖设计"，
恰恰是因为它的搜索空间**原则上无界**。⇒ 我们要么承认 C 是"域受限的枚举"（那就别宣称"自主探索架构"），
要么把搜索空间升级为**代码**（见下）。

### 二、它的"档案（archive）"就是我们要的"防过早闭合"的机械实现

我们的优化器契约里我写了 L4 元优化，但只写了"在 A/B/C 之上选架构"——**怎么防止搜索收敛到一个点**，
我没写死。ADAS 的答案是：**维护一个不断增长的档案，每次迭代基于全部历史发现生成新 agent**。
⇒ 这在结构上就是"不放弃已找到的行为" ⇒ **过早闭合被档案机制挡住**，而不是靠纪律挡住。

⇒ ★ 对我们最直接的抄法：**我们的"改进步轨迹"本身就是那个档案**。
契约第 ⑦ 条（每次改动的 (θ, θ', VD_net, 反判据, δ, 接受/回退) 全部落盘）—— 如果这条真的执行了，
我们就有了一个 archive，**下一轮可以基于全部历史改动再生成新配置**，而不是从最后一次开始。
⇒ 也就是说：**我们的契约第 ⑦ 条不是"留痕"，是"搜索结构本身"** —— 我之前把它当可观测性写的，定位错了。

### 三、★ 它成立的前提是一个**干净、零噪声的目标函数** —— 而我们的目标函数刚刚被自己测废了

ADAS 的目标是 ARC / GPQA / MGSM 的**任务正确率**：一个标量、可自动判定、重复测量几乎无噪声。
它的搜索信号"这个新 agent 得了多少分"是**可靠的**。

我们不是。我们的主判据（净有效维度增益）刚刚在 U1 批次被自己测出：
**同一批答案、同一判官，只换判官提示词版本 ⇒ 净增益从 `0/+1/−1` 变成 `+1/+4/0`**；
而且 **12 份里 9 份 D=0（地板效应）**。

⇒ ★★ **这是本篇给我们最重要的一课**：**ADAS 的成功高度依赖于"目标函数是可信的"这个前提。**
它没有解决"目标函数不可信"的问题——它假设目标函数是任务正确率，所以它可以直接用。
⇒ 对我们：**在目标函数带宽 > 信号之前，抄 ADAS 只会放大噪声**（优化器会去利用判官提示词版本这个隐藏混淆变量）。
⇒ **⇒ 我们的顺序必须是：先把目标函数变可靠（契约 L0）→ 才轮到学架构（ADAS 式）**。
这跟我之前在优化器契约里写的"L0 是准入券"一致，但 **ADAS 给了它一个名字**：**它是"能不能抄 ADAS"的前置条件**。

### 四、它的"跨域跨模型可迁移"是对我们"过拟合到题集"的正面回应 —— 但它的机制我们用不上

论文最亮的读数：**搜出来的 agent 换域、换模型仍然更强**。这正面回应了我们实测到的
「训练第 1 名在留出里变第 15 名」「Spearman(训练排名, 留出排名) = +0.166」。

但它的机制是**档案里存的是"行为描述 + 代码"**，可迁移性来自**代码的抽象层次**（一个通用的处理流程可以套到别的任务），
而不是来自"训练时没见到测试题"。

⇒ 对我们：**我们的"架构"目前是 prompt 模板 + 固定节点序列**，它的抽象层次比 ADAS 低得多
（我们的"拓扑"只描述阶段与信息可达性，不含可复用的算法结构）。
⇒ ⇒ **如果我们要追求"跨题可迁移的架构"，那可迁移的单元就不是"拓扑菜单里的一个模板"，而是"能跨题复用的那段代码"** ——
⇒ 这提示路线 C 的"拓扑"应该往**可编程的工作流原语**方向走，而不是继续在 6 个模板里挑。

### 五、它自己的警告恰好命中我们的路线 C

ADAS 仓库的 README 有一句显式警告：**代码会执行模型生成的不可信代码，即使在当前设置下不太可能明显作恶，
但仍可能因能力或对齐限制而破坏性地行动**。

⇒ 我们的路线 C 的"受约束提案器"让模型生成拓扑/代码，再由执行器跑起来 —— **这是同一个安全面**。
⇒ 它给出的工程形态是：提案者**默认关闭** + 结构检查器（H1–H6）+ 失败**强制回退到人定默认** + 把回退**记为可报告事件**。
⇒ ★ **我们的路线 C 复核恰好独立得出了一模一样的结论**（提案者默认关闭 + H1–H6 + 强制回退 T2 + 回退可报告）。
⇒ 这是**两条独立路径撞出同一个设计** ⇒ 置信度很高，可以直接沿用。

### 六、"换域评估"在我们这里对应什么？—— 一张很清楚的对照表

| ADAS | 我们的对应物 | 状态 |
|---|---|---|
| 搜索空间 = 代码（图灵完备） | 搜索空间 = ? | ❌ 只有 6 个模板（域受限） |
| 档案 = 历史发现（代码 + 行为描述） | 档案 = 改进步轨迹 | 🔨 契约第 ⑦ 条已有雏形，**但没被当作搜索结构** |
| 目标函数 = 任务正确率（干净） | 目标函数 = 净维度增益 | ❌ **带宽 > 信号 + 地板效应** |
| 跨域/跨模型可迁移 | 跨题可迁移（留出纪律） | ⚠️ 有纪律（留出）但读数 ρ=+0.166 |
| 定制到新域 = 改 `evaluate_forward_fn()` + 加元 agent 可用函数 + 改域信息 | 定制到新题域 = ? | 🔨 我们的 `evaluate` 就是主判据 |

⇒ **最该抄的一条**：**它把"如何把这个算法搬到新领域"写成了三个明确的代码改动点**
（改目标函数、加可用原语、改域提示）。
⇒ 我们的对应写法应该是：**新题域进来时，只需要改三处 —— 判官提示、依据包、结论空间 `C_t`**。
⇒ **这正好可以直接变成我们的 DEV 集设计约束**：DEV 题必须**可判**（有 `C_t`）且**可核验**（有依据包），
否则它进不了我们的搜索循环。

## 一句话
> ADAS 证明"Agent 自主搜架构"是可行的，**但它的可行性建立在"目标函数是干净的任务正确率"上**。
> 我们现在连目标函数都不可信（带宽>信号 + 地板效应）⇒ **它不是我们的路线图，是我们的天花板参照**。
> 可直接抄的三件事：**档案机制**（把改进步轨迹从"留痕"升级为"搜索结构"）、
> **提案者默认关闭 + 结构检查 + 强制回退**（我们独立得出同样结论）、
> **"搬到新域要改哪三处"的显式写法**（⇒ 我们的 DEV 集设计约束）。
