## 1. 核心机制（具体到能照着实现）

| 项 | 内容 |
|---|---|
| **输入** | 环境状态（机器人的传感器读数）。**有状态**：状态 = 迷宫里的 2D 位置 + 身上开了哪些门 + 传感器向量 |
| **状态表示** | **离散的、明确可数的**：<br>· **技能** = 门类型（红/绿/蓝/黄，K=4），"开了一种门"就算获得了该技能<br>· **行为/新颖性计数** = 触碰过的唯一网格 tile 数 t + 打开过的门数 d<br>· **观测** = 6 个方向的距离传感器 + 6 个扇形 tile 传感器（返回该方向的未访问 tile 数）+ 每种门类型 6 个扇形布尔传感器<br>**完全不含向量/树/图** |
| **动作/算子** | ANN 输出：左/右电机（[-3,3]）+ K=4 个开门神经元。开门需 **softmax + 置信度阈值 c=2.0**（最大值必须是次大值的 2 倍）才判定为"开" |
| **过程/回路** | **进化循环**（不是 in-context 循环）：<br>种群 125，**2000 代**，每个实验 **25 次独立运行**；rtNEAT（NEAT 演化）用于 CS / NS；Sferes 用于 TE（MAP-Elites）和多目标（NSGA-II）<br>**适应度（这就是优化器契约里的"目标函数"）**：<br>· **CS**：`f = t + d`（唯一 tile 数 + 开门数）<br>· **CS_O**（消融）：`f = t`（只算 tile）<br>· **NS_E**：endpoint 行为距离（与种群/archive 的平均 Manhattan 距离）<br>· **NS_T**：trajectory 行为距离（**一生**的轨迹）<br>· **CN_E / CN_T**：CS + NS 的**多目标**组合（NSGA-II）<br>· **TE**：Target Endpoints（MAP-Elites 基线，下界）<br>**停止条件 = 代数上限（2000）**；无学习率、无梯度 |
| **输出** | 进化出的**个体**（一个 ANN + 它的基因组）。评价产物 = **这个个体一生里探索的领域比例** 与 **它能开几种门** |
| **谁来评价** | ★ **纯外部、零自评**：环境真值（走到哪了、开了哪扇门）<br>**评价信号怎么回传给搜索**：直接作为**适应度**（NS 则是行为距离 → novelty 分数）交给进化算法。**没有"自评"环节**——新颖性由**环境轨迹**客观决定，不由个体自己说 |

## 2. 关键数字

**实验设置**
- 5 个迷宫（Cross / Finger / Hard / S / Tri），每格有红绿蓝黄门；Cross Maze 模拟 2500 步，其余 **5000 步**
- 种群 **125**，**2000 代**，**每实验 25 次运行**（共 5 个迷宫 × 若干处理 × 25 次）
- 统计：**双尾 Mann-Whitney U 检验**（EA 不正态 ⇒ 论文明确说明为何选它）
- 神经形态：前馈 ANN + sigmoid，权重 [-1,1]，6 距离传感器 + K 门神经元
- 距离函数：平均 Manhattan 距离 `‖a−b‖₁ / k`（论文注明"this has sometimes been mistakenly referred to as Euclidean distance"）

**主指标与读数**

| 读数 | 数值 |
|---|---|
| **CN_T（CS+NS 多目标）** | 探索 **75–98%** 的领域，**显著优于所有其他处理**（p < 0.001） |
| **Cross Maze：CN_T** | 探索**近 90%**，比单用任一算法**多 15–25%**（p < 0.0001） |
| **NS_E（endpoint 版 NS）** | 最好的个体在 **5 个迷宫中有 4 个探索 < 50%** 的领域；与 TE 几乎一样（"just under 40%"） |
| **NS_T vs NS_E** | NS_T 显著更高（p < 0.0001，4/5 迷宫） |
| **多目标的加成** | 探索提升 **20–50%**，且**让 endpoints 与 trajectories 的差异彻底消失**（CN_E vs CN_T，p ≥ 0.05） |
| **TE（基线）** | 显著低于所有其他处理（p < 0.01；整体 p < 0.0001），**探索从未超过 50%** |
| **人工检视量** | **"We manually examined over 500 randomly-chosen CS, NS_E, and NS_T trajectories"** |
| **CS vs NS_T 在 Finger Maze** | 两者都不比对方探索更多，但**仍打平**（p ≥ 0.05） |

**消融（★ 对我们最有用的一组）**
1. **"Do Doors Represent Distinct Skills?"**（去掉门）：
   - 去掉门后，CS 与 NS_T 的探索**几乎翻倍**（p < 0.0001，**Cross Maze 除外**）
   - **且 CS 与 NS_T 的差距几乎完全消失**（整体 p ≥ 0.05）
   - ⇒ 结论：**门确实代表彼此不同的非平凡技能**，而 CS 更擅长获得这些技能
2. **S4 Fig（把门从适应度里拿掉）**：CS_O（`f = t`）**仍以相同速率获得开门技能**（每个迷宫 p ≥ 0.05，整体 p ≥ 0.05）⇒ **"Curiosity Search 不需要直接奖励它应该发展的技能；只要奖励探索就够了"**
3. **S3 Fig（直接测开门技能）**：把进化出的个体放进 4 个只测单一开门技能的小迷宫（250 步、免导航）：
   - CS 个体的**四分位距显著更高**（5 个迷宫中 3 个 p < 0.05）
   - 整体上 **CS 与 CN_T 比单用 NS_T 开出更多种门**（p < 0.001）
4. **迁移实验（跨迷宫）**：
   - **不继续进化**：CS 与 NS_T **打平**（整体 p ≥ 0.05）；CN_T 比其他都**多探索 10%**（整体 p < 0.01）
   - **继续进化**：CS 与 NS_T **无差异**（p ≥ 0.05），且"原探索差异在进化一开始立刻消失"
   - ⚠️ **异常（论文自认无法解释）**：**"Interestingly, while Target Endpoints has consistently explored less than all other treatments, it performs very well after transfer, exploring more than CS and NS_T. We cannot offer a definitive explanation for this occurrence."**（作者猜测是 TE 的轨迹过于笔直 + 多数迷宫起点附近是直走廊）

**成本**
- 无 API 成本（是 EA，不是 LLM）。**计算成本未报**（25 次运行 × 2000 代 × 5 迷宫 × 若干处理；作者提到种群从 250 降到 125 是"to enable a more thorough investigation given our limited computational resources"）

## 3. ★ 它的「成功标准」是什么

**怎么判定自己成功了**
1. **主判据 = 个体一生探索到的领域比例**（外部环境真值：走过的 tile / 全部 tile）
2. **第二判据 = 独立测技能**：把个体放进只测单一技能的迷宫，**看它能开几种门**（S3 Fig）——**这是"另起一个环境复测"，不是自评**
3. **对照组分层**：TE = 极端专门化下界；NS_E = 传统 NS；NS_T = 终身感知版；CS = 本方法；CN = 多目标
4. **有正向判据也有负向判据**：`f = t` vs `f = t + d` 两种适应度都跑，结果定性一致

**否证 / 失败条件**
- ✅ **写得很硬**：多处主动报"没差别"。例如 "**the exploration gap between Curiosity Search and Novelty Search disappears almost entirely**"；"**there is no significant difference (p ≥ 0.05) between NS_T and CS after further evolution**"；"**Curiosity Search matches, but only rarely exceeds, the transfer performance of NS_T**"
- ✅ **主动报告了对自己不利/无法解释的异常**（TE 迁移后反而最好）——并明说 "We cannot offer a definitive explanation for this occurrence"
- ✅ **主动报告了一个削弱自己结论的消融**：去掉门后 **CS 相对 NS 的优势消失** ⇒ 他们没有把消融藏起来

**有没有报告"不可分辨"？**
- ✅ **有，但是"统计不显著"意义上的**：统一用 `p ≥ 0.05` 表述（"no significant difference"），**从不写成"无效应"**
- ⚠️ **但没有**：置信区间、效应量、噪声地板 δ、重复实验的方差报告。⇒ 它比多数 LLM 论文诚实（它真的做了 **25 次独立运行**），但**离"预注册噪声地板"还差一层**。
- ★ **对我们的直接启示**：它的"25 次运行 + Mann-Whitney + 明确报 p ≥ 0.05"是**"测量带宽"意识的最低可用版本**。我们的 DEV 集 n 小，但可以抄这个形态：**每个条件跑 k 次独立重复，并预先写死"p ≥ 0.05 就算不可分辨"这个档位**（我 memory 里的"不可分辨"档约定）。

## 4. 自认的局限（原文优先）

1. **§Curiosity Search 段**：
   > "In this initial paper on Curiosity Search, there is no intra-life reward provided for performing a new action; likewise, skills in this work are acquired across evolutionary time and hardwired into each agent's genome, and agents do not have the ability to learn within their lifetime."
2. **§Curiosity Search 段**：
   > "Because the automatic identification of new and increasingly complex behaviors is not yet technically feasible, we tested a simpler version of Curiosity Search which instead rewards agents for going to many different places."
3. **§Curiosity Search 段**：
   > "In this paper, fitness in Curiosity Search only considers the number of unique behaviors expressed. An agent that learns how to swim and drive has expressed the same number of behaviors as an agent that instead learns how to climb stairs and pick locks; therefore, both have the same fitness. Further, the order of behaviors is unimportant… Consequently, a single fitness score in Curiosity Search might conflate a plethora of diverse agents."
4. **§Methods 问题域段**：
   > "When describing our experiments in this work, we treat skill acquisition and exploration as interchangeable terms because they are highly correlated… However, we note that equating these two concepts may not always be appropriate, especially in domains for which the set of obtainable skills is not necessarily tied to 'going somewhere new'."
5. **§Future Work**：
   > "The experiments in this paper did not examine a problem domain with hierarchical skills. For example, agents do not need to learn how to open a yellow door as a prerequisite to learning how to open a red door."
6. **§Results 迁移段**：
   > "We cannot offer a definitive explanation for this occurrence."（TE 迁移异常）

另有 §Future Work 明确列为未来工作的（本篇未做）：biped 任务、视频游戏、Atari 纯像素、**"to investigate whether Curiosity Search might also aid the accumulation of hierarchical skills"**。

## 5. ★ 对我们项目的可迁移点

### 5.1 ★★★ 抄「**种群覆盖 ≠ 个体承重**」——这是本篇对我们的第一价值
原文（§Maze Exploration，Fig 7b 图注）：
> "the population of every treatment, even those that produce specialists (such as TE), can explore the entire maze, revealing that **population diversity alone is not sufficient to encourage generalists**."
⇒ **"整个臂的输出合起来覆盖了很多点" ≠ "每个输出有多个承重维度"。**
- **省掉什么实验**：我们**不用再做"整体语料的维度并集"**这种读数——它必然虚高。⇒ 我们的 `VD` 必须是**逐输出**计算后再聚合（我们 PROTOCOL 的"双边"设计已接近这个，但要把这条**理由**写进协议，堵住"用并集汇报"的诱惑）。
- **同时**：这也直接支持我们的 U4 校准点（"维度少但承重"优于"维度多但都是花絮"）——**这篇用一个 25 运行的实验给了它跨领域的形式化依据**。

### 5.2 ★★★ 抄「**行为距离必须是"终身"的，不是"终点的"**」
NS_E（终点距离）产出专家（< 50% 领域），NS_T（**整条一生轨迹**）产出通才（p < 0.0001）。
⇒ **判据的作用域必须是"一个个体的一生/一个输出本身"，而不是"一个集合"。**
- **省掉什么实验**：我们的净维度增益（工作流 − 直调）**已经是逐输出配对的**（我们 PROTOCOL §4 的双边设计）——这篇是**外部证据**，说明"逐输出/逐轨迹"这个口径不是我们拍脑袋，是有先例的。
- ⇒ **可抄进协议的措辞**："VD 的计算单元 = 单个输出（一次完整推理），不是输出集合"。

### 5.3 ★★★ 抄「**去掉一个东西，看效应是否消失**」——判"是否真是独立维度"的现成检验法
"Do Doors Represent Distinct Skills?"：把门从环境里拿掉 ⇒ **CS 相对 NS 的优势消失** ⇒ **门确实是彼此独立的技能**。
⇒ 这是我们"承重维度"判定的**现成范式**：
> **"某条信息是不是一个独立维度" = 拿掉它之后，决策/结论是否改变。**
- **省掉什么实验**：我们不用再设计一套"这条信息重不重要"的启发式；直接做**依据包条目的 leave-one-out**：从依据包里去掉第 k 条 ⇒ 重新跑 ⇒ 看该条的承重判定是否消失/结论是否改变。**n 条 = n 次消融**（用小 DEV 集可承受）。
- 这与我 memory 里"换值后痕迹必须同步变"是同一族判据，**但这篇的版本更便宜**（不需要第三方追问，只要看结论变没变）。

### 5.4 ★★ 抄「**把多样性当 helper objective，而不是主目标**」
CN_T（CS + NS 多目标）**在几乎所有指标上最好**（75–98% 领域，Cross Maze 比单用多 15–25%），而且**多目标让"endpoints vs trajectories"这个原本重要的差异消失**。
⇒ **路线 C 的具体配方**：`主目标 = VD_net（承重维度）`，`辅助目标 = 多样性/新颖性（去冗余项）`，**用 NSGA-II 式的多目标而不是加权求和**。
- **为什么是 NSGA-II 而不是加权和**：加权和会让我们在权重上调参（= 我们坑 ⑤ 缺"优化策略"的另一个形态）。多目标 Pareto 前沿让我们**不用拍权重**。
- ⚠️ **但要小心**：多目标会引入**Pareto 前沿选择**这一步 = 又要一个"选哪个"的问题 ⇒ 会撞上我们坑 ①（**线性策略里"与 op 无关的特征"对选择零作用**）——**Pareto 选择如果基于与 op 无关的特征，就等于没选**。⇒ 我们的多目标必须保证**至少有一个目标与 op 绑定**。

### 5.5 ★★ 抄「**适应度不该直接奖励你想让它发展的技能**」
S4 Fig：`f = t`（只算 tile，不奖励开门）**仍以相同速率获得开门技能**（每个迷宫 p ≥ 0.05）。
⇒ **"只奖励探索，技能会作为副产品出现"** ——这是对我们"维度"设计的一个**反向提示**：
> 如果我们把"目标维度的种类"直接写进奖励/依据包，模型可能只是**照着奖励学**，而不是**真的展开思维面**。
⇒ ⇒ 我们的依据包应当**只提供"世界是怎样的"，不提供"你应该想到哪几点"**。这与我们的"承重/远/有用"三问句是一致的（"有用"是准入，"远"是去冗余），但这篇补上了**"别把目标结构写进提示"**这一条。

### 5.6 ★ 抄「**把技能做成离散、可数、可独立复测的类型**」
门 = 4 个可数的技能类型，个体"会几种"是一个整数；S3 Fig 用**另一个环境**复测每个技能。
⇒ 我们的"维度"如果要做迁移/泛化测试，需要**类似的"另一个环境复测"**：把提取出的承重维度**在新题上复测**（新题上该维度是否仍承重）。我们 PROTOCOL 里 DEV/TEST 分离是同一个思路，这篇给了它一个更具体的形态。

## 6. ★ 不可迁移 / 会误导我们的点

1. **★ 它没有"信息维度"这个概念，只有"行为种类数"。** 它的"维度" = **离散的技能标签**（红门/绿门/蓝门/黄门），**在构造时就被人工枚举好了**。⇒ 我们不能把"t + d"这类计数当成"有效信息维度数"：**我们不知道哪些维度"承重"**（它知道，因为每种门对应一个可独立复测的技能）。
   ⇒ **但这恰恰是它的可迁移点 5.3 的价值**：它的"技能可独立复测"就是我们的"承重"的操作化。

2. **★ 它的适应度会"conflate a plethora of diverse agents"（自认第 3 条）**：一个会游泳+驾驶的和一个会爬楼梯+开锁的，适应度**完全相同**。⇒ **单一标量适应度丢掉了"维度之间的结构"**。我们的 `VD_net` 如果压成一个标量，会犯同样的错 ⇒ ⇒ **我们必须保留逐维度的明细表（哪些维度承重、依据是什么），不能只报一个 VD 总数**。★ 这是本篇对我们最直接的一条警告。

3. **★ 它是 EA，不是学习算法。** "skills are acquired across evolutionary time and hardwired into each agent's genome, and agents do not have the ability to learn within their lifetime"（自认第 1 条）。⇒ **它与我们的路线 B（训练架构）不同构**：我们要在**一个模型内**跨轮次累积状态，它是在**种群内**累积基因组。⇒ 它的"个体一生"这个类比，在我们的语境下对应的是"**一次任务内的多次尝试**"或"**一次会话内的多轮**"，**不是**"参数更新"。⇒ 迁移时这个类比要小心。

4. **★ 它的"个体"边界 = 一次模拟（2500/5000 步）**，与我们"一次输出 = 一次完整推理"**量纲不同**。它的"探索领域比例"是**空间覆盖率**；我们的"维度数"是**语义信息量**。⇒ **指标不可互换**。

5. **★ 它没有 embedding，没有语义距离**（✅ 不撞 embo-01）。它用网格 tile + Manhattan 距离。⇒ 这一点上它是**干净的**。但反过来说：**它没有回答"怎么自动识别新颖行为"这个真问题**——它自己说 "the automatic identification of new and increasingly complex behaviors is not yet technically feasible"，用的是**人写死的门类型**。
   ⇒ ⇒ **对我们的警告**：我们的"依据包"如果也是人写死的维度清单，我们就是在做"Curiosity Search 的 f = t + d"——**人写死的维度清单 ⇒ 计数容易，承重未证**。**我们必须比它多做一步：leave-one-out 复测（5.3）。**

6. **⚠️ 它的"技能 = 探索"是作者自认的简化**（自认第 4 条）。⇒ 我们的"维度 ≠ 承重"绝不能像它那样偷换。

7. **⚠️ 效应量口径**：它只报 p 值区间与描述性百分比，**不报 CI**。⇒ 我们抄它的形态时，必须补上 CI（我 memory 里的"两个独立实现复算取严"）。

8. **⚠️ 计算成本未报**，且作者明说是为了省算力把种群从 250 降到 125（"preliminary experiments found no qualitative difference"）。⇒ 抄它的实验规模时要注明这个前提。

9. **⚠️ "stepping stone" 的概念与我们"承重"的定义存在张力**（§Future Work 引 Innovation Engine 的结论）：*"rewarding all of these stepping stones led to higher performance for any specific objective than could be obtained by an EA rewarding only that objective"*。
   ⇒ **一个"当前不改变结论、但让未来结论变得可能"的维度，按我们的承重判据是不算维度的**，但按这篇的证据它可能很有价值。⇒ **我们必须显式决定：VD 算不算"阶梯石维度"？** 这是一个**要写进协议的概念岔口**，不是可以回避的问题。

## 7. 逐字摘录

1. **§Results「Novelty Search Specialization」**（种群 vs 个体）：
   > "Although a population in the endpoints version of Novelty Search explores everywhere (Fig 4a), a typical individual only explores a single branch (Fig 4b)."
2. **§Conclusions**（核心否定式结论）：
   > "encouraging population diversity is not sufficient to produce generalists—specialists inherently do 'different things' from one another and are thus rewarded by the algorithm."
3. **§Results「Do Doors Represent Distinct Skills?」**（leave-one-out 范式）：
   > "we found that both CS and NS_T agents explore nearly twice as much of their environment when the doors are removed (Fig 8, p < 0.0001 except for the Cross Maze, in which there is no significant change).    > "Similarly, Innovation Engines attempt to maximize performance on a wide range of objectives; however, it was found that rewarding all of these stepping stones led to higher performance for any specific objective than could be obtained by an EA rewarding only that objective [27]."

## 8. 读完后我自己的一句判断

- **最值得抄的**：**"去掉它，看差异是否消失"这个判据**（Do Doors Represent Distinct Skills? 那一节）。它把"这是不是一个真正独立的维度"这个哲学问题，压缩成了一次**可执行的消融**。我们"承重"判据一直缺一个这么硬的操作化——而我们的依据包是条目级的，**天然适合做 leave-one-out**。⇒ 这一条能直接省掉我们一整轮"怎么论证一条信息是承重的"的争论。
- **最容易骗我们的**：**"t + d" 这种"数一数有多少种行为"的形态**。它太干净了：一个非负整数 = 适应度 = 优化目标 = 成功判据，全部对齐。而我们的项目里，**最难的部分恰恰是"什么算一个维度"**——Curiosity Search 是**先把技能人工枚举好**才拿到这个干净计数的。⇒ 如果我们照抄"数一数有多少条不同的事实"，就会把**"依据包里写了几个条目"**当成"思维面有几个维度"——**这是我们 PROTOCOL 明确拒绝的（花絮膨胀 F3-a）**。它**恰恰没有**回答"哪些条目承重"这个问题，因为**它不需要回答**（门是不是技能，是可以用另一个环境复测的；而我们的自由文本条目不行）。⇒ 抄它的**判据形态**（leave-one-out + 另一个环境复测），不抄它的**计数口径**。
