# 09 — Self-Discover

## 0. 引用
- **标题**：Self-Discover: Large Language Models Self-Compose Reasoning Structures
- **作者**：Pei Zhou, Jay Pujara, Xiang Ren（USC）; Xinyun Chen, Heng-Tze Cheng, Quoc V. Le, Ed H. Chi, Denny Zhou, Swaroop Mishra, Huaixiu Steven Zheng（Google DeepMind）
- **年份**：2024（arXiv v1 2024-02-06）
- **venue**：**ICML 2024**（论文 Keywords 字段自述 "Machine Learning, ICML"）
- **arXiv id**：arXiv:2402.03620v1 / CC BY 4.0
- **一句话**：它声称——**不用标签、不用训练**，让 LLM 在**任务级**先"自己发现"出一个由原子推理模块（critical thinking / step-by-step / …）组合而成的**显式推理结构**（JSON 键值对），再让 LLM 按这个结构逐题作答，就能比 CoT 高最多 32%，且比 self-consistency 类推理密集方法**省 10–40 倍算力**。

> 读法提示：**这是 6 篇里最容易被误读成"路线 B/C"的一篇**——它确实"发现"了结构，但**发现出来的东西是自然语言**，且**发现阶段没有反馈信号、没有搜索、没有迭代**。第 5/6 节请重点看。

## 1. 核心机制（具体到能照着实现）

| 项 | 内容 |
|---|---|
| **输入** | 任务 + **几个无标签任务样例** `t_i ∈ T` + 一个**原子推理模块的自然语言描述集合 D**（论文里 D 有 **40 个模块**，如 "critical thinking" / "break the problem into sub-problems" / "reflect on task nature" / "creative thinking" / "let’s think step by step" / …）。<br>★ 注意：**不用标签**（"no labels or training required"）。 |
| **状态表示** | **JSON 风格的 key-value 对**（论文："We format the structure in key-value pairs similar to JSON due to interpretability and findings on following JSON boosts reasoning and generation quality"）。<br>结构 = **一个有序的步骤序列**，每步 = `{"step_1": "...", "step_2": "...", ...}`。★ **状态载体是自然语言文本**，不是符号结构。 |
| **动作/算子** | **Stage 1 的三个 meta-prompt 动作**（固定 3 个，无搜索空间、无采样、无打分）：<br>1. **SELECT**：`D_S = 𝒜(p_S ‖ D ‖ t_i)` —— 从 40 个模块里挑子集 `D_S`。<br>2. **ADAPT**：`D_A = 𝒜(p_A ‖ D_S ‖ t_i)` —— 把每个选中的模块**改写成任务特定**的描述。<br>3. **IMPLEMENT**：`D_I = 𝒜(p_A ‖ S_human ‖ D_A ‖ t_i)` —— 把改写后的描述**实例化**成一个可执行结构。★ 这里的 prompt 里**塞了一个手写的人类推理结构示例 `S_human`**（来自另一个任务）作为 few-shot 引导。<br>（论文原式 (3) 写的是 `p_A`，应为 `p_I`——**原文笔误**。） |
| **过程/回路** | **两阶段，单向，无回路**：<br>• **Stage 1 = 任务级**，**每个任务只跑一次**（"we only need to run Self-Discover once for each task"），**3 次额外推理**。<br>• **Stage 2 = 实例级**：`A = 𝒜(D_S ‖ t) ∀t∈T` —— 把结构塞进 prompt，让模型**逐个 key 填值**直到出答案。<br>**停止条件**：Stage 2 是**单次生成**，结构里的 key 填完即止（"filling each key and arrive at a final answer"）。**没有迭代、没有回溯、没有基于分数的重试。** |
| **输出** | 每个任务的**一个** JSON 推理结构（可解释、可跨模型迁移）+ 每题的最终答案。 |
| **谁来评价** | **外部 oracle（gold labels）**：BBH / T4D / MATH 的**准确率**。**不是 LLM 自评**。✅ <br>**评价信号怎么回传给"搜索"**：**不回传**。Stage 1 完全没有反馈环——**选模块、改写、实例化都是一次性的 meta-prompt 生成，没有"哪个结构更好"的信号用来改结构**。<br>唯一的"回传"是**人工/自动的错误分析**（Appendix D），是**事后**的，不参与生成。 |

**★ 一个容易被漏掉的结构性事实**：Stage 1 的输入是 `D`（40 个固定模块）+ `t_i`（无标签样例）。**这意味着"发现"出来的东西完全由这 40 个先验 + 模型的先验决定**，不是由任何 reward 决定的。**这在拓扑来源上等价于路线 A（人给定的先验池）+ 一次 LLM 组装，不是路线 B（训练学出）。**

## 2. 关键数字

**实验设置**
- **25 个任务** = BBH **23 个**任务（零样本）+ **T4D**（Thinking for Doing，grounded 社会推理）+ **MATH**（从测试集**抽样 200 题**；MATH 特殊：**用 one-shot 演示生成 instance-level 结构**）。
- 模型：**PaLM 2-L** 与 **GPT-4**（另用 GPT-4 结构 → Llama2-70B / GPT-3.5-turbo 做迁移测试）。
- 指标：**accuracy**。

**Table 1 主结果（逐字）**
| Method | BBH | T4D | MATH |
|---|---|---|---|
| PaLM 2-L | 56% | 30% | 45% |
| PaLM 2-L + CoT | 60% | 40% | 42% |
| PaLM 2-L + PS | 61% | 42% | 49% |
| **PaLM 2-L + Self-Discover** | **67%** | **69%** | **50.5%** |
| GPT-4 | 58% | 51% | 70.5% |
| GPT-4 + CoT | 75% | 52% | 71% |
| GPT-4 + PS | 73% | 53% | 70% |
| **GPT-4 + Self-Discover** | **81%** | **85%** | **73%** |

- **BBH 23 题聚合**：PaLM 2-L **+7pt** vs CoT、**+6pt** vs PS；GPT-4 **+6pt** vs CoT、**+8pt** vs PS。
- **T4D**：PaLM 2-L **+27pt**、GPT-4 **+32pt**（相对所有基线）。
- **MATH**：PaLM 2-L **+1~7pt**、GPT-4 **+2~3pt**（论文自称 "a moderate gain"）。
- **逐任务**：Self-Discover 在 **23/25 任务上优于 Direct Answering**、**21/25 任务上优于 CoT**（PaLM 2-L 零样本）；**最大单任务增益 42%**。
- 摘要口径："by as much as 32% compared to Chain of Thought"；结论节口径："improvements … up to 30%"。⚠️ **两处口径不同**（32% vs 30%），且"32%"与"42%"混用。

**错误分析（Appendix D）**
- PaLM 2-L 生成的推理结构**有 87.5% 的情况下是正确的**（"human experts can follow the reasoning structures to solve the tasks perfectly"）。
- **74.7% 的失败来自计算错误**（math 等），不是结构错误。

**消融（Figure 8）**
- 三个动作逐个加：**−S → −SA → 全三个 SAI**，准确率**单调上升**（4 个任务，GPT-4）。
- ⚠️ **Figure 8 是图，正文没有给出任何数值**。⇒ 消融只有定性方向，无量化读数。

**效率（Figure 5）**
- Self-Discover：**每实例 1 次推理调用** + **任务级 3 次 meta-prompt**；CoT-SC：**10×**；每个 RM 多数投票：**40×**。
- 论文自认："We acknowledge that Self-Discover input and output are longer than CoT and Direct prompting, increasing cost."

**迁移实验**
- PaLM 2-L 发现的结构 → GPT-4：Self-Discover **在 4 个任务中的 3 个上优于 OPRO**，而 **OPRO 用了 20% 的数据**做 prompt 优化（Self-Discover 零样本）。
- GPT-4 发现的结构 → Llama2-70B：**52% vs CoT 42%**（disambiguation QA）；→ GPT-3.5-turbo：**56% vs CoT 51%**（geometry，3-shot）。

## 3. ★ 它的「成功标准」是什么

**它怎么判定自己成功了？**
- **主判据 = 准确率 vs 固定基线**（Direct / CoT / PS），外加**效率判据 = 每实例推理调用数**。
- **没有任何绝对阈值**——"成功"= 在 25 题中的多数题上比 CoT 高。它是**相对判据**。
- **第二判据 = 消融的定性方向**（三动作单调有益，Figure 8）。
- **第三判据 = 跨模型迁移**（结构能不能换模型继续用）。

**它的否证/失败条件有没有写？**
- **部分有**：
  - **MATH 上收益"moderate"**（+1~7pt），且 §4.2 承认 **algorithmic 类别增益中等**，与 MATH 观察一致——即"**结构化推理对世界知识类任务帮助最大，对算法/计算类帮助最小**"。
  - **失败归因明确**：74.7% 的失败是计算执行错误，不是结构错。
  - **"Llama2 自己发现结构失败"**：脚注 3："We tried zero-shot meta prompting Llama2 but observed low-quality structure outputs."——⇒ **发现能力依赖模型档位**。
- **没有写的**：没有"在什么条件下 Self-Discover 会输给 CoT"的判据；没有任务难度/规模的失效边界；没有消融的数值门槛。

**它有没有报告"不可分辨"这种结果？**
- **没有。** 全文**无置信区间、无重复采样、无显著性检验、无噪声地板 δ**。
- 唯一接近"不可分辨"意识的是 **MATH 区间 +1~7pt** 被显式标注为 "moderate"，以及 **BBH 23 题逐题结果放在 Appendix C Table 3**（提供逐题读数，读者可自行看哪些题的差异可能是噪声）。
- ⚠️ **对我们**：我们的效应量是**离散计数（维度数）**，可能是 0/±1 的差异。**Self-Discover 的"21/25 题上更好"这种计数式结论，恰好是最容易被我们误用的形式**——它看起来像"信号"，但 21/25 在 n=25、且差异幅度未给定的情况下，**无法区分"稳定 +2pt"和"随机抖动"**。

## 4. 自认的局限（原话优先）

1. **长度/成本不自洽**（Figure 5 题注）："We acknowledge that Self-Discover input and output are longer than CoT and Direct prompting, increasing cost. However, as the number of instances increases, the efficiency of Self-Discover in terms of inference per instance is highly desirable."（⇒ **单实例更贵，摊薄后更便宜**。）
2. **发现能力有门槛**（脚注 3）："We tried zero-shot meta prompting Llama2 but observed low-quality structure outputs."
3. **算法类任务收益有限**：§4.1 "For MATH, we observe a moderate gain of 1%-7% (2%-3%) on PaLM 2-L (GPT-4)"；§4.2 "We observe the gain on the Algorithmic category is moderate, consistent with the findings from Sec. 4.1 on MATH."
4. **失败主要在执行层不在结构层**：§4.1 "The majority of the failures (74.7%) comes from errors in executing the computations."
5. **依赖人给的先验池**：§1 "From a set of atomic reasoning modules described in natural language such as 'breakdown into sub tasks' and 'critical thinking'"——**40 个模块是人写的**（Appendix A 列全），**不是一个可学习/可搜索的动作空间**。
6. **IMPLEMENT 阶段用了人写示例**：Appendix A 的人类推理结构 `S_human` 是另一个任务上的手写结构——**人仍然在给先验**。

## 5. ★ 对我们项目的可迁移点

**映射：路线 C（人定拓扑 + 训练调参数）—— 最接近的一篇**

- **★ 最有价值的一条：把"拓扑"从"一串提示词"里**显式化**出来。**
  Self-Discover 的贡献不在于答案变好，而在于**它逼出了一个显式的、可读的、可跨模型搬运的"步骤结构"对象**。这正是我们要的"拓扑"的雏形。
  → **能省我们什么**：省掉"**怎么把拓扑表示出来**"这个前置问题的探索。我们可以直接采纳它的表示：**有序步骤 + 每步一个自然语言描述**（JSON key-value）。
  → **要改什么**：⚠️ 我们的判据载体必须是**结构**（坑 ③：措辞级相似度在改写型环节彻底失效）。Self-Discover 的结构**内容是措辞**，所以：
  - 它的"结构"只能当**拓扑的载体**（有哪些步骤、什么顺序）；
  - **不能**用它来论证"结构变了 ⇒ 信息维度变了"，因为两个结构之间可能只是措辞不同；
  - 我们需要给每一步**再挂一个结构化标签**（这一步消费了哪一条承重信息 / 作用于哪个子目标），才能让"维度"可数。

- **★ 任务级（task-level）发现 vs 实例级（instance-level）执行，这个分层值得抄。**
  它把"贵的那部分"（选结构）**摊到整个任务上**：3 次 meta-prompt 服务于 N 道题。
  → 对我们的意义：如果我们的路线 C/B 要学"操作序列"，**学一次、用 N 次**（或学一次、迁移到留出集）是让算力可接受的关键。
  → **但要注意它的反面**：任务级结构**天然过拟合到该任务的分布**。我们的坑 ⑦（特征必须与题无关；实测「训练第 1 名在留出里变第 15 名」）**在这里是直接命中的**。⇒ 我们必须做**留出任务**上的迁移实验，像它 §5.2 那样把"在 A 任务发现的结构用到 B 任务/另一个模型"。

- **★ "效率"作为并列判据，值得抄成我们的第二根轴。**
  它报"每实例调用数"（1 vs 10 vs 40），逼得 CoT-SC 显得不划算。⇒ 我们的净维度增益**必须同时报调用数/token**。
  → 更狠一点：Self-Discover 的读数**不是等 token 配平的**（它自己承认输入输出更长）。⇒ **我们不能直接引用"32% 优于 CoT"作为"结构有增益"的证据**，因为**一部分增益可能只是"多写了一段任务特定的提示"**。★ 这条必须写进我们的复现清单。

- **DEV 集设计**：它的 **BBH 23 题 + T4D + MATH 200** 是个"**每类问题都留了逐题表（Appendix C）**"的设计——**逐题读数随论文发布**，这是好习惯。我们的对照报告应该照做。

- **优化器契约 L0–L4**：它只有 **L0（人给模块池）+ L1（一次性组装）**，**没有 L2/L3/L4**（无迭代改结构、无打分选结构、无更新规则）。⇒ **它没有回答我们的核心问题"结构从哪来"。**

## 6. ★ 不可迁移 / 会误导我们的点

1. **★ 最容易骗我们的点：它看起来像"模型自己学出了拓扑"，实际是"模型在 40 个词先验里挑词并改写"。**
   - 40 个原子模块是**人写的自然语言**（Appendix A）。
   - Stage 1 **没有任何 reward/打分/选择压力**，三个动作各是一次生成。
   - IMPLEMENT 还额外塞了**一个人写的人类结构示例**。
   ⇒ 严格说，**它的结构空间是人给定的先验池上的一个子集**，且**选择标准是 LLM 的语言直觉，不是任何可核验的信号**。
   → 对我们：**不能引用它说"结构可以由模型自动发现"**。可以说"**结构一旦被写出来，跨模型迁移比优化过的 prompt 更稳**"（§5.2 的 3/4 胜 OPRO 是它最扎实的一条）。

2. **★ 措辞级混淆（我们的坑 ③ 的正面命中）。**
   Self-Discover 的"结构"每一步都是自然语言。两个不同任务学出来的结构，在**语义上可能一样、在措辞上完全不同**。
   → 我们若要度量"结构带来的信息维度"，**判据必须落在步骤的符号骨架上**（有哪些步骤、顺序、依赖、每个步骤消费什么），**不能落在文本相似度上**。否则就会重蹈我们自己的 embo-01 覆辙（27 条断言压成 1 条）。

3. **★ 自评污染检查（模板第 6 节专门项）：本篇基本干净。**
   ✅ 主判据是 BBH/T4D/MATH 的 **gold label 准确率**，判官与被测不同源。
   ✅ Stage 1 明确用**无标签样例**（"task examples without labels"），不偷答案。
   ⚠️ 唯一的人评环节：MATH 的 "structures generated … are correct 87.5% of the time: **human experts can follow the reasoning structures to solve the tasks perfectly**"——这是**人工评估**（少量、非盲、样本量未给），只能当旁证。
   ⚠️ 结构性自评：结构由模型 M 发现、又由 M 执行（Self-Discover vs Self-Discover 的"自洽性"没被任何外部信号检验）。它靠**不同模型之间迁移**（PaLM 2-L→GPT-4）来部分排解，但**这仍不是独立判官**。

4. **★ 判据载体检查（embedding/相似度）**：**本篇全文没有任何 embedding 余弦、没有语义相似度**。结构靠 gold label 判定。✅ **对我们无害，也是本批 6 篇里判据最干净的一篇。**

5. **量纲不可比**：BBH/T4D/MATH 的准确率是**任务正确率**；我们的"维度"是**承重信息条数**。**21/25 题更好、+7pt** 这类读数**不能**转成"我们的拓扑多了 X 个维度"。

6. **效率声明需要打折**：它的"10–40× 更省"是**推理调用数**口径，而它自认**输入输出更长**。⇒ 换成 token 口径，优势会被压缩。**我们复现时必须同时报调用数与 token。**

## 8. 读完后我自己的一句判断

**最值得抄**：**"把拓扑写成一个显式的、可搬运的步骤对象，并且把'贵的那部分'摊到任务级"**——外加**它把每题读数全量放进附录**的评测纪律。抄这两条，我们能省掉"拓扑表示形式"和"消融报告形式"两个前置探索。

**最容易骗我们**：**它"自动发现"的是措辞，不是结构。** 40 个模块是人写的先验池，Stage 1 没有 reward、没有选择压力、还额外塞了人手写示例。我们如果照着做"让模型自己发现承重信息维度"，得到的会是**一段看起来很有道理的自然语言**，而我们的判据一旦落回措辞，就会重蹈 embo-01 的 27→1。⇒ **它的"结构"必须被剥成符号骨架再用；它的 21/25、+7pt、+32% 一律不能当成"维度增益"的量级参照。**
