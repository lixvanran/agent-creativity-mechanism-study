## 1. 负责人拍板之后，什么变了

**"思维面 = 有效信息维度数"** ⇒ 一切以"**这条信息能不能改变一个决策/结论**"为准绳。

这带来三个连锁后果：

1. **"条数"彻底失去合法性**。字数、断言数、角色数、提示词差异、表面新颖性 —— 全部不是维度数。
2. **"维度少但承重"是合法的，甚至更好**。锚点就是**用户四道题里的 U4（气质量表）**：
   它的有效维度可以只有 1–2 条（量表计分规则 + 四类得分比较），但**能推出结论**；
   再往上加的（负号含义说明、性格描述、适用人群科普、免责建议）**都不改变结论** ⇒ 不算维度。
   ⇒ **一条承重规则 > 十条不能改变任何决策的花絮。**
3. **代价侧必须进目标函数**。Mednick 双条件是**合取**，"远"和"有用"缺一不可；
   而"有用"必然带成本 ⇒ 目标不是无约束最大化，是**约束优化**。

## 2. T0 · 共享测量协议（三条路线的地基）

### 2.1 核心设计

| 要素 | 协议的规定 |
|---|---|
| **"维度"的单位** | **一张维度卡片**（1 card = 1 dimension）。**不是**断言、**不是**依赖组 |
| **单调不等式** | `维度数 ≤ 卡片数 ≤ 断言数`，且这个方向**永远不可被反向利用**（拆卡灌水换不来维度数） |
| **准入（承重检验）** | 写不出"它改变了哪个决策/结论" ⇒ **不是维度，只是内容** |
| **去冗余（"远"）** | 边际增益 `Δ(A→B) = D(A∪B) − D(A)`；**Δ=0 ⇒ 冗余**（与已有维度不互补） |
| **"有用"** | 准入项：能否被依据包核验（事实/推论/价值判断/建议 分层） |
| **U4 校准（事前写死）** | 有效维度数 ∈ **[1,4]**；>4 = 花絮膨胀（判死）；<1 = 未承重（判死）；且必须命中"多血质" |
| **主判据** | 净有效维度增益 = **新增 − 丢失**（双边）＋ **必须同时报绝对条数与分母** |
| **等预算对照** | **B0** 直调 / **B1** 等调用数 / **B2** 等 token / **B3** best-of-N（**只能由外部核验器选**） |
| **评分对象** | **事前选定 = 机械答案**（合成答案会把"选哪些维度进答案"这层差异混进来） |
| **统计单位** | **任务**（不是同题多步 rollout） |
| **否证条件** | **F1–F8**，每条都配了**具体触发数据**（含"可触发例子 1–4"） |
| **护栏** | **G1** 维度≠条数 / **G2** 花絮率不涨 / **G3** U4 不膨胀 |

**★ 可达性论证（很漂亮）**：为什么 target 状态只开 2 个？
因为按 v2 的候选规则，`VERIFY` 的 target 恒为"未核验"、`SPLIT` 的 target ∈ {未核验, 未提及}、
`EXTRACT` 的 target 是 ANSWER 节点 ⇒ **"支持"与"矛盾"的断言在结构上永远不会成为 target**
⇒ 为它们开维就是**再造一个 `f[5]` 式的死维**。

### 3.3 路线 C · 先设计再训练（人定拓扑 + 训练调参数）

**三层分离（判据可机械核对）**：
> 一个元素属于**拓扑**当且仅当：改变它会改变"有哪些阶段 / 谁能看到什么"；
> 属于**参数**当且仅当：改变它**不会**改变这些，且取值域是区间或有限档位；
> **既不是拓扑也不是参数的，是"冻结资产"**（内容类选择，训练前冻结、所有臂共用）。

| 层 | 规模 | 内容 |
|---|---|---|
| **拓扑** | 8 项 | 阶段集合与顺序 / 有无核验阶段 / **信息可达性矩阵** / 装配策略 / 有无拆分回环 / 有无停滞重分配 / 有无坍缩检测 / 生成路数是否可配 |
| **参数** | 12 个标量 | `n_frames`、`theta_util`、`theta_dist`、`n_verify_max`、`theta_collapse`、`m_clusters`… |
| **冻结资产** | 跨模板不变 | 6 个认知位置清单、提示词模板、装配模板、字数上限 |

**★ 漂亮推论**：**拓扑决定有哪些参数可调**（默认 T2 下只有 7 个参数活着；P6–P10 只在 T3/T4/T5 存在）
⇒ 换模板 ⇒ 可调参数集变 ⇒ **跨模板的参数值不可直接比较**。

**核心论点**：C 的真正增量不是"更好的架构"，而是
**让"人定拓扑"这一步本身成为可操纵的自变量** ⇒ 有了否证程序（**A/B 都给不了**：A 的先验不可检验、B 的图结构与权重纠缠）。

**提案器模式的根因修复**：行动空间说明书全文 + 可见(3 类结构性)/禁止(5 类含一切 oracle 统计)清单 +
结构检查器 H1–H6 + 修复 ≤2 次 + **强制回退 T2**
⇒ 把"矛盾率约束"从**提案者自觉**搬进**执行器/参数训练** —— 这正是本项目"3 轮 5 份提案全被否"的根因。

## 4. 三路线对照决策矩阵

| | **A 设计架构** | **B 训练架构** | **C 先设计再训练** |
|---|---|---|---|
| **谁决定架构** | 人（写死拓扑） | 训练（策略学出） | 人定拓扑 + 训练调参数 |

| **怎么被否证** | 与等预算多次采样比，净维度增益不显著 | 留出集不优于随机/固定；或只改了行为没改内容 | 与 A/B 对比**分离不出"拓扑"这一项的贡献** |
| **特征空间** | 不用策略特征 | **14 → 30 维**（旧权重作废） | 拓扑冻结 + 12 参数 |
| **可执行性验证** | 12 次 MiniMax 冒烟 | 14 次 MiniMax 冒烟 + 8/8 变异注入 | 13 次 MiniMax 冒烟 + 拓扑检查器 H1–H6 |

**我的判断（供你参考，不替你定）**：
三条路线**不是互斥的**，而是**互补的三层**：
- **A** 回答"**人能不能设计出比直调更宽的架构**"
- **B** 回答"**机器能不能自己搜出这样的架构**"
- **C** 回答"**人定拓扑 + 机器调参数，是不是最好的分工**"
⇒ **C 最有希望成为主路线**（因为它是**唯一有否证程序**的），但 **B 是唯一能证伪"人定拓扑到底有没有用"的那条**
⇒ 建议三条**都跑**（它们共用同一把尺子、同一批对照片），**这正是你今晚要的三条并行**。

| **1** | **f[6] 索引冲突** | `f[OPS.index(op)]=1.0` 写进 f[6]，随后 `f[6]=min(depth/6,1)` 覆盖 ⇒ `STOP 在 depth=3 时 f[6]=0.5`（应 1.0） | **STOP 永远选不中**；且 depth 成了公共常数 ⇒ **在 softmax 里完全抵消** ⇒ 这一维是废的 |
| **2** | **策略塌缩 ⇒ 权重冻结** | 修前轮2：**50 步全是 GEN_PLAIN**、轮1→2 ‖w‖ **一模一样**（0.1129） | 我起初说"τ=0.02 下信号 0.09 太小 ⇒ 几乎均匀" —— **方向反了**，实际是**太锐**（n_eff 只剩 **1.19**）⇒ 改成**先标准化分数再除 τ**（尺度无关）⇒ ‖w‖ 放大 **64 倍**后 n_eff 极差 **0.0000** |
| **3** | **线性策略里"与 op 无关的特征"对选择零作用** | ① 同 target 换 op ⇒ f[7..13] **完全相同** ⇒ 得分差恒为 **0.02700**（只来自 op one-hot）② target 分差对**所有 op 同时**发生 ③ 加"全局缺口特征" ⇒ **argmax 三个状态全不变** | **GPT6 建议的"14→17 维加全局缺口特征"是无效的**（除非做成 op×target 交叉项）—— **我写进路线 B 任务书的同一句建议也无效，我犯了同一个错** |

**第 3 条的一般化判据（可复用）**：
> 在"状态内对候选集打分"的线性策略中，**只有"在同一状态的不同候选之间会变"的特征才能影响选择**。
> 任何**状态级**（op 无关）特征 —— depth、CLAIM 总数、图大小、步数 —— 在加性线性模型里**对选择行为零作用**。
> ⇒ 这与 f[6] 冲突是**同一族病**：「加了但没起作用」。

**连带结论（把假设变成可被否证的预测）**：
本轮 8 轮重训用 14 维**纯加性**特征 ⇒ **在结构上不可能产生状态依赖的策略**
⇒ 它只能作为「纯加性 ⇒ 只能学到风格、学不到适应」这一命题的**对照实验**，
**不能**作为"学到了架构"的任何形式的证据。（路线 B 已把它写成**预注册预测 P-1**。）
