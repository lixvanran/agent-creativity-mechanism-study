## 0 · 这份规范要解决什么

三组（`docs/cmp8/routes/C/optimizer.py:75`）给的族键口径是 3 行字符串操作：

```python
def family_key(card: dict) -> str:
    return "|".join(sorted(card.get("supports_conclusions") or []))
```

★ **但归并的语义在判官那一半**：判官给每条候选陈述打 `supports_conclusions = ["C3", ...]`（**题级预注册的结论编号**）。
⇒ ⇒ **复现这套口径 = 复现判官那一半，不是复现函数那一半。**
⇒ ⇒ ★ **硬前提**：**每题必须有题级预注册的结论空间** ⇒ **不是自动的**
⇒ ⇒ ★ **「两派相反答案」能否被识别，取决于结论空间里是否同时列了这两派** ⇒ **报读数必须写明这一点**

本规范定义：**结论空间怎么写、怎么传给判官、族数怎么数、空族怎么办、怎么验收。**

## 1 · 结论空间的定义

> **题级结论空间** = 该题**事先**写死的、**互斥**的**候选结论集合**，每条带一个稳定编号 `C1..Cn`。

| 字段 | 必填 | 含义 |
|---|:-:|---|
| `id` | ✔ | 稳定编号（`C1`、`C2`…）★ **编号一旦写下不得改**（否则读数不可比） |
| `text` | ✔ | 结论的**命题**（不是措辞）⇒ ★ **措辞不同但同命题 ⇒ 同族** |
| `key_conclusions` | | 该题的**承重结论**（承重口径专用） |
| `mutual_exclusion_groups` | ✔ | **互斥组** ⇒ 组内结论**不能同时成立** ⇒ ★ 用来验证"两派相反"确实能被分族 |
| `open_ended` | | 该题是否开放题（★ 开放题上本口径最弱） |
| `note` | | 口径备注 |

### ★★ 1.1 为什么用「互斥命题」而不是「具体数值」

| 理由 | 说明 |
|---|---|
| ① **数值会算错** | ★ 把算错的数值写进预注册 ⇒ **污染整个尺子** ⇒ 不可接受 |
| ② ★★ **判官判的是命题** | `CARD_Q` 要判的是"这条陈述**支持哪条结论**" ⇒ 命题形式才是判官能对齐的东西 |
| ③ ★★★ **互斥命题天然分两族** | ⇒ **正面命中 Vendi 的盲点**（Vendi 把「2 同向 + 2 反向」判成 **1.00**） |
| ④ 与题目性质一致 | S1/S2/S3 是"推导唯一"，唯一性在**命题**上，不在数值书写上 |

### ★ 1.2 互斥组是**验收项**，不是装饰
★ **每个 `mutual_exclusion_groups` 内的结论不能同时成立** ⇒ ⇒ **互斥组必须覆盖全部结论**
⇒ ⇒ 违反 ⇒ 意味着这题的"结论空间"不是一个划分 ⇒ **该题的族数不可解释** ⇒ **该题不出读数**

## 3 · 族数的两个口径（★ 引用必须写明用哪个）

| 口径 | 定义 | 说明 |
|---|---|---|
| **承重（主读数）** | 只数 `load_bearing=True` 的卡 | ★ 空族（`''`）在该卡上代表"它什么结论都没支撑" ⇒ **不是一条路径** |
| **全卡** | 数全部卡的族（**含空族 `''`**） | ★ 空族会被算成**一个族** ⇒ ⇒ **两种口径的族数不同** |

⇒ 实现：`metrics_ext.py::family_dedup_count(cards, load_bearing_only=True|False)`（5 项自检全绿）
⇒ ★ **自检里含关键用例：「对立答案 ⇒ 分成两族」** ⇒ **正面命中 Vendi 的盲点**
