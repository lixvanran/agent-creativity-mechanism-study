# 优化器契约（Optimizer Contract）· 补上"只有目标函数、没有优化策略"的那一层

> 2026-10-21 ｜ 负责人指出：**维度增益 = 工作流 − 直调LLM 只是目标函数；强化学习还需要优化策略，而优化策略没有。**
> 本文件把那个缺口写成**三条路线共用的可执行契约**。
> ⚠️ 本文件是**设计**，未跑任何实验；所有阈值都需负责人确认后才冻结。

---

## 0. 缺口到底缺在哪（精确化）

现状（证据见 `routes/{A,B,C}/DESIGN.md` 与 `routes/PROTOCOL.md`）：

| | 协议声明的主判据 | 优化器实际最大化的量 | 优化器 |
|---|---|---|---|
| **A 设计架构** | `VD_net`（净有效维度增益，双边） | **无**（零训练，12 个预注册常量全是常量） | **没有** |
| **B 训练架构** | `VD_net` | 代理 **Ŵ**（依据条目覆盖率比例） | REINFORCE（30 维 w） |
| **C 先设计再训练** | `VD_net` | 目标 **J**（被支持且互不重复的断言计数） | 带收缩的坐标下降（12 参数） |

⇒ ★ **协议的主判据 `VD_net` 不是任何一个优化器在最大化的量。**
⇒ 路线 B 早已察觉这道断裂，但**把它做成了一个 kill switch**：
「`Spearman(Ŵ, vd_final) < 0.50` ⇒ 训练目标判定为**未验证** ⇒ 停止训练并如实报告失败」
⇒ 也就是说：**我们选择"发现断裂就杀死实验"，而不是"把断裂接上"。**

⇒ **这个缺口在三处的表现不同，但根子是同一个**：

| 路线 | 它缺的是 |
|---|---|
| **A** | **缺"可判定的改进步"** —— 它的"优化器"是**人**（每次改 DESIGN.md 就是一步），而人没有噪声地板概念，只会往好看方向看 |
| **B** | **缺"目标与优化器对齐"** —— 优化器在追 Ŵ，主判据在测 `VD_net` |
| **C** | **缺"跨拓扑的选择"** —— 参数学得再好，也只是**给定拓扑内的局部最优** |

## 1. ★ 先决条件：目标必须**可重复到能被优化**

**这一层排在最前，不是 RL，是"让目标可重复"。**

### 1.1 我们已经实测到的（批次 U1-2026-10-21）

同一批 12 份答案、同一判官模型、同一份依据包，**只换判官提示词版本**：

| 测量版本 | 判官提示 | 承重数分布 | `parsefail` 最高 | A_fixed 净增益（3 次重复） |
|---|---|---|---|---|
| v1 | 依据 + `C_t` **各传一份**（3771 字符） | 0–3 | **1.000** | 0 / +1 / −1 |
| v2 | 依据与 `C_t` **合并成一份** | 0–3 | **0.000** | +1 / +4 / 0 |

⇒ **同一批答案 ⇒ 读数随提示词版本变 ⇒ 测量带宽 > 信号带宽。**

### 1.2 为什么这直接否掉了"先上强化学习"

> **在测量带宽大于信号带宽时，任何梯度式更新都在优化噪声。**
> 更糟：判官提示词版本是一个**隐藏的混淆变量** —— 优化器会不自觉地去利用它
> （"换个提示词版本，读数就涨" ⇒ 这是 reward hacking 的教科书形态）。

### 1.3 所以 L0 的定义

**L0 · 目标可重复性**（**优化的准入券**）：

| # | 要求 | 具体做法 |
|:-:|---|---|
| **L0-1** | **测量协议版本冻结** | 判官提示词、抽取器、卡片 schema、依据包哈希 四者绑定成一个 `measure_version`；**改任一项 ⇒ 测量带宽变 ⇒ 全部历史读数作废并重测** |
| **L0-2** | **重复测量** | 同一份答案测 **R_meas** 次（成本：测量侧 $0 ⇒ 便宜 ⇒ 取 **5**），取**中位数**；不取单次 |
| **L0-3** | **噪声地板 δ** | 用 **DEV 集**上"同一配置、不同随机种子"的读数波动估 δ（`δ = 中位数绝对偏差 × 1.4826`）；**δ 必须事前写死** |
| **L0-4** | **接受阈值** | 一次改动的收益**必须 > δ** 才算"变好"（否则视为噪声，回退） |
| **L0-5** | **地板检测** | 若被优化量的**绝对值**长期贴着 0（U1 批次实测 9/12 份 `D=0`）⇒ **先放宽判据或扩依据包，再谈优化**（否则优化器只会去追噪声） |

⇒ ★ **L0-5 是本批最痛的一条**：现在的 `VD_net` 地板效应太重，
**在这个状态下做任何优化都是假的**。⇒ **L0-5 应当是优化的前置闸门。**

## 2. L1 · 信用分配：终局的增益怎么归因到具体步骤

**现状**：`VD_net` 是**终局标量**（两份答案的维度集合差）。
维度卡片有 `stage` 字段（`internal` / `final`）**但只用于区分"探索了但没输出"**，
**没有用于把增益归因到"哪个步骤"**。

⇒ **缺的是"贡献度"（contribution）分解**：

| 概念 | 定义 | 用途 |
|---|---|---|
| **边际贡献 Δ(step)** | 去掉该步骤后，`VD_net` 下降多少 | 哪个步骤真的在造维度 |
| **冗余步骤** | Δ(step) ≈ 0 | **可删**（这正是路线 A 缺优化器时最该做的事） |
| **反向步骤** | Δ(step) < 0 | 该步骤在**挤掉**别的维度（路线 A 复核 F4 抓到过） |
| **stage 分解** | 增益按产生阶段归因（GEN / EXTRACT / VERIFY / SPLIT / MERGE） | 让 B 的 op 分布、C 的参数、A 的节点**同台可比** |

⇒ ★ **可执行性判据**：`Δ(step)` 的估计必须**便宜** ⇒
**用消融臂**（去掉一步再测一遍）而不是反事实推理 —— 消融贵在**生成**，
而**测量是免费的**（MiniMax 订阅 $0）⇒ **成本结构天然支持消融式信用分配**。

⇒ **这一步同时解决路线 A 的核心问题**：
A 现在只能说"我按 track-d 选了 D2/D5/D3" ⇒ **说不出每个组件各贡献多少维度**。
有了 `Δ(component)` ⇒ A 的组件选择就**从先验变成了数据** ⇒ **A 也有优化器了**。

## 3. L2 · 搜索空间：哪些自由度可以动

| 路线 | 自由度 | 数量 | 谁定 |
|---|---|---|---|
| **A** | **无**（拓扑、承载面、装配顺序全是预注册常量） | 0 | —— |
| **B** | 权重 `w` | 30 | 训练 |
| **C** | 参数 `θ` | 12（默认拓扑下活 7）+ **拓扑 6 选 1** | 训练 / 人 |

⇒ ★ **路线 A 在 L2 上是空的** ⇒ 它**没有优化策略**（不是因为没写，而是**没有可动的量**）。
⇒ ⇒ **A 的"优化器"只能是"人改 DESIGN.md"** ⇒ 所以**契约对 A 的价值最大**：
它把"人拍脑袋改设计"变成"有噪声地板、有接受阈值、有留痕的可判定改进步"。

⇒ **L2 的统一化建议**：把 A 的预注册常量、B 的 `w`、C 的 `θ + 拓扑`
**都映射成同一种对象**：
```
config = {
  "route": "A"|"B"|"C",
  "topology": "T2",            # A 固定；B 固定；C 可枚举 6
  "params": {...},              # A 12 常量；B —；C 12 参数
  "weights": [...],             # A —；B 30 维；C —
  "prompt_version": "...",      # 三者都有
  "measure_version": "..."      # L0-1 的绑定
}
```
⇒ 于是**三条路线第一次可以在同一张"改进步"表上比较**。

## 4. L3 · 更新规则：从测得的增益到一次改动

### 4.1 契约（**三条路线共用；A 的"人"也走这条**）

```
输入：当前 config θ、DEV 集、measure_version、噪声地板 δ、改动预算 K
输出：下一候选 config θ'、变更理由、预期方向

纪律（缺一不可）：
 ① **一次只改一个自由度**（可归因；B 的 30 维权重一次只能动一个方向）
 ② 改动后在 DEV 上**重复测量 R_meas 次**，取中位数
 ③ **接受条件**：VD_net(θ') − VD_net(θ) > δ  **且** 所有反判据不劣化
    （矛盾率不升 / 正确答案不丢 / 成本不超预算）⇒ 接受；否则**回退到 θ**
 ④ **预算上限**：最多 K 次改动（K 事前写死）；到顶即停
 ⑤ **禁止在 TEST 集上做改动决策** —— TEST 只在最后跑一次（协议 §4.1 已分 DEV/TEST）
 ⑥ **禁止为了好看改 measure_version**（改它 ⇒ 带宽变 ⇒ 全部重测并声明）
 ⑦ 每次改动的 (θ, θ', VD_net(θ'), 反判据, δ, 接受/回退) **全部落盘**
 ⑧ 收敛判据：连续 3 次改动收益都 ≤ δ ⇒ 停（"已到噪声地板"）
```

⇒ ★ **③ 是整份契约的核心**：它把"变好了"定义成**可判定**的，
从而让 **A 的人、B 的梯度、C 的坐标下降** 用的是**同一条判据**。

### 4.2 优化策略的**形态**要匹配信号形态（别硬套 RL）

| 现实约束 | 本项目的实际情况 |
|---|---|
| 样本量 | 5 道训练题 × 10 步（路线 C 的实测：8 题 2 轮坐标下降） |
| 信号形态 | `VD_net` 是**整数**、是**两个噪声测量之差** |
| 信号带宽 | U1 批次实测：**跨判官版本就漂移**（0/+1/−1 → +1/+4/0） |
| 成本结构 | **生成贵**（OpenRouter 139 次 / 189k token）｜**测量便宜**（MiniMax $0） |

⇒ ⇒ **PPO / SAC 这类需要大量样本 + 平稳奖励的算法在这里是错的工具。**
⇒ **现实选择（按本项目量级排序）**：
1. **噪声感知的坐标下降 / 进化搜索（ES）** —— 路线 C 已有雏形，**只需加 L0 的 δ 与接受规则**
2. **贝叶斯优化** —— 超参少（12 个）、单次评估贵、噪声大 ⇒ BO 的典型场景
3. **bandit（UCB / Thompson）** —— 在**拓扑**这一层（6 选 1）最合适
4. **（不推荐）策略梯度** —— 除非先有 L0 的稳定测量 + 数量级更大的 DEV 集

⇒ ★ **成本结构给了一条很实用的策略**：
**用便宜的重复测量判"是否变好"，确认变好才花生成预算。**
（生成一次 ≈ 十几秒 + OpenRouter 费用；测量一次 ≈ $0 ⇒ 应该**多测少生成**。）

## 5. L4 · 元优化：**"Agent 自主探索架构"的真正落点**

现在的路线 B 学的是**操作序列**（在固定动作空间里选下一步）。
⇒ 但"自主探索出一套架构"更值钱的形态是：**让架构空间本身成为被优化对象**。

⇒ **元优化器**（三条路线共用）：
```
输入：候选架构集合（路线 = 拓扑模板 × 参数 × 权重 × 提示版本）
选择准则（事前写死）：
  ① VD_net 在 DEV 上的提升（必须 > δ）
  ② 反判据全部不劣化
  ③ 成本可接受
  ④ **稳定性**：在 DEV 的**留出折**上不塌（路线 C 的折外评估思路）
  ⑤ **可解释性/结构合法性**：通过结构检查器（如 C 的 H1–H6）
输出：选定的架构 + 它的 (θ, VD_net, 成本, 稳定性) 记录
TEST：只在最后跑一次，报告 VD_net 与全部否证条件
```

⇒ ★ **这才是三条路线能被"一起"评的依据**：
A 提供**人定拓扑的高质量候选**，B 提供**权重层面的自动搜索**，
C 提供**拓扑可枚举 + 参数可学** ⇒ 元优化器在它们之上选。

⇒ ⚠️ **但元优化器本身也会过拟合 DEV** ⇒ 必须有**留出折**（路线 C 已有）
⇒ 且**选择的自由度必须受罚**（复杂度罚：拓扑更复杂 ⇒ 同样增益下优先选简单的）⇒ 避免"选了个又贵又脆的"。

## 6. 落地顺序（建议）

| 阶段 | 做什么 | 需要什么 | 产出 |
|:-:|---|---|---|
| **S1** | **L0-3 噪声地板 δ**：在 DEV 集上重复测量，估 δ | **DEV 集先造出来**（协议 §4.2，一直没做） | `δ` 数值 + 测量复现脚本 |
| **S2** | **L1 信用分配**：消融式 `Δ(component)` | S1（否则 Δ 小于噪声） | 每条路线一张"组件贡献表" |
| **S3** | **L2 统一 config 对象 + L3 契约** | S2 | 三条路线共用的优化器接口 |
| **S4** | **L3 落地**：A（人）、B（REINFORCE 或换 ES）、C（坐标降级+δ） | S3 | 第一次可比较的"改进步"轨迹 |
| **S5** | **L4 元优化**：在 A/B/C 之上选架构 | S4 | 架构选择 + TEST 一次 |

⇒ ★ **S1 是所有后续的前提，而 S1 的前提是"DEV 集"** ——
**这是比"优化策略"更靠前的缺口**：协议 §4.2 写了 DEV 集规格，**但一直没人建**。
⇒ 没有 DEV 集 ⇒ 没有 δ ⇒ 没有 L1 ⇒ 没有优化策略。

## 7. 三个必须先承认的事实（不承认就没法优化）

1. **本批 `VD_net` 的地板效应很重**（U1：9/12 份 `D=0`）⇒ **在地板上优化 = 追噪声**。
   ⇒ 先扩依据包 / 放宽承重判据（两者都要重新冻结并留痕）。
2. **测量带宽 > 信号带宽**（U1：跨判官版本净增益 0/+1/−1 → +1/+4/0）⇒ **先 L0 再 L3**。
3. **A 路线目前根本没有可动的量** ⇒ 它与 B/C **不可比** ⇒ 要么给 A 一个可枚举的搜索空间
   （把 12 个预注册常量变成"可动但默认不动"），要么明确承认 **A = 人做优化的基线**，
   用契约去约束"人"（这本身就有价值）。
