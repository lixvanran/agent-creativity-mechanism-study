### 【主】B-1 · 层1：搜索空间塌缩 / 过早闭合的**原因分析**（transformer 注意力机制层面）

**要交付的**：
1. **机制假说清单**（每条写明：在 transformer 的哪个部件上、什么样的分布/信号会导致塌缩）
   - 候选机制（**不要**只列，要逐条给出可检验的预测）：
     - 注意力熵随生成步数单调下降（"注意力塌缩"）
     - 自我注意力的**头间冗余**（多头塌成同质）
     - 在**已生成前缀**上的注意力质量过度集中 ⇒ 采样的有效支撑集变小
     - 位置/内容混合方式导致的**长程依赖被截断** ⇒ 早期决策被锁定（"过早闭合"的结构性来源）
     - **logit 层面的低熵**（比注意力更早的信号）
   - ⚠️ **必须区分"塌缩"与"过早闭合"**：塌缩 = 空间在缩小；过早闭合 = 提前停止探索。二者机制未必相同。
2. **可测量的代理量**（能用我们的真实跑批数据算出来的那种）⇒ 给出**怎么算**
3. **一份"我们能不能证伪它"的清单**：每个假说配 **1 个可失败的预测**
4. **文献支撑**：读相关论文（attention collapse / low-entropy decoding / premature convergence /
   self-consistency / entropy-based search）⇒ **逐字摘录 + 真实标题/作者/venue/arXiv id**
   ⇒ ⚠️ **标签不可信**（我们历史上有 50% 概率把论文标题记错）⇒ **必须逐条核实**
5. **与我们的连接**：哪条假说能解释我们已经观察到的现象？至少要能解释这一条：

   ⇒ 这个"**发散带来更多维度、也带来矛盾**"的现象，在注意力机制上可能对应什么？

## 4. ★ 已知陷阱（每一条都真实发生过，别再踩）

### 4.1 `.pyc` 缓存：跑旧代码却以为在跑新代码
沙箱里 **`.pyc` 的 mtime 失效判断不可靠** ⇒ 源码已改、`grep` 能看到新代码，但 `import` 拿到的是**旧模块**
⇒ 实测：自检明明检测的是旧代码 ⇒ 「改了没反应」的现象。
⇒ **跑任何东西之前**：`rm -rf __pycache__` + `python3 -B` + 脚本里 `sys.dont_write_bytecode = True`
⇒ **「改了没反应」先怀疑环境/缓存，再怀疑代码逻辑**（否则会误导向"回滚"这种错误决定）

### 4.2 MiniMax 的预算：思考块会吃光 `max_tokens`
`MiniMax-M3.1-Flash-Preview` **强制 adaptive thinking**（`thinking:{type:"disabled"}` 会 **400**）
⇒ 实测：`max_tokens=2000` ⇒ **两次尝试都被思考块吃光**（`finish_reason=length`, `content_len=0`）⇒ **静默返回空串**
⇒ `8000` 才出正文。
⇒ ⇒ **2000/4000 这两档不是"可能失败"，是"必然失败"** ⇒ 阶梯必须从 **8000** 起
⇒ ⇒ **空串在读数上会被误读成"这条臂什么都没产出"** ⇒ **空输出必须是一条可计数的失败**

### 4.3 失败不许静默变 0
失败路径静默变成 `0` / 空串 / 完美指标 ⇒ 表格看着正常，比崩溃危险。
⇒ 任何"产出为空/解析失败/走了兜底"都必须**独立计数并落盘**
⇒ **比率型指标必须配绝对分母**
⇒ **日志必须记 `finish_reason` + 完成 token 数** ⇒ 否则事后**无法区分"臂写得短"与"预算烧光被截断"**
（★ 我们 cmp8 的 84 份日志**没记** ⇒ 那个"A5a/A5c 中位 116 字符"的归因**至今无法排除预算截断**）

### 4.4 文献标签不可信
用户派精读任务时给的"URL + 我记得的标题"约 **50% 概率对不上**。
⇒ 核实顺序：arXiv API `export.arxiv.org/api/query?id_list=<id>` → ACL 落地页 → PMC 的 `citation_*` meta → GitHub README 首行
⇒ **在写任何提取之前先做这一步**
⇒ **不许用摘要脑补正文**；抓不到就如实写"只读了 X"

### 4.5 统计纪律
- **分析单元 = 题**；同题多步 rollout **不是**独立样本
- **R 事前固定**（不许"跑够为止"）⇒ 不许因解析失败率高就重跑（p-hacking）
- **不重跑到好看**：invalid 也如实报 valid/total
- **差值 vs 种子噪声地板** ⇒ 落在地板内写「**不可分辨**」，**不写"无效应"**
- **判官/评审必须 `temperature=0`**；闸门型自检要求连跑 2 次一致

### 4.6 沙箱工程事实
- `web_fetch` **全面失败** ⇒ 用 `web_search`（结果的 `content` 字段带抓到的正文整段）；GitHub 用 `curl` 拉 raw
- 单次 bash ≈ 5 分钟上限 ⇒ 长任务 `setsid nohup` + log 写 workspace
- `git ls-files` **必须加 `-z`**（默认转义非 ASCII ⇒ 中文名文件被静默跳过）
- 推后要核对 ref HEAD + 远端树完整性
- **`team` 的 `decision` 通道传不进数组/布尔** ⇒ 用"取消原计划 + 消费已落盘产物"绕法
