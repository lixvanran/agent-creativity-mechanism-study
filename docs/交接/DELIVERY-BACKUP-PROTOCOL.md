## ★ 3 · ★★★ 跨会话传文件：★ 【★ 落 drive + 报 node_id + 报 sha256 ★】★★

> ★★★ **★ 三步（★ 第三组第四组都踩过）★★**
> ① **发件方**：★ 在【给用户的最终回复】里 `<deliver-assets>` 一次（★ ★ **这是唯一会落 drive 的入口** ★★）
> ② **发件方**：★ 查 `drive files search --session-id <自己>` ⇒ ⇒ ★ 取 `node_id` + `download_url`
> ③ **发件方**：★ 在给兄弟会话的消息里报 **node_id + download_url + sha256 全串** ⇒ ⇒ ★ ⇒ **接收方 `curl` URL + `sha256sum` 核**

★ ★★ **★ 绝对不要做的两件事 ★★**
| ★ **别做** | ★ **为什么** |
|---|---|
| ★ **贴 `src="/workspace/..."`** | ★ ★ **★ 那是发件方沙箱的路径 ⇒ ⇒ ★ ⇒ 接收方 curl 必然 404（★ ★ 兄弟会话是独立挂载）★★** |
| ★ **只贴文件名让对方搜** | ★ ★ **★ 中文名 `keyword` 检索失效 ⇒ ⇒ ★ ⇒ 对方会搜 0 命中 ⇒ ⇒ ★ ⇒ **误判"文件不存在"**（★ ★ 我与第四组各白搜过）★★** |

★ ★★ **★ 实测过的 sha256 核验链（★ 唯一可靠）★★**
```bash
curl -sSO "$URL" -o f.zip
sha256sum f.zip          # ★ 与发件方给的全串比对
unzip -q f.zip && cd ...
sha256sum -c SHA256SUMS.txt   # ★ 包内清单全量核
```
