### 0.3 OpenRouter 断供的替代方案（三层，逐层增强）

| 层 | 分区轴的实现 | 需要 OpenRouter？ | 科学强度 |
|---|---|:-:|---|
| **S** | 同模型 M3 多次采样，temp=1.0 | ❌ | 基线，预期饱和 |
| **P** | 同模型 + K 个**普通 persona**（A5 的干预） | ❌ | 中 |
| **M** | MiniMax **9 个不同规模档位**轮换（M3 / M3.1-Flash / M2.7 / M2.5 / M2.1 / M2 …） | ❌ | 中高 |
| **X** | 跨厂商（Claude / Gemini / Qwen / Mistral / DeepSeek） | ⏸ 后天 | **高** |

**关键设计**：把「分区轴的强度」本身做成**自变量**，而不是假设它一定需要跨厂商。这样：
- 如果 S 饱和而 P 就不饱和 → 结论是「persona 足够，不需要跨厂商」，**跨厂商不是必需品**
- 如果 S 和 P 都饱和而 M 不饱和 → 结论是「需要真异质模型」，X 只是加强
- 如果 S/P/M 全都饱和 → **整个前提被证伪**，这本身就是可发表的负面结果

**这样设计的好处**：主线不依赖 OpenRouter，且无论结果如何都有可发表的结论。

## 1. 核心主张与可证伪假设

### 1.1 主张

> LLM 想法多样性崩塌有两个**独立**机制：A5 已证明 (1) 个体层 fixation、(2) 群体层缺乏知识 partitioning，且两种干预各自独立、联合最优。
> 现有 Agent 方案（ADHD 项目，★4412）只处理 (1)——用隔离分支消除链内锚定。
> **但隔离无法产生 (2)**：N 个隔离的同模型采样仍然从同一个聚合分布里抽取，不产生知识分区。
> 我们用「多样性与样本量 K 的关系曲线」检验这一点。

### 1.2 预注册假设（数据收集前冻结）

| ID | 假设 | 证伪条件 |
|---|---|---|
| **H1** | 同模型采样的语义离散度随 K **饱和**（次线性） | S 曲线在 K≤32 内已接近线性 |
| **H2** | persona 多样化（P）能**部分或完全**解除饱和 | P 曲线与 S 曲线形状无统计差异 |
| **H3** | 模型多样化（M）的解除幅度 **> P** | M 与 P 的斜率差 p > 0.05 |
| **H4** | 隔离（独立调用）比单链列清单有更高的有效秩 | 两者有效秩差 p > 0.05 |
| **H5** | 跨厂商（X）的解除幅度 **> M** | X 与 M 无显著差异 |

**H2 是本方案最大的风险**——如果 A5 的 persona 干预单独就够了，「必须跨模型」的立论就垮了。**这必须先测，不要先写。**

## 2. 度量体系（本方案的成败在此）

### 2.1 为什么不能只用两两距离

我上一轮的实测教训：TF-IDF 两两距离在**跨族汇总**时相关系数塌到 **ρ=0.135**。两两距离还有更根本的缺陷——**它分不清「一个大而蓬松的云团」和「五个紧密的小簇」**。而「分区」恰恰是后者的性质。

### 2.2 指标栈（4 个，缺一不可）

设 K 个候选的句向量矩阵为 E（K×1536，已 L2 归一）：

| 指标 | 定义 | 抓什么 | 阈值 |
|---|---|---|---|
| **M1 有效秩 PR** | `PR = (Σλ)² / Σλ²`，λ 为 E 的 PCA 谱 | 集合**张成了几维**。一个模态 → PR≈1；K 个模态 → PR≈K | 无需阈值，**主指标** |
| **M2 模态数** | 在余弦距离 `r` 阈值下的连通分量数 | 字面意义的「分成了几块」 | r 预先固定（如 0.5），**结果对 r 做敏感性分析** |
| **M3 覆盖半径** | 各点到质心距离的均值 | 整体铺开程度（会饱和，只作辅助） | — |
| **M4 逃逸度** | 到 **K=1 默认答案**的距离 | 「有没有逃出高概率中心」——直接对应 premature convergence | 以 K=1 为原点 |

**M1 是主指标的理由**：它**不饱和**。覆盖半径在 K 增大时必然触顶，而有效秩在「真分区」时线性增长。**如果 M1 随 K 线性增长而 M3 早已饱和，这个差异本身就是 partition 的直接证据。**

### 2.3 度量体系的**自验证**（必做，先于任何 LLM 实验）

**在合成数据上先验一遍**：构造已知结构的集合——
- S1：1 个高斯簇（K=64）
- S2：5 个高斯簇，簇心分开（K=64）
- S3：1 个球壳（各向同性、半径相同）
- S4：5 个高斯簇但簇内方差极大（总方差和 S1 相同）

**验收门**：M1 和 M2 必须能把 S1↔S2、S3↔S4 分开；M3 必须**分不开** S3 和 S1（验证「覆盖半径不敏感」这个论断）。

**如果合成检验过不了，M1 就不成立，整套度量要重做。** 这一步不能跳。

### 2.4 效用与新颖必须正交

参考 Novelty Search（Lehman & Stanley 2011）的 deception 论证：**目标函数本身会把搜索误导到死胡同**。

ADHD 项目按 `0.35 新颖 + 0.40 可行 + 0.25 契合` 加权取前 3——**这就是把两轴压成一个标量**。本方案不这么做：

- **新颖/分区度**用 M1–M4 报告
- **效用**单独报告，用 NoveltyBench 的 `utility_k`（含耐心参数 p=0.8），并做 p ∈ {0, 0.3, 0.6, 0.8, 1.0} 的敏感性扫描
- **永不合成单一总分**

外加一道 **deception 检查**：每轮显式问模型「你的目标函数是什么？它会把你引到哪个死胡同？」

## 3. 阶段划分

### 阶段 0 · 度量底座（0.5 天，不依赖任何外部资源）

| 任务 | 验收门 |
|---|---|
| 封装 `embo-01` 客户端（含 `type` 参数坑、重试、并发） | 8 条语义自检全过 |
| 实现 M1–M4 | 合成数据检验过 §2.3 三条 |
| 构造题目集：20 个开放题，**跨领域均衡**（工程/商业/科学/个人决策/写作） | 每题有 ≥1 个可程序化验证的约束子条件，供效用轴使用 |
| 固定所有超参、种子；把假设表写成不可改的 `PREREG.md` | 提交并记录哈希 |

> ⚠️ 题目集必须**跨领域**。这是对 ADHD 项目的直接修正：它六道题**全是工程题**，自己在 preprint 局限里承认「向产品战略/科创/创意写作的泛化 plausible but not demonstrated」。不跨领域就重复它的缺陷。

### 阶段 1 · K 曲线：S 与 P（2 天）

```
K ∈ {1, 2, 4, 8, 16, 32, 64}
S: MiniMax-M3, temp=1.0, 无 persona
P: MiniMax-M3, temp=1.0, 第 i 个样本用第 i 个 ordinary persona
每格 5 次重复（不同种子）
```

- 拟合 `PR ~ K^α`，比较 S 与 P 的 **α**
- **α ≈ 0.5 或更低 = 饱和**；**α ≈ 1 = 线性增长（真分区）**
- 同时跑隔离 vs 单链列清单（H4）

**决策点**：
- 若 P 已接近线性 → **H2 成立，H3/H5 的立论要改**，主张降级为「persona 足够」
- 若 P 仍饱和 → 进入阶段 2

### 阶段 2 · M 轴（2 天）

MiniMax 9 档轮换（M3 / M3.1-Flash-Preview / M2.7 / M2.5 / M2.1 / M2 …）。
注意 highspeed 变体与同名档位可能是同权重不同服务配置，需先验证它们的输出是否真有差异（**这是必要的对照：若 highspeed 与非 highspeed 输出一致，模型轴的效应会被高估**）。

### 阶段 3 · X 轴（后天充值后，1 天）

跨厂商 5 家，与 M 轴同 K 网格。H5。

### 阶段 4 · 端到端架构（3 天）

只在阶段 1–3 确认「哪种轴真的能解除饱和」之后才建。理由：**先量后建**；反过来就是在没有证据的地基上盖楼——这正是 ADHD 项目 issue #18 的病。

架构届时由数据决定，大概率是：
```
轴A 变体：隔离上下文（治 fixation）
轴B 分区：由阶段 1–3 选出真正有效的那一种
归档：M1–M4 直接当在线指标
收敛：三问判据（差异在哪 / 什么条件下成立 / 承重风险），后置
```

### 阶段 5 · 写作（3 天）

论文骨架：
1. 两种机制（引 A5）
2. 测量：为什么两两距离不够（用合成数据证明）
3. K 曲线：S / P / M / X
4. 消融：隔离的独立贡献
5. 架构与端到端结果
6. 负面结果：温度旋钮、τ 阈值、我的两个方法学错误

## 5. 风险与杀死条件

| # | 风险 | 概率 | 后果 | 应对 |
|---|---|:-:|---|---|
| R1 | **persona 单独就够**（H2 成立） | **中** | 「必须跨模型」立论垮 | **提前接受**：结论改为「A5 的 persona 干预足以产生分区」，这本身就是把 A5 首次落到 Agent 上的贡献，**论文照样成立** |
| R2 | 有效秩 PR 对簇结构不敏感 | 中 | 主指标失效 | 阶段 0 合成检验专门验这个；备选：M2 模态数升为主指标 |
| R3 | MiniMax 各档位实际输出趋同 | 中 | M 轴效应被高估 | 先做档位差异性自检（同题不同档，看 PR） |
| R4 | 题目集偏斜 | 中 | 结论不可外推 | 强制跨领域配比，每域 ≥4 题 |
| R5 | embedding 端点限流/成本 | 低 | 进度阻塞 | 已有本地 MiniLM ONNX 兜底（hf-mirror 已下好） |
| R6 | 温度成为混淆源 | 中 | 分区效果被误归因 | **温度全程锁定 1.0**，只让「轴」变 |

**杀死条件（写进 prereg）**：若 S/P/M/X 四条曲线在 K≥16 后**全部**呈现 `α < 0.6`，则「问题空间过早闭合可通过采样架构解决」这一主张**被证伪**，论文改为负面结果报告。
