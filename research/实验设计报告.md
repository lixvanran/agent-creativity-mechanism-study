## 摘要

本实验要回答一个被反复误答的问题：**ADHD 的哪些认知机制，单独施加到 LLM Agent 上时，真的能改变输出质量？**

现有讨论中存在三类混淆，本设计逐一消除：(1) 「多采样」与「选择得好」的效果混淆；(2) 「机制起作用」与「提示词写得好」的效果混淆；(3) 「新颖」与「有用」被压成单一分数后无法分离。

本设计采用**逐档隔离**的准实验结构：10 个档位，每档只含一个机制（或一个基线），以「多选一·无门控」档作为分离「量」与「质」的关键对照，采用**人工盲评**提供 ground truth，采用**独立会话生成**消除生成者的机制偏好污染。

**本研究为探索性（n=4）。所有结论为假设生成，不构成确证。**

---

## 1. 研究问题与可证伪假设

### 1.1 研究问题

> **RQ：** 对每一条 ADHD 认知机制，当其被单独操作化为 Agent 的一个处理条件时，相对于无该机制的对照条件，输出在哪些维度上发生改变？改变的方向、量级、及其在维度间是否一致？

### 1.2 事前假设与证伪条件

> ⚠️ **本节在数据收集前撰写并冻结。** 任何在看到评分数据后新增的假设，均须标记为「事后（post-hoc）」并单独报告，不得混入本节。

| ID | 假设 | 证伪条件（观察到即判定不成立） |
|---|---|---|
| **H1** | 生成侧去重（M1）相对无门控多采样（B1）提高新颖性 | M1 的维度2 中位数 ≤ B1 |
| **H2** | **双门控（M2）相对 B1 提高效用**——即门控的增量价值不等于「候选更多」 | M2 的维度3「用」中位数 ≤ B1 |
| **H3** | 选择门（比较 M2 vs M1）单独贡献效用 | M2 的维度3「用」− M1 的维度3「用」 ≤ 0 |
| **H4** | M2 提高问题空间扩张 | M2 的维度1 中位数 ≤ B0 |
| **H5** | **通用工程实践（P1）不低于任何 ADHD 机制档** | P1 在任一维度上显著低于某个 ADHD 档 |
| **H6** | 前人方法（P1）在陷阱规避上占优 | P1 的维度4 中位数 < B0 |
| **H7** | **负对照失效**：采样参数（M6）与 `sleep(N)`（M7）相对 B0 无实质差异 | M6 或 M7 在 ≥3 个维度上中位数偏离 B0 ≥ 2 分 |
| **H8** | **远—用可分离**：M2 提升「远」时「用」不会同步下降 | M2 与 B0 的「远」差值 > 0 且「用」差值 < 0 |

**H7 的地位特殊**：它不是关于 ADHD 的假设，而是**实验管线的健全性检验**。若负对照失效，则所有其他结果均不可归因，须先排查题目与评分流程。

**H5 的地位同样特殊**：它是关于「ADHD 这层皮是否有贡献」的**元假设**。若 H5 成立，则本研究的主要结论将是否定性的。

## 2. 机制来源与核验状态

所有机制档的设计均有已核验来源。**核验状态分三级**：`✅已核验` = 亲自下载源码或抓取原文核对；`⚠️二手` = 仅有摘要或二手转述；`❌无来源`。

| 档 | 机制 | 来源 | 核验 |
|---|---|---|---|
| M1 | 远联想 / 联想扩张 | Mednick 1962；功能化自 White & Shah；实现参照 SemDiD | ✅ 已核验（机制存在性 ⚠️ 见下注） |
| M2 | 发散↑收敛↓ 双门控 | 本研究 2026-10-11 自建实验（n=72 配对单元） | ✅ 已核验 |
| M3 | 即时奖励偏好 / 尾部采样 | Verbalized Sampling, arXiv 2510.01171 | ✅ 已抓全文逐字核对 |
| M4 | 心智游移 → in-context regeneration | NoveltyBench, arXiv 2504.05228 (COLM 2025) | ✅ 已抓 PDF 核对 |
| M5 | 失败—重试循环 | Reflexion / ToT 家族 | ⚠️ 二手 |
| M6 | 新颖寻求（采样参数） | DIVERGE, arXiv 2602.00238 | ⚠️ 二手 |
| M7 | 睡眠 / 酝酿 | Wagner et al. 2004 *Nature*；Lacaux 2021 | ✅ 已核验（机制存在）；**Agent 侧实现为故意构造的负对照** |
| P1 | 认知框架 fan-out + 陷阱检测 | `UditAkhourii/adhd` ★4393 MIT | ✅ 已下载源码 grep 核验（14 框架、wild 槽位、bench/ 完整） |
| B0/B1 | 基线 | — | — |

**注（必须随本报告一并引用）**：M1 所依据的「远联想」机制本体，在人类研究中被 Benedek & Neubauer (2013, *J Creat Behav* 47(4):273–289) **直接检验且未获支持**——高低创造力者的联想层级并无显著差异。M1 保留的理由是它作为**工程启发**有效，而非因为它在 ADHD 上被证实。这是「可迁移功能目标」与「已被证实的机制」的区别。

## 3. 实验设计

### 3.1 设计类型

**被试内（within-subjects）准实验 + 配对分析。**

- **被试内**：同一题目下，10 个档位全部作答
- **配对单位**：`(题目, 档位)`，共 4 个配对单元
- **非随机化部分**：题目由用户指定，非随机抽样
- **评分者**：用户本人，非盲于**机制内容**（盲于**档位身份**）

### 3.2 自变量：10 个档位

#### 基线档

| 档 | 操作化定义 | 关键参数 |
|---|---|---|
| **B0** | 单次调用，直接输出。`temperature=1.0` | 1 次调用 |
| **B1** | 生成 K=8 个候选，**计算批次质心后取最靠近质心者**（即「最平庸的那个」）。**不设效用门，不设新颖偏置。** | 8 次调用 |

> **B1 的双重作用**：
> (a) 作为「多采样本身」的对照，隔离「量」的效应；
> (b) 作为「门控」的对照，隔离「质」的效应。
> B0→B1 是量的对比，B1→M2 是质的对比。**没有 B1，H2 与 H3 均无法检验。**

#### ADHD 机制档

| 档 | 操作化定义（精确定义到可复现） | 关键参数 |
|---|---|---|
| **M1** | K=8 候选，**贪心接受**：若候选与已接受者的 TF-IDF 余弦相似度 > 0.90 则丢弃重采，**至多 16 次尝试**。**无选择门**，最终取批次质心最近者。 | 最多 16 次调用 |
| **M2** | **生成侧同 M1**；**选择侧**：先计算每候选的效用分（见 §3.3），过门者（效用 ≥ θ）中选**离质心最远**者；无人过门则取效用最高者中离质心最近者。 | 同 M1 |
| **M3** | 单次调用，提示词要求「生成 5 个候选并为每个给出概率」。**丢弃概率 ≥ τ 的典型答案**（默认丢弃最高概率者），从剩余尾部中按自报概率加权采样 1 条。 | 1 次调用 |
| **M4** | 顺序生成 K=5 个候选。**第 2 条起，把此前全部候选原文置于上下文**，要求「给出与上述所有候选功能不等价的新答案」。最终输出最后一条。 | 5 次串行调用 |
| **M5** | 生成 → **外部确定性检查器**判是否通过（各题检查器见 §3.3）→ 未通过则**切换到一条结构上不同的策略**重试（非换随机种子），最多 3 轮。输出最高分者。 | 最多 3 次调用 |
| **M6** | 单次调用，`temperature=1.4`（其余档固定 1.0） | 1 次调用 |
| **M7** | 生成 → `sleep(15)` → **重新生成**（独立调用，非续写）→ 输出第二次结果 | 2 次调用 + 15s |

#### 前人方法档

| 档 | 操作化定义 | 关键参数 |
|---|---|---|
| **P1** | 选取 5 个认知框架（硬件工程师 / 10 岁小孩 / 竞争对手来搞破坏 / 反演 / 拆掉承重假设），并行各生成 1 条候选 → **对抗性批评者**点名每条候选中「看着聪明但实际错在哪」→ **效用检查器**过滤 → 在通过者中选离质心最远者。**保留一个框架槽位给 wild 框架。** | 5 + 1 + 1 次调用 |

#### 负对照

| 档 | 说明 |
|---|---|
| **M6** | 文献判定其已失效（温度在分布坍塌时改善有限；前沿模型不再暴露该参数） |
| **M7** | 无状态 LLM 上，`sleep(N)` 不改变任何条件分布 |

### 3.3 因变量：7 个评分维度 + 自由批注

每份答案按 **0–5** 打分（0=完全不具备，5=极强）。**维度必须分别对应不同机制的作用靶点**——若合并为单一「质量」分，所有机制将无法区分。

| # | 维度 | 判分锚点 | 主要考察 |
|---|---|---|---|
| **D1** | **问题空间扩张** | 是否提出了与常识框架**不同**的问题定义/视角？0=只换措辞，5=改变了问题本身 | M1 M2 P1 |
| **D2** | **新颖性** | 内容本身有多少落在陈词滥调之外？ | M1 M4 M6 |
| **D3a** | **远（distance）** | 联想跨越的语义距离 | Mednick 第一判据；M1 M2 |
| **D3b** | **用（usefulness）** | 落点是否成立、是否可执行 | Mednick 第二判据；M2 P1 |
| **D4** | **陷阱规避** | 是否被「看似合理实则错误」的解法骗到？ | P1 M5 |
| **D5** | **可执行性** | 读者能否照着做 | 通用（质量兜底） |
| **D6** | **自洽性** | 前后有无自相矛盾 | 通用（质量兜底） |
| **D7** | **总体有用** | 直觉判断 | 综合 |

> ⚠️ **D3 必须拆成 D3a / D3b 分别打分，不得合并。** 合并将永久失去检验 Mednick 第二判据的能力——本研究已有先例证据：某条件下「远」提升 16.7pp 而「用」仅变动 0.25pp，若合成单一分数则完全不可见。

**每份答案另附两行自由批注**（信息量常高于分数）：
- 「最强的一点」
- 「最大的问题」

---

### 3.4 外部确定性检查器（用于 M2 选择门与 M5 验证环）

**不得使用 LLM 裁判。** 各题的检查器随题目一并提供，或由评分者指定。检查器需满足：

- 输出 ∈ [0, 1] 的连续值
- 同一答案任意次判定结果**完全一致**
- 实现对评分者公开（保证 M2/M5 档得分可复现）

> **理由**：已知 LLM 裁判的一致性问题——自偏好偏置、长度偏置、谄媚偏差。本研究前期实测：序列奖励模型在配平客观正确性后仅 52.7% 准确率。用不可靠尺子做「选择门」，等于在最关键的环节引入噪声。

---

### 3.5 控制变量

| 变量 | 设定 | 不控制会怎样 |
|---|---|---|
| 模型 | 全部档位同一模型、同一版本号 | 档间差异无法归因于机制 |
| temperature | **固定 1.0**，仅 M6 档为 1.4 | 温度是最容易被误当作创造力旋钮的混淆源 |
| max_tokens | 固定上限 | 输出长度不可控 |
| **输出长度** | **强制等长**：每档 ≤ 400 中文字（见 §4.3） | **字数多的档在所有印象维度上都会赢** |
| 提示骨架 | 所有档使用**同一输出模板**与相近的骨架措辞 | 提示工程质量与机制效果混淆（见 §6.4） |
| 随机种子 | 各档独立固定种子，记录在案 | 不可复现 |
| 档位顺序 | 打散呈现 | 顺序效应 |
| ID 分配 | 每题内随机不透明 ID | 可被推断 |

## 4. 实验流程

### 4.1 阶段划分

```
阶段 0  输入题目 + 检查器定义（用户提供）
   ↓
阶段 1  档位提示词定稿 + 冻结（我方，单次会话，不接触题目）
   ↓
阶段 2  生成：10 个独立会话并行，各答 4 题（我方）
   ↓
阶段 3  审计：字数核查 + 机制触发日志核查（我方，不经手评分）
   ↓
阶段 4  打包：随机 ID + 打散 + 封存映射表（我方）
   ↓
阶段 5  评分：用户按 D1–D7 + 自由批注（用户）
   ↓
阶段 6  解封 + 配对分析（我方）
   ↓
阶段 7  成稿 + 诚实边界声明（我方）
```

### 4.2 阶段 2 的关键约束：独立会话

**每档开一个独立会话。** 该会话：
- 只接收 `{题目, 该档的机制指令, 统一输出模板}`
- **不接收**：其他档的任何信息、实验目的、假设、其他档的结果
- **不接收**：该档的代号（M1/B0/P1 等一律隐去）

**理由（必须写入报告）**：若由同一执行者撰写全部档位，执行者一旦知晓「这一档是高档机制」，其输出质量会系统性抬高，构成**生成者污染**。这是本设计中最难通过提示词约束消除的偏差，故用架构手段消除。

### 4.3 统一输出模板（所有档位强制）

```
【回答】
<正文，≤400 中文字>

【本回答的一句话定位】
<一句话说明这份回答试图解决什么>

【自评：我可能错在哪】
<主动指出本答案最脆弱的一点>
```

**「一句话定位」栏是诊断字段**：若某档的定位句与其他档高度雷同，说明**机制未真正生效**，仅换了说法。此情形须在最终报告中单列，不得计入机制有效性。

## 5. 盲评机制

1. 生成 40 份答案
2. 分配**随机不透明 ID**（如 `A7`/`K2`/`M9`），随机且非顺序、不含语义
3. **ID→档位映射表封存**至 `sealed-mapping.json`，评分期间不提供
4. 四题答案**混合打散**呈现，不按题分组、不按档分组
5. **同一档在不同题上使用不同 ID**，防止通过 ID 模式推断档位
6. 用户评分完毕后解封

### 5.1 我方在评分期间不得做的事

- 不得提示任何档位的代号或机制名
- 不得对任何答案给出倾向性评论
- 不得解释某一答案「本应体现什么机制」
- 若用户就具体答案提问，只能回答关于**事实内容**的问题，不得透露设计意图

## 6. 效度威胁与缓解

### 6.1 内部效度（构念效度 —— 最严重）

| 威胁 | 缓解 |
|---|---|
| **机制未真正触发**却被计为「机制无效」 | 阶段 3 审计**机制触发日志**；区分「执行了但无效」与「根本没执行」 |
| **D3a/D3b 未真正分开** | 模板与打分表强制分列；分析时分别导出 |
| 提示工程质量与机制效果混淆 | 统一模板与骨架措辞（§3.5）；**残余风险见 §6.4** |

### 6.2 统计结论效度

| 威胁 | 缓解 |
|---|---|
| n=4 无法支撑显著性检验 | **只报方向与量级，禁止报 p 值**；预先声明探索性 |
| 多重比较（10 档 × 7 维 = 70 个比较） | 假设已在 §1.2 冻结；**未登记的比较一律标为事后** |
| 评分者即生成触发者 | 无法通过设计消除；靠多维度 + 自由批注部分缓解，并在报告声明 |

### 6.3 外部效度

n=4 且题目单一，结论**仅在所选题目的类型上成立**。禁止外推至其他模型、其他温度、其他领域。

### 6.4 残余风险（必须写入最终报告，无法消除）

> **若某档位得分显著高于基线，无法区分其成因是「机制本身有效」还是「该档的提示词写得更好」。**

**本设计无法在统计上分离这两者。** 缓解办法（可选，用户决定是否加跑）：
增加一个 **P2 对照档**——使用与最高分档**完全相同的提示骨架**，但**移除其核心机制**。若 P2 的分数回落到基线水平，则机制贡献成立；若维持高分，则说明是提示工程质量所致。
- 加跑：10 档 → 11 档，40 份 → 44 份
- 不加跑：本风险在报告中明确声明

---

## 7. 伦理

1. **不使用真实临床数据、不涉及任何真实患者或诊断。** 本实验仅将公开文献中的认知机制作为**工程启发**使用。
2. **不对外宣称「ADHD 机制提升了创造力」。** 鉴于本研究为探索性且类比基础存在已知问题，任何对外表述须包含完整限定条件。
3. **不使用「ADHD 化」作为产品定位。** 将临床构型作为营销标签存在明确的伦理风险——诊断标签可能被直接转移到非临床用户身上。
4. 评分数据的使用范围由用户在实验前指定（默认仅限本次分析）。

## 8. 分析计划（事前登记，冻结）

### 8.1 主分析

以题目为配对单位，对每个假设计算**四题配对差值的中位数**。

| 对比 | 检验假设 |
|---|---|
| B1 − B0 | 「多采样」本身是否有效（量的效应） |
| M1 − B1 | H1：生成侧去重的增量 |
| **M2 − B1** | **H2：门控的增量（核心对比）** |
| M2 − M1 | H3：选择门的单独贡献 |
| M2 − B0 | H4：相对基线的整体效果 |
| P1 − max(M1, M2) | H5：通用实践 vs ADHD 机制组合 |
| P1 − B0（D4） | H6：陷阱规避 |
| M6 − B0；M7 − B0 | H7：负对照健全性 |
| (M2−B0) 在 D3a / D3b 上 | H8：远—用是否分离 |

### 8.2 判定规则

- **支持**：四题配对差值中位数方向与假设一致，且 ≥3/4 题同向
- **不支持**：方向相反，或 ≤2/4 题同向
- **不确定**：恰好 2/4 题同向

**不设阈值型显著性检验。** 报告将明确写出：n=4 下任何 p 值均不具备解释价值。

### 8.3 必须报告的中间诊断

| 诊断项 | 目的 |
|---|---|
| 各档字数分布 | 验证等长约束是否真的生效 |
| 机制触发率 | 各档机制是否真的执行 |
| 定位句相似度 | 检测「换皮不换机制」 |
| 单调性检查 | 若 D3a↑ 而 D3b↓，是否在 M2 上出现 |

## 附录 A：档位与「ADHD 特质」对应关系

| 档 | 对应的 ADHD 特质 | 该特质在人类研究中的证据强度 |
|---|---|---|
| M1 | 远联想 / 联想扩张（Mednick） | **低**——机制本体被直接检验且未获支持（Benedek & Neubauer 2013） |
| M2 | 发散↑ / 收敛↓ 的失衡 | **高**——解离现象在多项研究中稳定复现 |
| M3 | 即时奖励偏好（时间贴现） | **中**——Wilson 2011，但控制 IQ 后效应不存活 |
| M4 | 心智游移 / 默认模式网络 | **低-中**——相关实验样本多非 ADHD 被试 |
| M5 | 失败—重试循环 | **未找到原始出处** |
| M6 | 新颖寻求 / 感觉寻求 | **低**——影像学差异 ≠ 创造力收益 |
| M7 | 睡眠 / 入睡期意象 | **最不 ADHD 特异**；Agent 侧为故意构造的负对照 |

**M5 与 M7 是本设计中最需要警惕的两档**：前者无原始文献出处，后者被标注为「不可迁移」。若这两档意外得分高，优先怀疑的是**提示工程质量**而非机制本身（见 §6.4）。

## 附录 B：本报告的已知局限

1. **n=4，探索性研究。** 所有结论为假设生成。
2. **题目由用户指定**，非随机抽样，存在选择性偏差风险。
3. **单一评分者**，无评分者间信度（IRR）数据。
4. **单一模型、单一温度**，结论不可外推。
5. **「机制」与「提示工程质量」不可分离**（§6.4），这是本设计最大的未解问题。
6. **M2 的选择门依赖外部检查器**，而检查器的定义随题目而变，其质量会直接影响 M2 的表现——这是一个未受控的依赖。
